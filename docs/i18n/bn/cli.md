# CLI রেফারেন্স

Co-op Translator নিম্নলিখিত কমান্ড-লাইন এন্ট্রি পয়েন্টগুলো ইনস্টল করে:

- `translate`
- `evaluate`
- `migrate-links`
- `co-op-review`
- `co-op-translator-mcp`

`translate`, `evaluate`, `migrate-links`, এবং `co-op-review` কমান্ডগুলো `co_op_translator.__main__` এর মাধ্যমে প্রেরিত হয়, যা চালানো স্ক্রিপ্টের নামের ওপর ভিত্তি করে কমান্ড ইমপ্লিমেন্টেশন নির্বাচন করে। MCP সার্ভার সরাসরি `co_op_translator.mcp.server` ব্যবহার করে।

আপনি যদি CLI, Python API, এবং MCP-এর মধ্যে বেছে নিতে যাচ্ছেন, তাহলে শুরু করুন [আপনার কর্মপ্রবাহ নির্বাচন করুন](workflows.md)।

## কনসোল আউটপুট

ইন্টারেক্টিভ টার্মিনালগুলো কমান্ড হেডার, প্রগ্রেস, এবং সারাংশের জন্য Rich ফরম্যাটিং ব্যবহার করে। CI এবং নন-ইন্টারেক্টিভ আউটপুট স্বয়ংক্রিয়ভাবে প্লেইন টেক্সটে ফিরে যায়।

প্লেইন আউটপুট জোরপূর্বক করতে `CO_OP_TRANSLATOR_OUTPUT_STYLE=plain` সেট করুন, অথবা Rich আউটপুট জোরপূর্বক করতে `CO_OP_TRANSLATOR_OUTPUT_STYLE=rich` সেট করুন। লাইভ প্রগ্রেস বারগুলো দমন করে সারাংশ রাখতে `CO_OP_TRANSLATOR_NO_PROGRESS=1` সেট করুন।

যখন অন্য কোনো সিস্টেম মেশিন-রিডেবল প্রগ্রেস প্রয়োজন করে তখন `translate --json-events progress.ndjson` ব্যবহার করুন
CLI মানব-উদ্দেশ্য আউটপুটটি রেন্ডার করা চালিয়ে যায়, যখন
NDJSON ফাইল সংস্করণকৃত `co-op.translation.event.v1` ইভেন্টগুলি পায় যার মধ্যে
স্থির ক্ষেত্রসমূহ যেমন `type`, `stage_key`, `completed`, `total`, এবং
`current_path` থাকে।

## প্রথমবারের CLI প্রবাহ

যদি আপনি টার্মিনাল থেকে Co-op Translator ব্যবহার করে থাকেন, এখানে শুরু করুন:

1. একটি LLM প্রদানকারী কনফিগার করুন যেমন [Configuration](configuration.md)-এ বর্ণিত।
2. আপনি কোন কন্টেন্ট ধরন অনুবাদ করতে চান তা নির্বাচন করুন।
3. প্রথমে একটি কেন্দ্রীভূত কমান্ড চালান, যেমন শুধুমাত্র Markdown অনুবাদ।
4. বড় রেপোজিটরি পরিবর্তনের আগে `--dry-run` ব্যবহার করুন।
5. অনুবাদের পরে গঠন ও সাম্প্রতিকতা পরীক্ষা করতে `co-op-review` ব্যবহার করুন।

| লক্ষ্য | শুরু করার জন্য কমান্ড |
| --- | --- |
| Markdown ডকুমেন্ট অনুবাদ করুন | `translate -l "ko" -md` |
| নোটবুক অনুবাদ করুন | `translate -l "ko" -nb` |
| ইমেজের টেক্সট অনুবাদ করুন | `translate -l "ko" -img` |
| ফাইল না লিখে কাজের পূর্বরূপ দেখুন | `translate -l "ko" -md --dry-run` |
| বিদ্যমান অনুবাদ পর্যালোচনা করুন | `co-op-review -l "ko"` |
| নোটবুক এবং Markdown লিঙ্ক আপডেট করুন | `migrate-links -l "ko" --dry-run` |
| টুলগুলো MCP ক্লায়েন্টের কাছে উপলব্ধ করুন | CLI কমান্ড সরাসরি চালানোর পরিবর্তে [MCP সার্ভার](mcp.md) কনফিগার করুন। |

## translate

Markdown ফাইল, নোটবুক, এবং ইমেজ টেক্সট এক বা একাধিক লক্ষ্য ভাষায় অনুবাদ করুন।

```bash
translate -l "ko ja fr"
```

### সাধারণ উদাহরণ

শুধুমাত্র Markdown অনুবাদ করুন:

```bash
translate -l "de" -md
```

শুধুমাত্র নোটবুক অনুবাদ করুন:

```bash
translate -l "zh-CN" -nb
```

Markdown ও ইমেজ অনুবাদ করুন:

```bash
translate -l "pt-BR" -md -img
```

বিদ্যমান অনুবাদগুলি মুছে পুনরায় তৈরি করে আপডেট করুন:

```bash
translate -l "ko" -u
```

ইন্টারএক্টিভ প্রম্পট বাদ দিয়ে চালান:

```bash
translate -l "ko ja" -md -y
```

লগ সংরক্ষণ করুন:

```bash
translate -l "ko" -s
```

গঠনভিত্তিক প্রগ্রেস ইভেন্ট লিখুন:

```bash
translate -l "ko ja" -md --json-events progress.ndjson
```

### অপশনসমূহ

| অপশন | প্রয়োজনীয় | বিবরণ |
| --- | --- | --- |
| `-l`, `--language-codes` | Yes | স্পেস-সেপারেট ভাষা কোড, যেমন `"es fr de"`, বা `"all"`. |
| `-r`, `--root-dir` | No | প্রকল্প রুট। ডিফল্ট হল বর্তমান ডিরেক্টরি। |
| `-u`, `--update` | No | নির্বাচিত ভাষাগুলোর বিদ্যমান অনুবাদ মুছে ফেলে পুনরায় তৈরি করুন। |
| `-img`, `--images` | No | শুধুমাত্র ইমেজ ফাইল অনুবাদ করুন। |
| `-md`, `--markdown` | No | শুধুমাত্র Markdown ফাইল অনুবাদ করুন। |
| `-nb`, `--notebook` | No | শুধুমাত্র Jupyter নোটবুক ফাইল অনুবাদ করুন। |
| `-d`, `--debug` | No | কনসোলে ডিবাগ লগিং সক্ষম করুন। |
| `-s`, `--save-logs` | No | DEBUG-লেভেলের লগ `<root-dir>/logs/`-এ সংরক্ষণ করুন। |
| `--json-events` | No | অনুবাদ প্রগ্রেস ইভেন্ট NDJSON হিসেবে মেশিন-রিডেবলভাবে লিখুন। |
| `-x`, `--fix` | No | পূর্ববর্তী মূল্যায়ন ফলাফলের ভিত্তিতে নিম্ন-নির্ভরতার Markdown ফাইলগুলি পুনরায় অনুবাদ করুন। |
| `-c`, `--min-confidence` | No | `--fix` এর জন্য আত্মবিশ্বাস থ্রেশহোল্ড। ডিফল্ট `0.7`. |
| `--add-disclaimer`, `--no-disclaimer` | No | মেশিন অনুবাদ ডিসক্লেইমার যোগ বা অদৃশ্য করুন। CLI-তে ডিফল্টভাবে সক্রিয়। |
| `-f`, `--fast` | No | পুরনো (deprecated) দ্রুত ইমেজ মোড। |
| `-y`, `--yes` | No | প্রম্পটগুলো স্বয়ংক্রিয়ভাবে কনফার্ম করুন, CI-তে উপকারী। |
| `--repo-url` | No | README ভাষা টেবিলে sparse-checkout পরামর্শে ব্যবহৃত রেপোজিটরি URL। |
| `--migrate-language-folders` | No | পুরনো আলিয়াস ফোল্ডারগুলো, যেমন `cn` বা `tw`, canonical BCP 47 ফোল্ডারে নাম পরিবর্তন করুন। |
| `--dry-run` | No | ফাইল না লিখে ভাষা ফোল্ডার মাইগ্রেশন ও অনুবাদের অনুমান পূর্বদৃশ্য দেখুন। |

যদি কোন টাইপ ফ্ল্যাগ প্রদান না করা হয়, `translate` Markdown, নোটবুক, এবং ইমেজগুলো প্রক্রিয়াকরণ করে। ইমেজ অনুবাদ করার জন্য Azure AI Vision কনফিগারেশন প্রয়োজন।

## evaluate

একটি ভাষার অনুবাদিত Markdown এর মান মূল্যায়ন করুন।

!!! warning "Experimental"
    `evaluate` একটি পরীক্ষামূলক ফিচার। এটি রুল-ভিত্তিক এবং LLM-ভিত্তিক মান যাচাই ব্যবহার করতে পারে, মূল্যায়ন ফলাফল অনুবাদ মেটাডেটায় লিখে, এবং এর স্কোরিং মডেল ও মেটাডেটা আচরণ পরিবর্তিত হতে পারে।

```bash
evaluate -l "ko"
```

### সাধারণ উদাহরণ

কঠোরতর নিম্ন-নির্ভরতার থ্রেশহোল্ড ব্যবহার করুন:

```bash
evaluate -l "es" -c 0.8
```

শুধুমাত্র রুল-ভিত্তিক চেক চালান:

```bash
evaluate -l "fr" -f
```

শুধুমাত্র LLM-ভিত্তিক চেক চালান:

```bash
evaluate -l "ja" -D
```

### অপশনসমূহ

| অপশন | প্রয়োজনীয় | বিবরণ |
| --- | --- | --- |
| `-l`, `--language-code` | Yes | মূল্যায়ন করার একক ভাষা কোড। আলিয়াস কোডগুলো সাধারণীকরণ করা হয়। |
| `-r`, `--root-dir` | No | প্রকল্প রুট। ডিফল্ট হল বর্তমান ডিরেক্টরি। |
| `-c`, `--min-confidence` | No | নিম্ন-নির্ভরতার অনুবাদ তালিকাকরণের সময় ব্যবহৃত থ্রেশহোল্ড। ডিফল্ট `0.7`. |
| `-d`, `--debug` | No | ডিবাগ লগিং সক্ষম করুন। |
| `-s`, `--save-logs` | No | DEBUG-লেভেলের লগ `<root-dir>/logs/`-এ সংরক্ষণ করুন। |
| `-f`, `--fast` | No | শুধুমাত্র রুল-ভিত্তিক মূল্যায়ন। |
| `-D`, `--deep` | No | শুধুমাত্র LLM-ভিত্তিক মূল্যায়ন। |

ডিফল্টভাবে `evaluate` রুল-ভিত্তিক ও LLM-ভিত্তিক উভয় মূল্যায়ন ব্যবহার করে। ফলাফল অনুবাদ মেটাডেটায় লেখা হয় এবং কনসোলে সারাংশ দেখানো হয়।

## co-op-review

API ক্রেডেনশিয়াল ছাড়াই ডিটারমিনিস্টিক অনুবাদ রক্ষণাবেক্ষণ চেক চালান।

!!! note "Beta"
    `co-op-review` একটি বিটা ডিটারমিনিস্টিক রিভিউ কমান্ড। এটি মডেল প্রদানকারীদের কল করে না এবং ফাইল লিখে না, তবে এর চেক এবং ইস্যু আউটপুট স্কিমা পরিবর্তিত হতে পারে।

```bash
co-op-review -l "ko"
```

### সাধারণ উদাহরণ

বর্তমান ডিরেক্টরি থেকে কোরিয়ান ও জাপানী অনুবাদ পর্যালোচনা করুন:

```bash
co-op-review -l "ko ja"
```

নির্দিষ্ট একটি প্রকল্প রুট পর্যালোচনা করুন:

```bash
co-op-review -l "fr" -r ./my-course
```

README-শুধুমাত্র অনুবাদের পরে কেবল README পর্যালোচনা করুন:

```bash
translate -l "ko" --readme-only -y
co-op-review -l "ko" --readme-only --format github
```

`--readme-only` অন্যান্য ডকুমেন্ট এবং নেস্টেড README-গুলো উপেক্ষা করে। এটি ব্যর্থ হবে যদি রুট
`README.md` অনুপস্থিত থাকে। `--changed-from`-এর সঙ্গে মিলিয়ে এটি কেবল README পর্যালোচনা করে
যখন ঐ সোর্স ফাইলটি পরিবর্তিত হয়েছে। README-only অনুবাদ সোর্স README-কে
অপরিবর্তিত রাখে, যেকোনো shared-section মার্কারসহ।

শুধুমাত্র সেই সোর্স ফাইলগুলো পর্যালোচনা করুন যেগুলো একটি বেস রেফের বিরুদ্ধে পরিবর্তিত হয়েছে:

```bash
co-op-review -l "ko" --changed-from origin/main
```

CI সারাংশের জন্য GitHub-স্টাইল Markdown আউটপুট প্রিন্ট করুন:

```bash
co-op-review -l "ko ja" --changed-from origin/main --format github
```

### অপশনসমূহ

| অপশন | প্রয়োজনীয় | বিবরণ |
| --- | --- | --- |
| `-l`, `--language-code` | No | পর্যালোচনার জন্য ভাষা কোড। একাধিক বার বা স্পেস-সেপারেট মান হিসেবে প্রদান করা যেতে পারে। ডিফল্টভাবে সকল আবিষ্কৃত অনুবাদ ভাষা। |
| `-r`, `--root-dir` | No | প্রকল্প রুট। ডিফল্ট হল বর্তমান ডিরেক্টরি। |
| `--changed-from` | No | পর্যালোচনাকে পরিবর্তিত সোর্স ফাইলগুলোতে সীমিত করার জন্য ব্যবহৃত Git রেফ। |
| `--readme-only` | No | শুধুমাত্র রুট `README.md` অনুবাদ পর্যালোচনা করুন। |
| `--format` | No | আউটপুট ফরম্যাট: `text` বা `github`. ডিফল্ট `text`. |

`co-op-review` বর্তমানে অনুপস্থিত অনুবাদিত ফাইল, অনুপস্থিত বা বার্ধক্যপ্রাপ্ত অনুবাদ মেটাডেটা, Markdown frontmatter ও কোড ফেন্সের অখণ্ডতা, অবৈধ অনুবাদিত নোটবুক JSON, এবং অনুপস্থিত স্থানীয় Markdown বা ইমেজ লিংক টার্গেটগুলো চেক করে। অনুপস্থিত লিংকগুলো ডিফল্টভাবে ওয়ার্নিং; গঠনগত ও সাম্প্রতিকতার সমস্যাগুলো কমান্ডকে ব্যর্থ করে।

## co-op-translator-mcp

এজেন্ট, এডিটর, এবং MCP-সামঞ্জস্যপূর্ণ ক্লায়েন্টদের জন্য Co-op Translator MCP সার্ভার চালান।

```bash
co-op-translator-mcp
```

ডিফল্ট ট্রান্সপোর্ট হল `stdio`। ক্লায়েন্ট কনফিগারেশন, টুলস, রিসোর্স, এবং সেফটি নোটসের জন্য [MCP সার্ভার](mcp.md) গাইড দেখুন।

### অপশনসমূহ

| অপশন | প্রয়োজনীয় | বিবরণ |
| --- | --- | --- |
| `--transport` | No | MCP ট্রান্সপোর্ট: `stdio`, `streamable-http`, or `sse`. ডিফল্ট `stdio`. |

## migrate-links

অনুবাদিত Markdown ফাইলগুলো পুনরায় প্রক্রিয়াকরণ করুন এবং নোটবুক লিঙ্কগুলো আপডেট করুন যাতে উপলব্ধ হলে সেগুলো অনুবাদিত নোটবুকগুলোতেই নির্দেশ করে।

```bash
migrate-links -l "ko ja"
```

### সাধারণ উদাহরণ

লিংক আপডেটের পূর্বদৃশ্য দেখুন:

```bash
migrate-links -l "ko" --dry-run
```

কনফার্মেশন ছাড়াই সব সমর্থিত ভাষা প্রক্রিয়াকরণ করুন:

```bash
migrate-links -l "all" -y
```

শুধুমাত্র তখনই লিংক পুনরায় লেখুন যখন অনুবাদিত নোটবুক বিদ্যমান থাকে:

```bash
migrate-links -l "ko" --no-fallback-to-original
```

### অপশনসমূহ

| অপশন | প্রয়োজনীয় | বিবরণ |
| --- | --- | --- |
| `-l`, `--language-codes` | Yes | স্পেস-সেপারেট ভাষা কোড, বা "all". |
| `-r`, `--root-dir` | No | প্রকল্প রুট। ডিফল্ট হল বর্তমান ডিরেক্টরি। |
| `--image-dir` | No | রুটের আপেক্ষিক অনুবাদিত ইমেজ ডিরেক্টরি। ডিফল্ট `translated_images`. |
| `--dry-run` | No | আপডেট না করে কোন ফাইলগুলো পরিবর্তিত হতো তা দেখান। |
| `--fallback-to-original`, `--no-fallback-to-original` | No | অনুবাদিত নোটবুক অনুপস্থিত হলে মূল নোটবুক লিঙ্ক ব্যবহার করুন। ডিফল্টভাবে সক্রিয়। |
| `-d`, `--debug` | No | ডিবাগ লগিং সক্ষম করুন। |
| `-s`, `--save-logs` | No | DEBUG-লেভেলের লগ `<root-dir>/logs/`-এ সংরক্ষণ করুন। |
| `-y`, `--yes` | No | সব ভাষা প্রক্রিয়াকরণের সময় প্রম্পটগুলো স্বয়ংক্রিয়ভাবে কনফার্ম করুন। |

## পরিবেশ

কোনো কমান্ড যদি প্রদানকারী ক্রেডেনশিয়াল প্রয়োজন করে, তাহলে এই প্রদানকারী সেটগুলোর একটি কনফিগার করুন। `translate --dry-run` এবং `co-op-review` প্রদানকারী ক্রেডেনশিয়াল প্রয়োজন করে না:

```bash
# অ্যাজিউর ওপেনএআই
AZURE_OPENAI_API_KEY="..."
AZURE_OPENAI_ENDPOINT="https://<resource>.openai.azure.com/"
AZURE_OPENAI_MODEL_NAME="gpt-4o"
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME="<deployment>"
AZURE_OPENAI_API_VERSION="2024-12-01-preview"

# অথবা ওপেনএআই
OPENAI_API_KEY="..."
OPENAI_CHAT_MODEL_ID="gpt-4o"

# অথবা অ্যানথ্রপিক
ANTHROPIC_API_KEY="..."
ANTHROPIC_MODEL="claude-..."
```

ইমেজ অনুবাদের জন্য অতিরিক্তভাবে Azure AI Vision প্রয়োজন:

```bash
AZURE_AI_SERVICE_API_KEY="..."
AZURE_AI_SERVICE_ENDPOINT="https://<resource>.cognitiveservices.azure.com/"
```

## আউটপুট বিন্যাস

টেক্সট অনুবাদগুলো লেখা হয় নিচে:

```text
translations/<language-code>/<original-path>
```

অনুবাদকৃত ইমেজ আউটপুট লেখা হয় নিচে:

```text
translated_images/<language-code>/<original-path>
```

উদাহরণস্বরূপ, `README.md` এবং `docs/setup.md` কে কোরিয়ান ভাষায় অনুবাদ করলে তৈরি হয়:

```text
translations/ko/README.md
translations/ko/docs/setup.md
```

## কপি-পেস্ট CLI উদাহরণ

Markdown তিনটি ভাষায় অনুবাদ করুন:

```bash
translate -l "ko ja fr" -md
```

শুধুমাত্র নোটবুক অনুবাদ করুন:

```bash
translate -l "zh-CN" -nb
```

শুধুমাত্র ইমেজ অনুবাদ করুন:

```bash
translate -l "pt-BR" -img
```

ফাইল লিখে না Markdown অনুবাদের পূর্বদৃশ্য দেখুন:

```bash
translate -l "de es" -md --dry-run
```

নিম্ন-নির্ভরতার Markdown অনুবাদগুলো মেরামত করুন:

```bash
evaluate -l "ko" -c 0.8
translate -l "ko" --fix -c 0.8 -md
```

CI-অনুকূল Markdown অনুবাদ চালান:

```bash
translate -l "ko ja" -md -y -s
```

অনুবাদিত আউটপুট পর্যালোচনা করুন:

```bash
co-op-review -l "ko ja"
```

লিংক মাইগ্রেশনের পূর্বদৃশ্য দেখুন:

```bash
migrate-links -l "ko" --dry-run
```
