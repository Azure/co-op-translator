## একটি ভাষা যোগ করুন

নতুন ভাষার সমর্থন যোগ করতে:

1. ভাষার কোড এবং প্রদর্শন নাম language utilities-এ যোগ করুন।
2. `src/co_op_translator/fonts/font_language_mappings.yml`-এ একটি ফন্ট যোগ করুন বা ম্যাপ করুন।
3. Markdown এবং ইমেজ অনুবাদ আউটপুট পরীক্ষা করুন।
4. ম্যাপিং এবং ভ্যালিডেশন নোটসসহ একটি পুল রিকোয়েস্ট খুলুন।
