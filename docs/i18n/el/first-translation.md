# Μετάφραση, επεξεργασία και αναθεώρηση ενός μικρού έργου

Ξεκινήστε με δύο σύντομα αρχεία Markdown και μία γλώσσα-στόχο. Θα δείτε πού γράφονται οι μεταφράσεις, τι συμβαίνει όταν αλλάζει το αρχικό, και πώς να ελέγξετε το αποτέλεσμα.

## Καταγεγραμμένα αποτελέσματα

Το παράδειγμα εκτελέστηκε στις 19 Σεπτεμβρίου 2026 με το Co-op Translator 0.21.0 και το Azure OpenAI (`gpt-5-mini`). Οι μη τροποποιημένες εντολές CLI κλήθηκαν μέσω του `CliRunner` του Click χρησιμοποιώντας το χτισμένο wheel και τις υπάρχουσες εξαρτήσεις Python.

| Βήμα | Αποτέλεσμα |
| --- | --- |
| Προεπισκόπηση | Έξοδος 0; δεν ζητήθηκε μετάφραση μοντέλου |
| Αρχική μετάφραση | Έξοδος 0; 27.36 δευτερόλεπτα |
| Αρχική αναθεώρηση | Έξοδος 0 |
| Επεξεργασία README και αναθεώρηση | Έξοδος 1; ανιχνεύθηκε παρωχημένη μετάφραση |
| Ενημέρωση μετάφρασης | Έξοδος 0; 22.17 δευτερόλεπτα |
| Αναθεώρηση μετά την ενημέρωση | Έξοδος 0; χωρίς σφάλματα ή προειδοποιήσεις |
| Οδηγός χωρίς αλλαγές | Ίδια bytes πριν και μετά την ενημέρωση του README |
| Εκτέλεση ξανά | Έξοδος 0; ίδια hashes για όλα τα αρχεία μετάφρασης |

Πρόκειται για μετρήσεις μεμονωμένων εκτελέσεων, όχι εγγυήσεις απόδοσης. Ο χρόνος ρύθμισης δεν περιλαμβάνεται; η χρέωση από τον πάροχο δεν μετρήθηκε. Μια εκτέλεση χωρίς αλλαγές μπορεί ακόμα να πραγματοποιήσει έλεγχο υγείας του παρόχου.

Εξετάστε την [αρχική μετάφραση](../../assets/demo/before.txt), την [ενημερωμένη μετάφραση](../../assets/demo/after.txt), το [πλήρες diff μετάφρασης](../../assets/demo/update.diff), την [παρωχημένη αναθεώρηση](../../assets/demo/review-stale.txt), την [τελική αναθεώρηση](../../assets/demo/review-after.txt) και τις [λεπτομέρειες εκτέλεσης](../../assets/demo/results.json). Η μετάφραση ολόκληρου αρχείου μπορεί να αλλάξει άλλες διατυπώσεις, όπως δείχνει το καταγεγραμμένο diff. Και τα δύο τεκμήρια κειμένου διατηρούν την παραχθείσα αποποίηση ευθυνών.

Η ανθρώπινη αναθεώρηση εξακολουθεί να έχει σημασία: η καταγεγραμμένη ενημέρωση χρησιμοποιεί `[사용 가이드](guide.md)을`; το κορεατικό μόριο θα έπρεπε να είναι `[사용 가이드](guide.md)를`. Τα τεκμήρια κειμένου διατηρούν αυτήν την έξοδο ανέπαφη αντί να παρουσιάσουν μια επεξεργασμένη μετάφραση ως έξοδο του μοντέλου. Η δομική αναθεώρηση περνάει παρά αυτό το ζήτημα διατυπώσεως.

## 1. Προετοιμάστε έναν μικρό φάκελο

Χρησιμοποιήστε Python 3.11–3.14 και τη [ρύθμιση εικονικού περιβάλλοντος](configuration.md#local-runtime-setup). Εγκαταστήστε την έκδοση που χρησιμοποιήθηκε για αυτό το παράδειγμα:

```bash
python -m pip install co-op-translator==0.21.0
mkdir translation-demo
cd translation-demo
git init
```

Κατεβάστε τα [README.txt](../../assets/demo/README.txt) και [guide.txt](../../assets/demo/guide.txt) σε αυτόν τον φάκελο, αποθηκεύοντάς τα ως `README.md` και `guide.md`. Είναι μικρά φανταστικά έγγραφα έργου; δεν απαιτείται εγκατάσταση εφαρμογής.

Το README περιλαμβάνει ένα μπλοκ κώδικα και έναν σύνδεσμο προς το `guide.md`. Η τελική του πρόταση είναι:

```text
Notes are saved locally.
```

Διατηρήστε μόνο αυτά τα δύο αρχεία πηγής σε αυτόν τον φάκελο. Όλες οι επόμενες εντολές τρέχουν μέσα στο `translation-demo` και λειτουργούν σε Bash και PowerShell.

## 2. Προεπισκόπηση χωρίς διαπιστευτήρια

```bash
translate -l "ko" -md --dry-run
```

Η προεπισκόπηση εκτιμά το έργο μετάφρασης χωρίς να καλεί κάποιο μοντέλο ή να γράφει μεταφράσεις. Οι εκτιμήσεις tokens δεν είναι προσφορά χρέωσης. Η πρώτη εκτέλεση θα πρέπει να εντοπίσει και τα δύο αρχεία Markdown ως νέο έργο.

## 3. Επιλέξτε πάροχο και μεταφράστε

Ρυθμίστε έναν πάροχο χρησιμοποιώντας τον [οδηγό ρύθμισης](configuration.md): Azure OpenAI, OpenAI ή Anthropic. Οι μεταφράσεις κειμένου με OpenAI και Anthropic δεν απαιτούν λογαριασμό Azure. Υπηρεσίες εικόνας δεν απαιτούνται για αυτό το παράδειγμα.

Εάν χρησιμοποιείτε τοπικό αρχείο `.env`, προσθέστε το `.env` στο `.gitignore` αυτού του φακέλου. Οι κλήσεις μετάφρασης χρησιμοποιούν τον λογαριασμό του παρόχου σας και ενδέχεται να προκαλέσουν χρεώσεις.

```bash
translate -l "ko" -md
co-op-review -l "ko"
```

Ανοίξτε τα `translations/ko/README.md` και `translations/ko/guide.md`. Ελέγξτε τη διατύπωση στα κορεατικά, το μπλοκ κώδικα και τον σύνδεσμο από το μεταφρασμένο README προς τον μεταφρασμένο οδηγό. Η διατύπωση εξόδου διαφέρει ανά μοντέλο.

`co-op-review` ελέγχει την επικαιρότητα, τη δομή και τους τοπικούς συνδέσμους. Ένα επιτυχές αποτέλεσμα δεν πιστοποιεί τη γλωσσική ακρίβεια. Επιλύστε τυχόν αναφερόμενα σφάλματα πριν συνεχίσετε.

Καταγράψτε τη επιτυχημένη βάση με το Git (ρυθμίστε πρώτα την ταυτότητα Git εάν χρειάζεται):

```bash
git add README.md guide.md translations
git commit -m "Record initial Korean translation"
```

## 4. Αλλάξτε το αρχικό αρχείο

Στο `README.md`, αντικαταστήστε το `Notes are saved locally.` με:

```text
Notes are saved locally as Markdown files.
```

Αφήστε το `guide.md` ανεπηρέαστο. Έπειτα τρέξτε:

```bash
co-op-review -l "ko"
translate -l "ko" -md --dry-run
```

Η αναθεώρηση θα πρέπει να αναφέρει ότι η μετάφραση του README είναι παρωχημένη και να τερματίσει με αποτυχία. Αυτή είναι η αναμενόμενη ενδιάμεση κατάσταση. Η προεπισκόπηση θα πρέπει να εντοπίσει εργασία για το αλλαγμένο README.

## 5. Ενημερώστε και ελέγξτε το diff

```bash
translate -l "ko" -md
git diff -- README.md translations/ko/README.md
git diff -- translations/ko/guide.md
co-op-review -l "ko"
```

Ελέγξτε το πραγματικό diff: το προεπιλεγμένο CLI επαναμεταφράζει το αρχείο που άλλαξε, έτσι ώστε το μοντέλο να μπορεί επίσης να αναθεωρήσει άλλη διατύπωση σε εκείνο το αρχείο. Ο αμετάβλητος οδηγός δεν θα πρέπει να έχει diff. Η αναθεώρηση δεν θα πρέπει πλέον να αναφέρει το README ως παρωχημένο· διερευνήστε τυχόν άλλα ευρήματα αντί να τα αγνοήσετε.

Η διατήρηση σε επίπεδο μπλοκ των ανθρώπινων επεξεργασιών Markdown απαιτεί έναν προαιρετικό πάροχο κατάστασης μετάφρασης στο [Python API](api.md). Δεν είναι ενεργοποιημένος από αυτές τις εντολές CLI.

## 6. Εκτελέστε ξανά χωρίς αλλαγές

Κάντε commit το ενημερωμένο αρχικό και τη μετάφραση:

```bash
git add README.md translations
git commit -m "Update Korean translation after source edit"
translate -l "ko" -md
git diff --exit-code -- translations
```

Με τις τρέχουσες μεταφράσεις και χωρίς αλλαγή στη ρύθμιση, ο μεταφραστής παρακάμπτει τα αρχεία. Η τελική εντολή Git δεν θα πρέπει να παράγει diff και να τερματίσει επιτυχώς.
