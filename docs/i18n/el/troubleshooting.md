# Αντιμετώπιση προβλημάτων

Χρησιμοποιήστε αυτή τη σελίδα όταν μια εκτέλεση μετάφρασης ολοκληρώνεται απροσδόκητα επιτυχώς, αποτυγχάνει κατά τη διαμόρφωση ή παράγει έξοδο που χρειάζεται αναθεώρηση.

## Ξεκινήστε εδώ

1. Εκτελέστε πρώτα μια συγκεκριμένη εντολή, για παράδειγμα `translate -l "ko" -md`.
2. Προσθέστε `-d` για αρχεία καταγραφής αποσφαλμάτωσης στην κονσόλα.
3. Προσθέστε `-s` για να αποθηκεύονται τα αρχεία καταγραφής αποσφαλμάτωσης στο `<root-dir>/logs/`.
4. Εκτελέστε `co-op-review` μετά τη μετάφραση για να ελέγξετε την επικαιρότητα, τη δομή και τους τοπικούς συνδέσμους.

```bash
translate -l "ko" -md -d -s
co-op-review -l "ko"
```

## Σφάλματα διαμόρφωσης

### Δεν υπάρχει πάροχος γλωσσικού μοντέλου

Σφάλμα:

```text
No language model configuration found.
```

Διόρθωση:

- Διαμορφώστε το Azure OpenAI, το OpenAI ή το Anthropic.
- Επιβεβαιώστε ότι οι μεταβλητές υπάρχουν στο περιβάλλον όπου εκτελείται η εντολή.
- Για τοπική χρήση, τοποθετήστε τις στο `.env` στη ρίζα του έργου.

Δείτε [Διαμόρφωση](configuration.md).

### Μετάφραση εικόνων χωρίς Azure AI Vision

Σφάλμα:

```text
Image translation requested but Azure AI Service is not configured.
```

Διόρθωση:

- Προσθέστε `AZURE_AI_SERVICE_API_KEY`.
- Προσθέστε `AZURE_AI_SERVICE_ENDPOINT`.
- Ή εκτελέστε μια εντολή μόνο με κείμενο, όπως `translate -l "ko" -md`.

### Μη έγκυρο κλειδί ή endpoint

Τα συμπτώματα μπορεί να περιλαμβάνουν `401`, αποκρυμμένα σφάλματα δικαιωμάτων ή σφάλματα πρόσβασης στο endpoint.

Διόρθωση:

- Επιβεβαιώστε ότι το κλειδί ανήκει στον ίδιο πόρο Azure με το endpoint.
- Επιβεβαιώστε ότι ο πόρος υποστηρίζει Vision όταν χρησιμοποιείτε `-img`.
- Επιβεβαιώστε ότι το όνομα της ανάπτυξης (deployment) του Azure OpenAI και η έκδοση API ταιριάζουν με την ανάπτυξή σας.
- Εκτελέστε με αρχεία καταγραφής αποσφαλμάτωσης: `translate -l "ko" -md -d -s`.

## Δεν μεταφράστηκαν αρχεία

Συνήθεις αιτίες:

- Οι επιλεγμένες σημαίες (flags) δεν ταιριάζουν με τα αρχεία σας.
- Υπάρχουν ήδη μεταφρασμένα αρχεία.
- Τα αρχεία πηγής βρίσκονται σε αποκλεισμένους καταλόγους.
- Η εντολή εκτελείται από λάθος ρίζα έργου.

Έλεγχοι:

```bash
translate -l "ko" -md --dry-run
translate -l "ko" -nb --dry-run
translate -l "ko" -img --dry-run
```

Χρησιμοποιήστε `--root-dir` όταν η εντολή εκτελείται έξω από τη ρίζα του έργου.

## Απρόσμενη συμπεριφορά συνδέσμων

Η επαναγραφή συνδέσμων εξαρτάται από τους επιλεγμένους τύπους περιεχομένου:

- `-nb` συμπεριλαμβάνεται: οι σύνδεσμοι notebook μπορούν να δείχνουν σε μεταφρασμένα σημειωματάρια.
- `-nb` εξαιρείται: οι σύνδεσμοι notebook μπορεί να παραμείνουν να δείχνουν στα αρχεία προέλευσης.
- `-img` συμπεριλαμβάνεται: οι σύνδεσμοι εικόνων μπορούν να δείχνουν σε μεταφρασμένες εικόνες.
- `-img` εξαιρείται: οι σύνδεσμοι εικόνων μπορούν να εξακολουθούν να δείχνουν στις αρχικές εικόνες.

Εκτελέστε πλήρη μετάφραση περιεχομένου όταν όλοι οι εσωτερικοί σύνδεσμοι πρέπει να προτιμούν τα μεταφρασμένα αποτελέσματα:

```bash
translate -l "ko" -md -nb -img
```

Εκτελέστε έλεγχο συνδέσμων μετά τη μετάφραση:

```bash
co-op-review -l "ko"
```

## Προβλήματα απόδοσης Markdown

Εάν το μεταφρασμένο Markdown εμφανίζεται εσφαλμένα:

- Ελέγξτε ότι το frontmatter αρχίζει και τελειώνει με `---`.
- Ελέγξτε ότι ο αριθμός των φρακτών κώδικα (code fences) ταιριάζει μεταξύ των αρχικών και των μεταφρασμένων αρχείων.
- Εκτελέστε `co-op-review` για να εντοπίσετε κοινά προβλήματα δομής.
- Μεταφράστε ξανά το συγκεκριμένο αρχείο εάν η έξοδος ήταν κατεστραμμένη.

```bash
co-op-review -l "ko" --format github
```

## Το GitHub Action εκτελέστηκε αλλά δεν δημιουργήθηκε Pull Request

Εάν το `peter-evans/create-pull-request` αναφέρει ότι το branch δεν είναι πιο μπροστά από τη βάση, η ροή εργασίας δεν βρήκε αρχεία για commit.

Πιθανές αιτίες:

- Η εκτέλεση μετάφρασης δεν παρήγαγε αλλαγές.
- Το `.gitignore` εξαιρεί τους φακέλους `translations/`, `translated_images/` ή τα μεταφρασμένα σημειωματάρια.
- Το `add-paths` δεν ταιριάζει με τους δημιουργημένους καταλόγους εξόδου.
- Το βήμα μετάφρασης τερματίστηκε νωρίς.

Διορθώσεις:

1. Επιβεβαιώστε ότι τα παραγόμενα αρχεία υπάρχουν στους φακέλους `translations/` ή `translated_images/`.
2. Επιβεβαιώστε ότι το `.gitignore` δεν αγνοεί τα παραγόμενα αρχεία εξόδου.
3. Χρησιμοποιήστε τα αντίστοιχα `add-paths`:

   ```yaml
   with:
     add-paths: |
       translations/
       translated_images/
   ```

4. Προσθέστε προσωρινά τις σημαίες αποσφαλμάτωσης στην εντολή translate:

   ```bash
   translate -l "ko" -md -d -s
   ```

5. Επιβεβαιώστε ότι τα δικαιώματα της ροής εργασίας περιλαμβάνουν:

   ```yaml
   permissions:
     contents: write
     pull-requests: write
   ```

## Ποιότητα μετάφρασης

Οι μηχανικές μεταφράσεις μπορεί να χρειάζονται ανθρώπινη αναθεώρηση. Χρησιμοποιήστε `evaluate` μόνο όταν θέλετε πειραματική βαθμολόγηση ποιότητας και ροές εργασίας επισκευής χαμηλής εμπιστοσύνης.

!!! warning "Experimental"
    Το `evaluate` μπορεί να χρησιμοποιεί ελέγχους βάσει κανόνων και ελέγχους με LLM, και το μοντέλο βαθμολόγησης και η συμπεριφορά των μεταδεδομένων του ενδέχεται να αλλάξουν. Μην το τοποθετείτε σε υποχρεωτικές πύλες CI εκτός εάν η ροή εργασίας σας είναι προετοιμασμένη για αλλαγές.

Για ντετερμινιστικούς ελέγχους CI, χρησιμοποιήστε το `co-op-review`.
