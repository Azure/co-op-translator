# Επιλέξτε τη ροή εργασίας σας

Το Co-op Translator μπορεί να χρησιμοποιηθεί με τρεις τρόπους: το CLI, το Python API και ο διακομιστής MCP. Μοιράζονται τις ίδιες δυνατότητες μετάφρασης, αλλά κάθε ένας ταιριάζει σε διαφορετική ροή εργασίας.

Χρησιμοποιήστε αυτή τη σελίδα όταν αποφασίζετε από πού να ξεκινήσετε.

**Εάν επεξεργάζεστε τις μεταφράσεις χειροκίνητα:** οι προεπιλεγμένες ροές εργασίας CLI και Actions μεταφράζουν ξανά πλήρως τα αλλαγμένα αρχεία πηγής, οπότε η διατύπωσή σας σε αυτά τα αρχεία μπορεί να αντικατασταθεί. Ελέγξτε τη διαφορά πριν αποδεχτείτε μια ενημέρωση. Για διατήρηση σε επίπεδο μπλοκ Markdown των αποδεκτών επεξεργασιών, χρησιμοποιήστε τον προαιρετικό [παροχέα κατάστασης μετάφρασης του Python API](api.md#preserve-accepted-human-edits-with-a-translation-state-provider).

## Γρήγορη Απόφαση

| --- | --- | --- |
| Μεταφράσετε ή αναθεωρήσετε ένα αποθετήριο από το τερματικό | CLI | [Αναφορά CLI](cli.md) |
| Προσθέστε μετάφραση σε ένα σενάριο Python, υπηρεσία, σημειωματάριο ή εργασία CI | Python API | [Python API](api.md) |
| Αφήστε έναν πράκτορα, επεξεργαστή ή πελάτη συμβατό με MCP να μεταφράσει περιεχόμενο για εσάς | Διακομιστής MCP | [Διακομιστής MCP](mcp.md) |
| Μεταφράσετε ένα έγγραφο Markdown, σημειωματάριο ή εικόνα που η εφαρμογή σας έχει ήδη φορτώσει | Python API ή Διακομιστής MCP | [Python API](api.md) ή [Διακομιστής MCP](mcp.md) |
| Μεταφράσετε ολόκληρο αποθετήριο με τυπικούς φακέλους εξόδου και μεταδεδομένα | CLI ή `run_translation` | [Αναφορά CLI](cli.md) ή [Python API](api.md) |

## Χρησιμοποιήστε το CLI όταν

Επιλέξτε το CLI όταν ένα άτομο ή μια εργασία CI εκτελεί τη μετάφραση αποθετηρίου από ένα shell.

Το CLI είναι ο πιο άμεσος δρόμος όταν θέλετε το Co-op Translator να εντοπίσει αρχεία έργου, να δημιουργήσει μεταφρασμένα αρχεία εξόδου, να διατηρήσει τη διάταξη του έργου, να ενημερώσει μεταδεδομένα και να εκτελέσει εντολές αναθεώρησης.

```bash
translate -l "ko" -md --dry-run
translate -l "ko" -md -nb
co-op-review -l "ko"
migrate-links -l "ko" --dry-run
```

Αυτό το παράδειγμα μεταφράζει Markdown και σημειωματάρια. Προσθέστε `-img` μόνο μετά τη ρύθμιση του [Azure AI Vision](configuration.md#azure-ai-vision). Για μια πρώτη εκτέλεση που αφορά μόνο Markdown, ακολουθήστε [Την πρώτη σας μετάφραση](first-translation.md).

Κατάλληλες περιπτώσεις:

- Μεταφράζετε ένα αποθετήριο από το τερματικό σας.
- Θέλετε μια επαναλήψιμη εντολή για ροές εργασίας CI ή κυκλοφορίας.
- Θέλετε ενσωματωμένη ανακάλυψη έργου, διαδρομές εξόδου, μεταδεδομένα, καθαρισμό και αναθεώρηση.
- Προτιμάτε διεπαφή εντολών αντί να γράφετε κώδικα Python.

## Χρησιμοποιήστε το Python API όταν

Επιλέξτε το Python API όταν ο δικός σας κώδικας πρέπει να ελέγχει τη ροή εργασίας.

Το API είναι χρήσιμο για εφαρμογές, αυτοματοποιημένα σενάρια, σημειωματάρια, υπηρεσίες και προσαρμοσμένες σωληνώσεις (pipelines). Σας επιτρέπει να καλέσετε API μετάφρασης περιεχομένου χαμηλού επιπέδου για μεμονωμένα αρχεία ή να εκτελέσετε την ίδια ορχήστρωση σε επίπεδο αποθετηρίου που χρησιμοποιεί το CLI.

Μεταφράστε ένα έγγραφο Markdown και αποφασίστε πού θα το αποθηκεύσετε:

```python
import asyncio
from pathlib import Path

from co_op_translator.api import rewrite_markdown_paths, translate_markdown_content


async def main() -> None:
    source_path = Path("docs/guide.md")
    target_path = Path("translations/ko/docs/guide.md")

    translated = await translate_markdown_content(
        source_path.read_text(encoding="utf-8"),
        "ko",
        {"source_path": source_path},
    )

    rewritten = rewrite_markdown_paths(
        translated,
        source_path=source_path,
        target_path=target_path,
    )

    target_path.parent.mkdir(parents=True, exist_ok=True)
    target_path.write_text(rewritten, encoding="utf-8")


asyncio.run(main())
```

Εκτελέστε μετάφραση αποθετηρίου από Python:

```python
from co_op_translator.api import run_translation

run_translation(
    language_codes="ko",
    markdown=True,
    notebook=True,
    images=False,
    dry_run=True,
)
```

Κατάλληλες περιπτώσεις:

- Η εφαρμογή σας ήδη διαβάζει αρχεία, buffers, σημειωματάρια ή bytes εικόνων.
- Χρειάζεστε προσαρμοσμένο έλεγχο εγκυρότητας, αποθήκευση, καταγραφή, επαναλήψεις ή ροές έγκρισης.
- Θέλετε να μεταφράσετε ένα έγγραφο, σημειωματάριο ή εικόνα χωρίς να επεξεργαστείτε ολόκληρο αποθετήριο.
- Θέλετε μετάφραση αποθετηρίου, αλλά από αυτοματοποίηση Python αντί για εντολή shell.

## Χρησιμοποιήστε τον Διακομιστή MCP όταν

Επιλέξτε τον διακομιστή MCP όταν ένας πράκτορας, επεξεργαστής ή πελάτης συμβατός με MCP πρέπει να καλεί τα εργαλεία του Co-op Translator.

Στη συνηθισμένη τοπική ρύθμιση, ο χρήστης δεν διατηρεί χειροκίνητα έναν διακομιστή σε λειτουργία. Ο πελάτης MCP ξεκινάει `co-op-translator-mcp` μέσω του `stdio` όταν χρειάζεται τα εργαλεία.

Παραδείγματα αιτημάτων χρήστη που θα μπορούσε να χειριστεί ένας πράκτορας:

- "Μεταφράστε αυτό το αρχείο Markdown στα Κορεατικά και διατηρήστε τους συνδέσμους σωστούς."
- "Μεταφράστε αυτό το αρχείο Markdown στα Κορεατικά με τη ροή εργασίας MCP με βοήθεια πράκτορα, χρησιμοποιώντας το δικό σας μοντέλο για τα μεταφρασμένα τμήματα."
- "Μεταφράστε αυτό το σημειωματάριο στα Κορεατικά, διατηρήστε τα κύτταρα κώδικα και χρησιμοποιήστε το Co-op Translator MCP για να ανασυνθέσετε το σημειωματάριο."
- "Μεταφράστε το κείμενο σε αυτή την εικόνα στα Ιαπωνικά και αποθηκεύστε το αποτέλεσμα."
- "Κάντε προσομοιωμένη εκτέλεση μετάφρασης αποθετηρίου στα Ισπανικά και πείτε μου τι θα άλλαζε."
- "Ελέγξτε αν η έξοδος μετάφρασης στα Κορεατικά είναι ενημερωμένη."

Για Markdown και σημειωματάρια, το MCP μπορεί να λειτουργήσει σε δύο λειτουργίες:

| Λειτουργία | Χρησιμοποιήστε όταν | Κύρια εργαλεία |
| --- | --- | --- |
| Με βοήθεια πράκτορα | Ο κεντρικός πράκτορας MCP πρέπει να μεταφράζει τμήματα με το δικό του μοντέλο, χωρίς τα διαπιστευτήρια παρόχου LLM του Co-op Translator. | `start_markdown_agent_translation`, `finish_markdown_agent_translation`, `start_notebook_agent_translation`, `finish_notebook_agent_translation` |
| Υποστηριζόμενο από πάροχο | Το Co-op Translator πρέπει να καλεί απευθείας το Azure OpenAI, το OpenAI ή την Anthropic. | `translate_markdown_content`, `translate_notebook_content` |

Σχήμα κλήσης εργαλείου Markdown υποστηριζόμενου από πάροχο στο MCP:

```json
{
  "tool": "translate_markdown_content",
  "arguments": {
    "document": "# Setup\n\nInstall Co-op Translator first.",
    "language_code": "ko",
    "options": {
      "source_path": "docs/setup.md"
    }
  }
}
```

Σχήμα κλήσης εργαλείου εικόνας MCP:

```json
{
  "tool": "translate_image_content",
  "arguments": {
    "image_path": "assets/architecture.png",
    "language_code": "ko",
    "output_path": "translated_images/ko/assets/architecture.png"
  }
}
```

Η μετάφραση αποθετηρίου εκτελείται προσομοιωμένα από προεπιλογή μέσω MCP:

```json
{
  "tool": "run_translation",
  "arguments": {
    "language_codes": ["ko"],
    "translate_markdown": true,
    "translate_notebooks": true,
    "translate_images": false,
    "dry_run": true
  }
}
```

Κατάλληλες περιπτώσεις:

- Θέλετε ροές εργασίας μετάφρασης σε φυσική γλώσσα μέσα σε έναν πράκτορα ή επεξεργαστή.
- Θέλετε μετάφραση Markdown ή σημειωμάτων όπου το μοντέλο του κεντρικού πράκτορα μεταφράζει προετοιμασμένα τμήματα.
- Θέλετε ο πράκτορας να μεταφράσει επιλεγμένο περιεχόμενο αντί για ολόκληρο αποθετήριο.
- Θέλετε ένα βήμα έγκρισης πριν από τις εγγραφές σε όλο το αποθετήριο.
- Θέλετε μια διεπαφή που να παρέχει εργαλεία για Markdown, σημειωματάριο, εικόνα, αναθεώρηση και επανεγγραφή διαδρομών.

## Πώς ταιριάζουν μεταξύ τους

Το CLI είναι η καλύτερη προεπιλογή για ανθρώπους που μεταφράζουν αποθετήρια. Το Python API είναι καλύτερο όταν ο κώδικάς σας ελέγχει τη ροή εργασίας. Ο διακομιστής MCP είναι καλύτερος όταν ένας πράκτορας ή επεξεργαστής ελέγχει τη ροή εργασίας.

Και οι τρεις δρόμοι χρησιμοποιούν το ίδιο δημόσιο API του Co-op Translator, επομένως μπορείτε να ξεκινήσετε με το CLI, να αυτοματοποιήσετε με Python αργότερα και να εκθέσετε τις ίδιες δυνατότητες σε πελάτες MCP όταν χρειάζεστε ροές εργασίας με καθοδήγηση πράκτορα.
