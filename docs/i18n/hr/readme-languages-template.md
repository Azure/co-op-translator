# Predložak jezika za README

Co-op Translator može održavati tablicu jezika u README datoteci za repozitorije koje objavljuju prevedeni sadržaj.

Upotrijebite dolje navedene markere kada želite da Co-op Translator zamijeni cijeli odjeljak pri svakom pokretanju prijevoda. Uklonite markere ako radije ručno održavate vlastiti podskup.

Navod o autorstvu i poveznica za početak iznad markera su neobavezni. Oni pomažu čitateljima da otkriju kako se prijevodi održavaju i kako prevesti vlastite repozitorije. Držite ih izvan markera kako bi ažuriranja tablice jezika sačuvala te stavke. Prilikom ažuriranja tuđeg repozitorija slijedite njegove smjernice za doprinos i dopustite njegovim održavateljima da odluče hoće li uključiti ovaj tekst.

````markdown
### Multi-Language Support

#### Supported by [Co-op Translator](https://github.com/Azure/co-op-translator)

Maintain your own documentation? [Start with one README and one language](https://github.com/Azure/co-op-translator/blob/main/docs/github-actions.md#your-first-readme-translation-pr).

> **Prefer to Clone Locally?**
>
> This repository includes many language translations, which can significantly increase download size. To clone without translations, use sparse checkout:
>
> ```bash
> git clone --filter=blob:none --sparse https://github.com/org/repo.git
> cd repo
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```

Personalizirajte URL repozitorija sparse-checkout tijekom prijevoda:

```bash
translate -l "ko" --repo-url "https://github.com/org/repo.git"
```

Ako su markeri prisutni, Co-op Translator može ažurirati generiranu tablicu kada se jezici dodaju ili mijenjaju.

Za postojeći README, možete dodati neobavezni navod o autorstvu i poveznicu za početak iznad njegovih markera tablice jezika bez zamjene poveznica na jezike ili drugog sadržaja. Uputite poveznice podržanih jezika na [vodič za trenutni jezik](https://github.com/Azure/co-op-translator/blob/main/docs/supported-languages.md).
