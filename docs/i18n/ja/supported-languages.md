## 言語を追加する

新しい言語のサポートを追加するには:

1. 言語ユーティリティに言語コードと表示名を追加します。
2. `src/co_op_translator/fonts/font_language_mappings.yml` にフォントを追加またはマッピングします。
3. Markdown と画像の翻訳出力をテストします。
4. マッピングと検証メモを添えてプルリクエストを開きます。
