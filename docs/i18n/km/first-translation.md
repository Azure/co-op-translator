## 1. រៀបចំថតតូច

ប្រើ Python 3.11–3.14 និង [ការតំឡើងបរិយាកាស virtual environment](configuration.md#local-runtime-setup)។ តម្លើងកំណែដែលបានប្រើសម្រាប់ឧទាហរណ៍នេះ៖

```bash
python -m pip install co-op-translator==0.21.0
mkdir translation-demo
cd translation-demo
git init
```

ទាញយក [README.txt](../../assets/demo/README.txt) និង [guide.txt](../../assets/demo/guide.txt) ទៅក្នុងថតនេះ ហើយរក្សាទុកជា `README.md` និង `guide.md`។ វាជាឯកសារគម្រោងនិទានខ្លីៗ; មិនចាំបាច់តម្លើងកម្មវិធីណាមួយឡើយ។

README រួមមានកូដប្លុកមួយ និងតំណទៅ `guide.md`។ ប្រយោគចុងក្រោយរបស់វា គឺ៖

```text
Notes are saved locally.
```

រក្សាទុកតែឯកសារប្រភពទាំងពីរនេះនៅក្នុងថតនេះ។ ពាក្យបញ្ជាទាំងអស់នៅក្រោយនេះរត់ក្នុង `translation-demo` និងអាចដំណើរការបាននៅក្នុង Bash និង PowerShell។

## 2. មើលជាមុនដោយមិនមានអាជ្ញាបណ្ណ

```bash
translate -l "ko" -md --dry-run
```

ការមើលជាមុនប៉ាន់ស្មានការងារបកប្រែដោយមិនហៅម៉ូឌែល ឬសរសេរបកប្រែ។ ការប៉ាន់ស្មាន token មិនមែនជាការបញ្ជាក់ទៅលើការគិតប្រាក់។ ការរត់ដំបូងគួរតែសម្គាល់ឯកសារ Markdown ទាំងពីរថាជាការងារថ្មី។

## 3. ជ្រើសរើសអ្នកផ្គត់ផ្គង់ និងបកប្រែ

កំណត់រចនាសម្ព័ន្ធអ្នកផ្គត់ផ្គង់មួយដោយប្រើ [មគ្គុទ្ទនៃការកំណត់](configuration.md): Azure OpenAI, OpenAI, ឬ Anthropic។ ការបកប្រែអត្ថបទជាមួយ OpenAI និង Anthropic មិនត្រូវការគណនី Azure ទេ។ សេវាកម្មរូបភាពមិនចាំបាច់សម្រាប់ឧទាហរណ៍នេះ។

ប្រសិនបើអ្នកប្រើឯកសារ `.env` ទីតាំងតាមដានក្នុងម៉ាស៊ីន បន្ថែម `.env` ទៅក្នុង `.gitignore` របស់ថតនេះ។ ការហៅសេវាបកប្រែប្រើគណនីអ្នកផ្គត់ផ្គង់របស់អ្នក និងអាចបណ្តាលឱ្យមានកម្រៃ។

```bash
translate -l "ko" -md
co-op-review -l "ko"
```

បើក `translations/ko/README.md` និង `translations/ko/guide.md`។ ពិនិត្យពាក្យភាសាកូរ៉េ កូដប្លុក និងតំណពី README ដែលបានបកប្រែរ ទៅកាន់ guide ដែលបានបកប្រែ។ សំណុំនៃពាក្យលទ្ធផលអាចខុសគ្នាតាមម៉ូឌែល។

`co-op-review` ពិនិត្យភាពថ្មី រចនាសម្ព័ន្ធ និងតំណក្នុងកន្លែង។ លទ្ធផលដែលឆ្លងកាត់មិនបានធានាថាត្រឹមត្រូវផ្នែកភាសាទេ។ ដោះស្រាយកំហុសណាមួយដែលបានរាយការណ៍មុនបន្ត។

កត់ត្រាប្លាស៊ែនដែលជោគជ័យជាមួយ Git (កំណត់អត្តសញ្ញាណ Git របស់អ្នកជាមុន ប្រសិនបើចាំបាច់)៖

```bash
git add README.md guide.md translations
git commit -m "Record initial Korean translation"
```

## 4. ប្ដូរប្រភព

នៅក្នុង `README.md` ជំនួស `Notes are saved locally.` ដោយ៖

```text
Notes are saved locally as Markdown files.
```

ទុក `guide.md` ដដែល។ បន្ទាប់មករត់៖

```bash
co-op-review -l "ko"
translate -l "ko" -md --dry-run
```

ការពិនិត្យគួរតែរាយការណ៍ថាការបកប្រែ README ធ្លាក់ចាស់ និងបញ្ចប់ដោយបរាជ័យ។ នេះគឺជាស្ថានភាពមធ្យមដែលរំពឹងទុក។ ការមើលជាមុនគួរតែសម្គាល់ការងារសម្រាប់ README ដែលបានផ្លាស់ប្តូរ។

## 5. បច្ចុប្បន្នភាព និងពិនិត្យ diff

```bash
translate -l "ko" -md
git diff -- README.md translations/ko/README.md
git diff -- translations/ko/guide.md
co-op-review -l "ko"
```

ពិនិត្យ diff ជាក់ស្តែង៖ CLI លំនាំដើមនឹងបកប្រែឡើងវិញឯកសារដែលបានផ្លាស់ប្តូរ ដូច្នេះម៉ូឌែលអាចកែសម្រួលពាក្យផ្សេងទៀតក្នុងឯកសារនោះបានផងដែរ។ មគ្គុទ្ទេសក៍ដែលមិនបានផ្លាស់ប្តូរគួរតែគ្មាន diff។ ការពិនិត្យគួរតែមិនរាយការណ៍ថា README ចាស់ឡើងវិញទេ; ស៊ើបអង្កេតលទ្ធផលផ្សេងទៀតជាជំហរមុនមិនត្រូវមើលរំលង។

ការរក្សា​កម្រិត​ប្លុក​នៃការកែសម្រួល Markdown ដោយមនុស្ស ត្រូវការអ្នកផ្គត់ផ្គង់ស្ថានភាពបកប្រែជាជម្រើសនៅក្នុង [Python API](api.md)។ វាមិនត្រូវបានបើកដោយពាក្យបញ្ជា CLI ទាំងនេះ។

## 6. រត់ម្ដងទៀតដោយគ្មានការផ្លាស់ប្តូរ

ធ្វើ commit ប្រភពដែលបានធ្វើបច្ចុប្បន្នភាព និងការបកប្រែ៖

```bash
git add README.md translations
git commit -m "Update Korean translation after source edit"
translate -l "ko" -md
git diff --exit-code -- translations
```

ជាមួយការបកប្រែបច្ចុប្បន្ន និងកំណត់រចនាសម្ព័ន្ធដែលមិនបានផ្លាស់ប្តូរ អ្នកបកប្រែ​នឹងលោតលើឯកសារ។ ពាក្យបញ្ជា Git ចុងក្រោយគួរតែបង្ហាញគ្មាន diff និងបញ្ចប់ដោយជោគជ័យ។
