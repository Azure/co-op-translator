# ការរួមចំណែកក្នុងការកែលម្អភាសា

ចំណេះដឹងភាសារបស់អ្នកអាចជួយកែលម្អ Co-op Translator។ ចាប់ផ្តើមដោយឧទាហរណ៍ មួយ ការកែសម្រួលដែលបានស្នើ និងការពន្យល់ ដោយប្រើ [សំណុំបែបបទមតិយោបល់បកប្រែ](https://github.com/Azure/co-op-translator/issues/new?template=translation_feedback.yml)। អ្នកមិនចាំបាច់ត្រូវសរសេរកូដ ឬចំណាយសម្រាប់ការរត់ម៉ូឌែលទេ។

## ពីរបាយការណ៍ទៅការកែលម្អចែករំលែក

1. អ្នករួមចំណែកផ្តល់ខ្លឹមសារ​ផ្នែកមួយពីប្រភព បកប្រែរបស់វា និងបរិបទ។
2. អ្នកពិនិត្យភាសាប្រឡូកអត្ថន័យ ភាពធម្មជាតិ និងថាតើការផ្តល់យោបល់ពឹងផ្អែកលើទីកន្លែងជាក់លាក់ ឬវគ្គសិក្សាណាមួយទេ។
3. អ្នកថែទាំសម្រេចថាតើការជួសជុលនោះគួរពាក់ព័ន្ធនៅក្នុងវគ្គប្រភព មន្ត្រីណែនាំភាសាចែករំលែក ការកំណត់ពាក្យ ឬកូដបកប្រែ។
4. សម្រាប់ច្បាប់ចែករំលែក អ្នកថែទាំនឹងប្រៀបធៀបលទ្ធផលមុននិងក្រោយការផ្លាស់ប្តូរនៅលើឧទាហរណ៍ដែលរាយការណ៍ និងឧទាហរណ៍ផ្សេងទៀតដែលមិនបានទាក់ទង។ អ្នករួមចំណែកអាចពិនិត្យលទ្ធផលទាំងនេះបានដោយមិនចាំបាច់រត់ឧបករណ៍ដោយខ្លួនឯង។
5. PR ដែលទទួលបាន នឹងភ្ជាប់របាយការណ៍ និងផ្តល់កិត្តិយសដល់មនុស្សដែលបានផ្ដល់ឧទាហរណ៍ និងបានពិនិត្យ។ ការដាក់បញ្ចូន ឬការបង្កើតឡើងវិញនៅក្នុងឃ្លាំងកូដដែលប្រើប្រាស់គឺជជំហានផ្សេងទៀត។

របាយការណ៍មិនបម្លែងសំណើឬបង្កើតការបកប្រែវគ្គឡើងវិញដោយស្វ័យប្រវត្តិទេ។ ការកែប្រែជាវគ្គជាក់លាក់គួរទុកភ្ជាប់ទៅនឹងឃ្លាំងវគ្គនោះ។ កុំសន្មត់ថាការកែដោយដៃនឹងនៅរស់ក្រោយការបកប្រែម្ដងទៀត—សូមបញ្ជាក់ភាពពាក់ព័ន្ធនៃដំណើរការនោះ។

## ឧទាហរណ៍ដែលមានរួចហើយ៖ តំណ Markdown ភាសាជប៉ុន

ឯកសារ [ឯកសារណែនាំភាសាជប៉ុន](https://github.com/Azure/co-op-translator/blob/main/src/co_op_translator/templates/language/ja.md) បញ្ជាក់ទៅម៉ូឌែលឲ្យបកប្រែអត្ថបទតំណ ខណៈដែលរក្សាស្យនតិច (Markdown syntax) និងគោលដៅតំណ។ ឧទាហរណ៍ តំណដែលសរសេរជា `[text](URL)` មិនគួរប្រើទ្រង់ទ្រាយជាបន្ទាត់ជប៉ុន `「text」（URL）` ទេ។

នេះជាឧទាហរណ៍ផ្តោតលើច្បាប់ភាសាមួយ ដែលបានគាំទ្រដោយការបង្ហាញលទ្ធផលត្រឹមត្រូវ និងមិនត្រឹមត្រូវ។ វាមិនមែនជាភស្តុតាងថានែនាំសំណើដោយខ្លួនឯងធានាលទ្ធផល Markdown ត្រឹមត្រូវទេ។

ឧបករណ៍ [ឧបករណ៍បង្កើតសំណើ Markdown](https://github.com/Azure/co-op-translator/blob/main/src/co_op_translator/utils/markdown/prompts.py) យក `templates/language/<language_code>.md` ដោយប្រើកូដភាសាដែលអក្សរតូច និងកាត់ចេញ។ ប្រសិនបើមិនមានឯកសារ វានឹងប្រើការណែនាំទូទៅ។ នេះពណ៌នាផ្លូវសំណើ Markdown; កុំសន្មត់ថារូបភាព ឬផ្លូវបកប្រែផ្សេងទៀតទាំងអស់ប្រើការណែនាំដូចគ្នា។

ការធ្វើតេស្ត [prompt tests](https://github.com/Azure/co-op-translator/blob/main/tests/co_op_translator/utils/markdown/test_prompts.py) ពិនិត្យថានែនាំជប៉ុនត្រូវបានរួមបញ្ចូល។ នេះបញ្ជាក់ពីការរួមបញ្ចូលសំណើ មិនមែនគុណភាពបកប្រែ។

## តើអ្វីខ្លះដែលត្រូវនៅក្នុងច្បាប់ភាសា?

សូមស្នើការកែសម្រួលជារបៀបច្បាស់ និងអាចធ្វើឡើងម្ដងទៀត មានឧទាហរណ៍ប្រភព ការរំពឹងពីអាកប្បកិរិយា និងឧទាហរណ៍ប្រឆាំងដែលច្បាប់មិនគួរអនុវត្ត។ រក្សាអត្ថន័យ កន្លែងដាក់ទិន្នន័យ កូដ URL និងរចនាសម្ព័ន្ធឯកសារ។ ជៀសវាងការបម្លែងចំណង់ចំណូលរបស់នរណាម្នាក់ ឬពាក្យវចនានុក្រមរបស់វគ្គមួយទៅជាច្បាប់សកល។

ការអនុវត្ត [ការអនុវត្តវចនានុក្រម](https://github.com/Azure/co-op-translator/blob/main/src/co_op_translator/glossary.py) បច្ចុប្បន្នការពារពាក្យពីការបកប្រែ។ វាមិនមែនជាធាតុវិចារណកថាពាក្យពីប្រភពទៅគោលដៅទេ។ ពិភាក្សាអំពីរបៀបអនុវត្តពាក្យថ្មីមុនពេលសន្យាចំពោះអ្នករួមចំណែក។

## ឧទាហរណ៍សហគមន៍៖ របាយការណ៍ឈ្មោះផលិតផលជប៉ុន

ក្នុង [របាយការណ៍ #527](https://github.com/Azure/co-op-translator/issues/527) @hyoshioka0128 បានសម្គាល់ការបកប្រែជប៉ុនដែលបានបម្លែងឈ្មោះផលិតផល `Co-op Translator` ទៅជា `Co-op 翻訳`។ របាយការណ៍មានតំណទៅឯកសារដែលខូច និងរូបថតអេក្រង់ ដែលធ្វើឲ្យងាយសម្រាប់រកបញ្ហា។

អ្នករួមចំណែកក៏បានភ្ជាប់ [PR វគ្គដែលទាក់ទង](https://github.com/microsoft/AZD-for-beginners/pull/109)។ ក្នុងការពិភាក្សាបញ្ហា អ្នកថែទាំបានទទួលស្គាល់របាយការណ៍ និងបានស្នើឱ្យស៊ើបអង្កេតមូលហេតុដែលឈ្មោះបានផ្លាស់ប្តូរ រួមទាំងការការពារបណ្តាញពាក្យ របៀបប្រតិបត្តិវចនានុក្រម និងផ្លូវបកប្រែ។

នេះបង្ហាញពីវិធីដែលរបាយការណ៍តូចអាចជួយគាំទ្រការស៊ើបអង្កេតលើសពីការកែសម្រួលពាក្យមួយ។ វាមិនមែនជាលទ្ធផលបានផ្ទៀងផ្ទាត់មុន/ក្រោយ ឬភស្តុតាងថានែនាំ Markdown-link ជប៉ុនខាងលើបានដោះស្រាយបញ្ហាឈ្មោះផលិតផលនេះទេ។

អ្នកអាចរួមចំណែកដូចគ្នា៖ ចែករំលែកអត្ថបទដើម ការបកប្រែបច្ចុប្បន្ន ការកែសម្រួលដែលបានស្នើ និងហេតុផលដែលវាសំខាន់។ បន្ថែមតំណឯកសារ ឬរូបថតអេក្រង់ពេលមានប្រយោជន៍។ អ្នកមិនចាំបាច់ត្រូវវាយតម្លៃមូលហេតុ ឬសរសេរសំណើមុននឹងរាយការណ៍ទេ។

## ការផ្ទៀងផ្ទាត់មុនទទួលយកច្បាប់
