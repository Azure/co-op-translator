## បន្ថែមភាសា

ដើម្បីបន្ថែមការគាំទ្រសម្រាប់ភាសាថ្មី៖

1. បន្ថែមកូដភាសា និងឈ្មោះបង្ហាញទៅក្នុងឧបករណ៍ជំនួយភាសា។
2. បន្ថែម ឬផ្គូផ្គងអក្សរមួយនៅក្នុង `src/co_op_translator/fonts/font_language_mappings.yml`។
3. សាកល្បងលទ្ធផលបកប្រែ Markdown និងរូបភាព।
4. បើក pull request ដែលមានផែនទី និងកំណត់ចំណាំការផ្ទៀងផ្ទាត់។
