# CLI ಉಲ್ಲೇಖ

Co-op Translator ಇವು ಕೆಳಗಿನ ಕಮಾಂಡ್-ಲೈನ್ ಎಂಟ್ರಿ ಪಾಯಿಂಟ್‌ಗಳನ್ನು ಸ್ಥಾಪಿಸುತ್ತದೆ:

- `translate`
- `evaluate`
- `migrate-links`
- `co-op-review`
- `co-op-translator-mcp`

`translate`, `evaluate`, `migrate-links`, ಮತ್ತು `co-op-review` ಕಮಾಂಡ್‌ಗಳನ್ನು `co_op_translator.__main__` ಮೂಲಕ ಡಿಸ್ಪ್ಯಾಚ್ ಮಾಡಲಾಗುತ್ತದೆ, ಅದು ಕರೆಮಾಡಿದ ಸ್ಕ್ರಿಪ್ಟ್ ಹೆಸರಿನ ಆಧಾರದ ಮೇಲೆ ಕಮಾಂಡ್ ಅನುಷ್ಠಾನವನ್ನು ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ. MCP ಸರ್ವರ್ ನೇರವಾಗಿ `co_op_translator.mcp.server` ಅನ್ನು ಬಳಸುತ್ತದೆ.

ನೀವು CLI, Python API, ಮತ್ತು MCP ನಡುವೆ ನಿರ್ಧಾರ ಮಾಡುತ್ತಿದ್ದರೆ, [ನಿಮ್ಮ ಕಾರ್ಯಪ್ರವಾಹವನ್ನು ಆರಿಸಿ](workflows.md) ನಿಂದ ಪ್ರಾರಂಭಿಸಿ.

## ಕಾನ್ಸೋಲ್ ಔಟ್‌ಪುಟ್

ಇಂಟರಾಕ್ಟಿವ್ ಟರ್ಮಿನಲ್‌ಗಳು ಕಮಾಂಡ್ ಶೀರ್ಷಿಕೆ, ಪ್ರಗತಿ, ಮತ್ತು ಸಾರಾಂಶಗಳಿಗಾಗಿ Rich ಫಾರ್ಮ್ಯಾಟಿಂಗ್ ಅನ್ನು ಬಳಸುತ್ತವೆ. CI ಮತ್ತು ನಾನ್-ಇಂಟರಾಕ್ಟಿವ್ ಔಟ್‌ಪುಟ್‌ಗಳು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸಾದಾ ಪಠ್ಯಕ್ಕೆ ಹಿಂದಿರುಗುತ್ತವೆ.

ಸರಳ ಔಟ್‌ಪುಟ್ ಅನ್ನು ಬಲವಂತಗೊಳಿಸಲು `CO_OP_TRANSLATOR_OUTPUT_STYLE=plain` ಅನ್ನು ಸೆಟ್ ಮಾಡಿ, ಅಥವಾ ಸಮೃದ್ಧ ಔಟ್‌ಪುಟ್ ಅನ್ನು ಬಲವಂತಗೊಳಿಸಲು `CO_OP_TRANSLATOR_OUTPUT_STYLE=rich` ಅನ್ನು ಸೆಟ್ ಮಾಡಿ. ಲೈವ್ ಪ್ರಗತಿ ಬಾರ್‌ಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುವಾಗ ಸಾರಾಂಶಗಳನ್ನು ಉಳಿಸಲು `CO_OP_TRANSLATOR_NO_PROGRESS=1` ಅನ್ನು ಸೆಟ್ ಮಾಡಿ.

ಮತ್ತೊಂದು ಸಿಸ್ಟಮ್‌ಗೆ ಅವಶ್ಯಕತೆ ಇದ್ದಾಗ `translate --json-events progress.ndjson` ಅನ್ನು ಬಳಸಿ
ಯಂತ್ರ-ಓದುವಂತೆ ಇರುವ ಪ್ರಗತಿ. CLI ಮಾನವ-ಮುಖಿ ಔಟ್‌ಪುಟ್ ಅನ್ನು ಮುಂದುವರೆಸುತ್ತಿದ್ದು,
NDJSON ಫೈಲ್ ಆವೃತ್ತಿ ಹೊಂದಿರುವ `co-op.translation.event.v1` ಘಟನೆಗಳನ್ನು ಸ್ವೀಕರಿಸುತ್ತದೆ ಮತ್ತು
ಸ್ಥಿರ ಕ್ಷೇತ್ರಗಳಂತಹ `type`, `stage_key`, `completed`, `total`, ಮತ್ತು
`current_path`.

## ಮೊದಲ ಬಾರಿಗೆ CLI ಹರಿವು

ಟರ್ಮಿನಲ್‌ನಿಂದ Co-op Translator ಬಳಸುತ್ತಿದ್ದರೆ ಇಲ್ಲಿ ಪ್ರಾರಂಭಿಸಿ:

1. [ಕಾನ್ಫಿಗರೇಶನ್](configuration.md) ನಲ್ಲಿ ವಿವರಿಸಿದಂತೆ LLM ಪ್ರೊವೈಡರ್ ಅನ್ನು ಸಂರಚಿಸಿ.
2. ನೀವು ಭಾಷಾಂತರಿಸಬೇಕಾದ ವಿಷಯದ ಪ್ರಕಾರವನ್ನು ಆಯ್ಕೆಮಾಡಿ.
3. ಮೊದಲಿಗೆ ವಿಶೇಷಿತ ಕಮಾಂಡ್ ಓಡಿಸಿ, ಉದಾಹರಣೆಗೆ ಕೇವಲ Markdown ಭಾಷಾಂತರ.
4. ದೊಡ್ಡ ರೆಪೊಸಿಟರಿ ಬದಲಾವಣೆಗಳ ಮುನ್ನ `--dry-run` ಬಳಸಿ.
5. ಭಾಷಾಂತರದ ನಂತರ ರಚನೆ ಮತ್ತು ತಾಜಾಗಿರುವಿಕೆ ಪರಿಶೀಲಿಸಲು `co-op-review` ಅನ್ನು ಬಳಸಿ.

| ಗುರಿ | ಪ್ರಾರಂಭಿಸಲು ಕಮಾಂಡ್ |
| --- | --- |
| Markdown ದಸ್ತಾವೇಜುಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ | `translate -l "ko" -md` |
| ನೋಟ್‌ಬುಕ್‌ಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ | `translate -l "ko" -nb` |
| ಚಿತ್ರ ಪಠ್ಯವನ್ನು ಭಾಷಾಂತರಿಸಿ | `translate -l "ko" -img` |
| ಫೈಲ್‌ಗಳನ್ನು ಬರೆಯದೇ ಕೆಲಸವನ್ನು ಪೂರ್ವವೀಕ್ಷಣೆ ಮಾಡಿ | `translate -l "ko" -md --dry-run` |
| ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಭಾಷಾಂತರಗಳನ್ನು ವಿಮರ್ಶಿಸಿ | `co-op-review -l "ko"` |
| ನೋಟ್‌ಬುಕ್ ಮತ್ತು Markdown ಲಿಂಕ್‌ಗಳನ್ನು ನವೀಕರಿಸಿ | `migrate-links -l "ko" --dry-run` |
| ಉಪಕರಣಗಳನ್ನು MCP ಕ್ಲೈಂಟ್‌ಗೆ ಮುಕ್ತಗೊಳಿಸಿ | CLI ಕಮಾಂಡ್‌ಗಳನ್ನು ನೇರವಾಗಿ 실행 ಮಾಡುವ ಬದಲು [MCP ಸರ್ವರ್](mcp.md) ಅನ್ನು ಸಂರಚಿಸಿ. |

## translate

Markdown ಫೈಲ್‌ಗಳು, ನೋಟ್‌ಬುಕ್‌ಗಳು, ಮತ್ತು ಚಿತ್ರ ಪಠ್ಯವನ್ನು ಒಂದು ಅಥವಾ ಹೆಚ್ಚು ಗುರಿ ಭಾಷೆಗಳಿಗೆ ಅನುವಾದಿಸಿ.

```bash
translate -l "ko ja fr"
```

### ಸಾಮಾನ್ಯ ಉದಾಹರಣೆಗಳು

ಕೇವಲ Markdown ಅನ್ನು ಭಾಷಾಂತರಿಸಿ:

```bash
translate -l "de" -md
```

ಕೇವಲ ನೋಟ್‌ಬುಕ್‌ಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ:

```bash
translate -l "zh-CN" -nb
```

Markdown ಮತ್ತು ಚಿತ್ರಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ:

```bash
translate -l "pt-BR" -md -img
```

ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಭಾಷಾಂತರಗಳನ್ನು ಅಳಿಸಿ ಮತ್ತೆ ಸೃಷ್ಟಿಸುವ ಮೂಲಕ ನವೀಕರಿಸಿ:

```bash
translate -l "ko" -u
```

ಇಂಟರಾಕ್ಟಿವ್ ಪ್ರಾಂಪ್ಟ್‌ಗಳಿಲ್ಲದೇ ಓಡಿಸಿ:

```bash
translate -l "ko ja" -md -y
```

ಲಾಗ್‌ಗಳನ್ನು ಉಳಿಸಿ:

```bash
translate -l "ko" -s
```

ರಚನಾತ್ಮಕ ಪ್ರಗತಿ ಘಟನೆಗಳನ್ನು ಬರೆಯಿರಿ:

```bash
translate -l "ko ja" -md --json-events progress.ndjson
```

### ಆಯ್ಕೆಗಳು

| ಆಯ್ಕೆ | ಅಗತ್ಯವೇ | ವಿವರಣೆ |
| --- | --- | --- |
| `-l`, `--language-codes` | ಹೌದು | ಖಾಲಿ (space) ಮೂಲಕ ಬೇರ್ಪಡಿಸಿದ ಭಾಷಾ ಕೋಡ್‌ಗಳು, ಉದಾಹರಣೆಗೆ `"es fr de"`, ಅಥವಾ `"all"`. |
| `-r`, `--root-dir` | ಇಲ್ಲ | ಪ್ರಾಜೆಕ್ಟ್ ರೂಟ್. ಡೀಫಾಲ್ಟ್ ಪ್ರಸ್ತುತ ಡೈರೆಕ್ಟರಿ. |
| `-u`, `--update` | ಇಲ್ಲ | ಆಯ್ಕೆಮಾಡಿದ ಭಾಷೆಗಳ ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಭಾಷಾಂತರಗಳನ್ನು ಅಳಿಸಿ ಮರುಸೃಷ್ಟಿಸಿ. |
| `-img`, `--images` | ಇಲ್ಲ | ಕೇವಲ ಚಿತ್ರ ಫೈಲ್‌ಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ. |
| `-md`, `--markdown` | ಇಲ್ಲ | ಕೇವಲ Markdown ಫೈಲ್‌ಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ. |
| `-nb`, `--notebook` | ಇಲ್ಲ | ಕೇವಲ Jupyter ನೋಟ್‌ಬುಕ್ ಫೈಲ್‌ಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ. |
| `-d`, `--debug` | ಇಲ್ಲ | ಕಾನ್ಸೋಲ್‌ನಲ್ಲಿ ಡೀಬಗ್ ಲಾಗಿಂಗ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿ. |
| `-s`, `--save-logs` | ಇಲ್ಲ | DEBUG-ಮಟ್ಟದ ಲಾಗ್‌ಗಳನ್ನು `<root-dir>/logs/` ಅಡಿಯಲ್ಲಿ ಉಳಿಸಿ. |
| `--json-events` | ಇಲ್ಲ | ಯಂತ್ರ-ಓದುವ ಸಾಧ್ಯವಾದ ಪ್ರಗತಿ ಘಟನೆಗಳನ್ನು NDJSON ಆಗಿ ಬರೆಯಿರಿ. |
| `-x`, `--fix` | ಇಲ್ಲ | ಹಿಂದಿನ ಮೌಲ್ಯಮಾಪನ ಫಲಿತಾಂಶಗಳ ಆಧಾರದ ಮೇಲೆ ಕಡಿಮೆ-ಆತ್ಮವಿಶ್ವಾಸ Markdown ಫೈಲ್‌ಗಳನ್ನು ಮರುಭಾಷಾಂತರಿಸಿ. |
| `-c`, `--min-confidence` | ಇಲ್ಲ | `--fix` ಗಾಗಿ ಆತ್ಮವಿಶ್ವಾಸ ಗಡಿ. ಡೀಫಾಲ್ಟ್ `0.7`. |
| `--add-disclaimer`, `--no-disclaimer` | ಇಲ್ಲ | ಯಂತ್ರ ಭಾಷಾಂತರ ಡಿಸ್ಕ್ಲೈಮರ್‌ಗಳನ್ನು ಸೇರಿಸುವ ಅಥವಾ ತಡೆಮಾಡುವ. CLI ನಲ್ಲಿ ಡೀಫಾಲ್ಟ್ ಆಗಿ ಸಕ್ರಿಯವಾಗಿದೆ. |
| `-f`, `--fast` | ಇಲ್ಲ | ತ್ವರಿತ ಚಿತ್ರ ಮೋಡ್ (ಬಳಕೆ ನಿಲ್ಲಿಸಲಾಗಿದೆ). |
| `-y`, `--yes` | ಇಲ್ಲ | ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ದೃಢೀಕರಿಸಿ, CI ಯಲ್ಲಿ ಉಪಯುಕ್ತ. |
| `--repo-url` | ಇಲ್ಲ | README ಭಾಷಾ ಟೇಬಲಿನ sparse-checkout ಸಲಹೆಯಲ್ಲಿ ಬಳಸಲಾಗುವ Repository URL. |
| `--migrate-language-folders` | ಇಲ್ಲ | ಹಳೆ ಅಲಿಯಾಸ್ ಫೋಲ್ಡರ್‌ಗಳನ್ನು, ಉದಾ. `cn` ಅಥವಾ `tw`, canonical BCP 47 ಫೋಲ್ಡರ್‌ಗಳಿಗೆ ಮರುಹೆಸರಿಸಿ. |
| `--dry-run` | ಇಲ್ಲ | ಫೈಲ್‌ಗಳನ್ನು ಬರೆಯದೆ ಭಾಷಾ ಫೋಲ್ಡರ್ ವಲಸೆ ಹಾಗೂ ಭಾಷಾಂತರ ಅಂದಾಜುಗಳನ್ನು ಪೂರ್ವವೀಕ್ಷಿಸಿ. |

ಯಾವುದೇ ಟೈಪ್ ಫ್ಲಾಗ್ ನೀಡದಿದ್ದರೆ, `translate` Markdown, ನೋಟ್ಬುಕ್‌ಗಳು ಮತ್ತು ಚಿತ್ರಗಳನ್ನು ಪ್ರಕ್ರಿಯೆ ಮಾಡುತ್ತದೆ. ಚಿತ್ರಗಳ ಅನುವಾದಕ್ಕೆ Azure AI Vision ಕಾನ್ಫಿಗರೇಷನ್ ಅಗತ್ಯವಿದೆ.

## evaluate

ಒಂದು ಭಾಷೆಗೆ ಅನುವಾದಿಸಿದ Markdown ಗುಣಮಟ್ಟವನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡಿ.

!!! warning "ಪ್ರಯೋಗಾತ್ಮಕ"
    `evaluate` ಪ್ರಯೋಗಾತ್ಮಕವಾಗಿದೆ. ಇದು ನಿಯಮ-ಆಧಾರಿತ ಮತ್ತು LLM-ಆಧಾರಿತ ಗುಣಮಟ್ಟ ಪರಿಶೀಲನೆಗಳನ್ನು ಬಳಸಬಹುದು, ಮೌಲ್ಯಮಾಪನ ಫಲಿತಾಂಶಗಳನ್ನು ಅನುವಾದ ಮೆಟಾಡೇಟಾದಲ್ಲಿ ಬರೆಯುತ್ತದೆ, ಮತ್ತು ಅದರ ಸ್ಕೋರ್ ಮಾದರಿ ಮತ್ತು ಮೆಟಾಡೇಟಾ ವರ್ತನೆ ಬದಲಾಗಬಹುದು.

```bash
evaluate -l "ko"
```

### ಸಾಮಾನ್ಯ ಉದಾಹರಣೆಗಳು

ಇನ್ನಷ್ಟು ಕಟ್ಟುಕಟ್ಟು ಕಡಿಮೆ-ಆತ್ಮವಿಶ್ವಾಸ ಗಡಿಯನ್ನು ಬಳಸಿ:

```bash
evaluate -l "es" -c 0.8
```

ಕೇವಲ ನಿಯಮ-ಆಧಾರಿತ ಪರಿಶೀಲನೆಗಳನ್ನು ಓಡಿಸಿ:

```bash
evaluate -l "fr" -f
```

ಕೇವಲ LLM-ಆಧಾರಿತ ಪರೀಕ್ಷೆಗಳನ್ನು ಓಡಿಸಿ:

```bash
evaluate -l "ja" -D
```

### ಆಯ್ಹೆಗಳು

| ಆಯ್ಕೆ | ಅಗತ್ಯವೇ | ವಿವರಣೆ |
| --- | --- | --- |
| `-l`, `--language-code` | ಹೌದು | ಮೌಲ್ಯಮಾಪನಕ್ಕೆ ಏಕ ಭಾಷಾ ಕೋಡ್. ಅಲಿಯಾಸ್ ಕೋಡ್‌ಗಳನ್ನು ಸಾಮಾನ್ಯೀಕರಿಸಲಾಗುತ್ತದೆ. |
| `-r`, `--root-dir` | ಇಲ್ಲ | ಪ್ರಾಜೆಕ್ಟ್ ರೂಟ್. ಡೀಫಾಲ್ಟ್ ಪ್ರಸ್ತುತ ಡೈರೆಕ್ಟರಿ. |
| `-c`, `--min-confidence` | ಇಲ್ಲ | ಕಡಿಮೆ-ಆತ್ಮವಿಶ್ವಾಸ ಅನುವಾದಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುವಾಗ ಬಳಸುವ ಗಡಿ. ಡೀಫಾಲ್ಟ್ `0.7`. |
| `-d`, `--debug` | ಇಲ್ಲ | ಡೀಬಗ್ ಲಾಗಿಂಗ್ ಸಕ್ರಿಯಗೊಳಿಸಿ. |
| `-s`, `--save-logs` | ಇಲ್ಲ | DEBUG-ಮಟ್ಟದ ಲಾಗ್‌ಗಳನ್ನು `<root-dir>/logs/` ಅಡಿಯಲ್ಲಿ ಉಳಿಸಿ. |
| `-f`, `--fast` | ಇಲ್ಲ | ಕೇವಲ ನಿಯಮ-ಆಧಾರಿತ ಮೌಲ್ಯಮಾಪನ. |
| `-D`, `--deep` | ಇಲ್ಲ | ಕೇವಲ LLM-ಆಧಾರಿತ ಮೌಲ್ಯಮಾಪನ. |

ಡೀಫಾಲ್ಟ್‌ಗಾಗಿ, `evaluate` ನಿಯಮಾಧಾರಿತ ಮತ್ತು LLM-ಆಧಾರಿತ ಎರಡೂ ಮೌಲ್ಯಮಾಪನಗಳನ್ನು ಬಳಸುತ್ತದೆ. ಫಲಿತಾಂಶಗಳನ್ನು ಅನುವಾದ ಮೆಟಾಡೇಟಾದಲ್ಲಿ ಬರೆಯಲಾಗುತ್ತದೆ ಮತ್ತು ಕನ್‌ಸೋಲ್‌ನಲ್ಲಿ ಸಾರಾಂಶವಾಗಿ ತೋರಿಸಲಾಗುತ್ತದೆ.

## co-op-review

API ಪ್ರಮಾಣಪತ್ರಗಳಿಲ್ಲದೇ ನಿರ್ಧಾರಾತ್ಮಕ ಅನುವಾದ ನಿರ್ವಹಣೆ ತಪಾಸಣೆಗಳನ್ನು ನಡೆಸಿ.

!!! note "ಬೆಟಾ"
    `co-op-review` ಒಂದು ಬೆಟಾ ನಿರ್ಧಾರಾತ್ಮಕ ವಿಮರ್ಶೆ ಕಮಾಂಡ್ ಆಗಿದೆ. ಇದು ಮಾದರಿ ಪೂರೈಕೆದಾರರನ್ನು ಕರೆಯುವುದಿಲ್ಲ ಅಥವಾ ಫೈಲ್‌ಗಳನ್ನು ಬರೆಯುವುದಿಲ್ಲ, ಆದರೆ ಅದರ ತಪಾಸಣೆಗಳು ಮತ್ತು ಸಮಸ್ಯೆ ಔಟ್‌ಪುಟ್ ಸ್ಕೀಮಾ ಅಭಿವೃದ್ಧಿ ಹೊಂದಬಹುದು.

```bash
co-op-review -l "ko"
```

### ಸಾಮಾನ್ಯ ಉದಾಹರಣೆಗಳು

ಪ್ರಸ್ತುತ ಡೈರೆಕ್ಟರಿಯಿಂದ ಕೊರಿಯನ್ ಮತ್ತು ಜಪಾನೀಸ್ ಭಾಷಾಂತರಗಳನ್ನು ವಿಮರ್ಶಿಸಿ:

```bash
co-op-review -l "ko ja"
```

ನಿರ್ದಿಷ್ಟ ಪ್ರಾಜೆಕ್ಟ್ ರೂಟ್ ಅನ್ನು ವಿಮರ್ಶಿಸಿ:

```bash
co-op-review -l "fr" -r ./my-course
```

README-ಮಾತ್ರ ಅನುವಾದದ ನಂತರ ಕೇವಲ README ಅನ್ನು ವಿಮರ್ಶಿಸಿ:

```bash
translate -l "ko" --readme-only -y
co-op-review -l "ko" --readme-only --format github
```

`--readme-only` ಇತರೆ ದಾಖಲೆಗಳು ಮತ್ತು ನೆಸ್ಟೆಡ್ README ಗಳನ್ನು ನಿರ್ಲಕ್ಷಿಸುತ್ತದೆ. ಇದು ವಿಫಲವಾಗುತ್ತದೆ যদি ರೂಟ್
`README.md` ಕಾಣೆಯಾಗಿದ್ದರೆ. `--changed-from` ಜೊತೆಗೆ ಒಟ್ಟುಗೂಡಿಸಿದರೆ, ಅದು README ಮಾತ್ರ ವಿಮರ್ಶೆ ಮಾಡುತ್ತದೆ
ಆ ಮೂಲ ಫೈಲ್ ಬದಲಾಗಿದ್ದಾಗ. README-ಮಾತ್ರ ಅನುವಾದ ಮೂಲ README ಅನ್ನು
ಬದಲಿಸಲಾಗದೆ, ಯಾವುದೇ ಹಂಚಿಕೊಂಡ ವಿಭಾಗ ಚಿಹ್ನೆಗಳನ್ನು ಸೇರಿಸಿ.

ಆಧಾರ ರೆಫ್ ವಿರುದ್ಧ ಬದಲಾಗಿದೆ ಎಂದು ಗುರುತಿಸಲಾದ ಮೂಲ ಫೈಲ್‌ಗಳನ್ನು ಮಾತ್ರ ವಿಮರ್ಶಿಸಿ:

```bash
co-op-review -l "ko" --changed-from origin/main
```

CI ಸಾರಾಂಶಗಳಿಗಾಗಿ GitHub-ವೈಶಿಷ್ಟ್ಯಗೊಳಿಸಿದ Markdown ಔಟ್‌ಪುಟ್ ಅನ್ನು ಮುದ್ರಿಸಿ:

```bash
co-op-review -l "ko ja" --changed-from origin/main --format github
```

### ಆಯ್ಕೆಗಳು

| ಆಯ್ಕೆ | ಅಗತ್ಯವೇ | ವಿವರಣೆ |
| --- | --- | --- |
| `-l`, `--language-code` | ಇಲ್ಲ | ವಿಮರ್ಶೆ ಮಾಡಲು ಭಾಷಾ ಕೋಡ್. ಇದನ್ನು ಬಹುಮಾರಿಗೆ ಅಥವಾ space ಮೂಲಕ ಬೇರ್ಪಡಿಸಿದ ಮೌಲ್ಯವಾಗಿ ನೀಡಬಹುದು. ಡೀಫಾಲ್ಟ್ ಎಲ್ಲಾ ಪತ್ತೆಯಾದ ಅನುವಾದ ಭಾಷೆಗಳಿಗೆ. |
| `-r`, `--root-dir` | ಇಲ್ಲ | ಪ್ರಾಜೆಕ್ಟ್ ರೂಟ್. ಡೀಫಾಲ್ಟ್ ಪ್ರಸ್ತುತ ಡೈರೆಕ್ಟರಿ. |
| `--changed-from` | ಇಲ್ಲ | ವಿಮರ್ಶೆಯನ್ನು ಬದಲಾಗಿರುವ ಮೂಲ ಫೈಲ್‌ಗಳಿಗೆ ಸೀಮಿತಗೊಳಿಸಲು ಬಳಸುವ Git ರೆಫ್. |
| `--readme-only` | ಇಲ್ಲ | ಮೂಲ `README.md` ಅನುವಾದವನ್ನು ಮಾತ್ರ ವಿಮರ್ಶಿಸಿ. |
| `--format` | ಇಲ್ಲ | ಔಟ್‌ಪುಟ್ ಸ್ವರೂಪ: `text` ಅಥವಾ `github`. ಡೀಫಾಲ್ಟ್ `text`. |

`co-op-review` ಸದ್ಯದಲ್ಲಿ ಕಳೆದುಹೋಗಿರುವ ಅನುವಾದಿತ ಫೈಲ್‌ಗಳು, ಕಾಣೆಯಾಗಿದ್ದ ಅಥವಾ ಕಾಲಹರಣಗೊಂಡ ಅನುವಾದ ಮೆಟಾಡೇಟಾ, Markdown frontmatter ಮತ್ತು ಕೋಡ್ ಫೆನ್ಸ್ ಸಮಗ್ರತೆ, ಅಮಾನ್ಯ ಅನುವಾದಿತ ನೋಟ್‌ಬುಕ್ JSON, ಮತ್ತು ಕಳೆದುಹೋಗಿದ ಸ್ಥಳೀಯ Markdown ಅಥವಾ ಚಿತ್ರ ಲಿಂಕ್ ಗುರಿಗಳನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ. ಕಳೆದುಹೋಗಿದ ಲಿಂಕ್‌ಗಳು ಡೀಫಾಲ್ಟ್‌ನಲ್ಲಿ ಎಚ್ಚರಿಕೆಗಳಾಗಿವೆ; ರಚನಾತ್ಮಕ ಮತ್ತು ತಾಜಾಗುವಿಕೆ ಸಮಸ್ಯೆಗಳು ಕಮಾಂಡ್ ಅನ್ನು ವಿಫಲಗೊಳಿಸುತ್ತವೆ.

## co-op-translator-mcp

ಏಜೆಂಟ್ಸ್, ಸಂಪಾದಕರು, ಮತ್ತು MCP-ಸಮ್ಮತ ಕ್ಲೈಂಟ್‌ಗಳಿಗಾಗಿ Co-op Translator MCP ಸರ್ವರ್ ಅನ್ನು ಓಡಿಸಿ.

```bash
co-op-translator-mcp
```

ಡೀಫಾಲ್ಟ್ ಸಾರಿಗೆ `stdio` ಆಗಿದೆ. ಗ್ರಾಹಕ ಸಂರಚನೆ, ಉಪಕರಣಗಳು, ಸಂಪನ್ಮೂಲಗಳು ಮತ್ತು ಭದ್ರತಾ ಟಿಪ್ಪಣಿಗಳಿಗಾಗಿ [MCP ಸರ್ವರ್](mcp.md) ಮಾರ್ಗದರ್ಶಿಯನ್ನು ನೋಡಿ.

### ಆಯ್ಕೆಗಳು

| ಆಯ್ಕೆ | ಅಗತ್ಯವೇ | ವಿವರಣೆ |
| --- | --- | --- |
| `--transport` | ಇಲ್ಲ | MCP ಟ್ರಾನ್ಸ್‌ಪೋರ್ಟ್: `stdio`, `streamable-http`, ಅಥವಾ `sse`. ಡೀಫಾಲ್ಟ್ `stdio`. |

## migrate-links

ಅನುವಾದಿತ Markdown ಫೈಲ್‌ಗಳನ್ನು ಮರುಪ್ರಕ್ರಿಯೆ ಮಾಡಿ ಮತ್ತು ನೋಟ್‌ಬುಕ್ ಲಿಂಕ್‌ಗಳನ್ನು ಅಪ್ಡೇಟ್ ಮಾಡಿ যাতে ಲಭ್ಯವಿದ್ದರೆ ಅವು ಅನುವಾದಿತ ನೋಟ್‌ಬುಕ್‌ಗಳನ್ನು ಸೂಚಿಸು.

```bash
migrate-links -l "ko ja"
```

### ಸಾಮಾನ್ಯ ಉದಾಹರಣೆಗಳು

ಲಿಂಕ್ ಅಪ್ಡೇಟ್‌ಗಳನ್ನು ಪೂರ್ವವೀಕ್ಷಿಸಿ:

```bash
migrate-links -l "ko" --dry-run
```

ಎಲ್ಲ ಬೆಂಬಲಿತ ಭಾಷೆಗಳನ್ನು ದೃಢೀಕರಣವಿಲ್ಲದೆ ಪ್ರಕ್ರಿಯೆಗೆ ಒಳಪಡಿಸಿ:

```bash
migrate-links -l "all" -y
```

ಅನುವಾದಿತ ನೋಟ್‌ಬುಕ್‌ಗಳು ಇದ್ದಾಗ ಮಾತ್ರ ಲಿಂಕ್‌ಗಳನ್ನು ಮರುಬರೆಯಿರಿ:

```bash
migrate-links -l "ko" --no-fallback-to-original
```

### ಆಯ್ಕೆಗಳು

| ಆಯ್ಕೆ | ಅಗತ್ಯವೇ | ವಿವರಣೆ |
| --- | --- | --- |
| `-l`, `--language-codes` | ಹೌದು | space ಮೂಲಕ ಬೇರ್ಪಡಿಸಿದ ಭಾಷಾ ಕೋಡ್‌ಗಳು, ಅಥವಾ `"all"`. |
| `-r`, `--root-dir` | ಇಲ್ಲ | ಪ್ರಾಜೆಕ್ಟ್ ರೂಟ್. ಡೀಫಾಲ್ಟ್ ಪ್ರಸ್ತುತ ಡೈರೆಕ್ಟರಿ. |
| `--image-dir` | ಇಲ್ಲ | ರೂಟ್‌ಗೆ ಸಾಪೇಕ್ಷವಾದ ಅನುವಾದಿತ ಚಿತ್ರ ಡೈರೆಕ್ಟರಿ. ಡೀಫಾಲ್ಟ್ `translated_images`. |
| `--dry-run` | ಇಲ್ಲ | ಅಪ್ಡೇಟ್‌ಗಳನ್ನು ಬರೆಯದೆ ಯಾವ ಫೈಲ್‌ಗಳು ಬದಲಾಗುತ್ತವೆ ಎಂದು ತೋರಿಸಿ. |
| `--fallback-to-original`, `--no-fallback-to-original` | ಇಲ್ಲ | ಅನುವಾದಿತ ನೋಟ್‌ಬುಕ್‌ಗಳು ಇಲ್ಲದೆ ಇದ್ದಾಗ ಮೂಲ ನೋಟ್‌ಬುಕ್ ಲಿಂಕ್‌ಗಳನ್ನು ಬಳಸಿ. ಡೀಫಾಲ್ಟ್ ಸಕ್ರಿಯವಾಗಿದೆ. |
| `-d`, `--debug` | ಇಲ್ಲ | ಡೀಬಗ್ ಲಾಗಿಂಗ್ ಸಕ್ರಿಯಗೊಳಿಸಿ. |
| `-s`, `--save-logs` | ಇಲ್ಲ | DEBUG-ಮಟ್ಟದ ಲಾಗ್‌ಗಳನ್ನು `<root-dir>/logs/` ಅಡಿಯಲ್ಲಿ ಉಳಿಸಿ. |
| `-y`, `--yes` | ಇಲ್ಲ | ಎಲ್ಲಾ ಭಾಷೆಗಳನ್ನು ಪ್ರಕ್ರಿಯೆಗೊಳಿಸುವಾಗ ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ದೃಢೀಕರಿಸಿ. |

## ಪರಿಸರ

ಕಮಾಂಡ್‌ಗಾಗಿ ಪ್ರოვೈಡರ್ ಪ್ರಮಾಣಪತ್ರಗಳ ಅಗತ್ಯವಿದ್ದಾಗ, ಈ ಪ್ರೊವೈಡರ್ ಸೆಟ್‌ಗಳಲ್ಲಿ ಒಂದನ್ನು ಸಂರಚಿಸಿ. `translate --dry-run` ಮತ್ತು `co-op-review` ಗೆ ಪ್ರೊವೈಡರ್ ಪ್ರಮಾಣಪತ್ರಗಳ ಅವಶ್ಯಕತೆ ಇಲ್ಲ:

```bash
# ಏಜೂರ್ ಓಪನ್‌ಎಐ
AZURE_OPENAI_API_KEY="..."
AZURE_OPENAI_ENDPOINT="https://<resource>.openai.azure.com/"
AZURE_OPENAI_MODEL_NAME="gpt-4o"
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME="<deployment>"
AZURE_OPENAI_API_VERSION="2024-12-01-preview"

# ಅಥವಾ ಓಪನ್‌ಎಐ
OPENAI_API_KEY="..."
OPENAI_CHAT_MODEL_ID="gpt-4o"

# ಅಥವಾ ಆಂಥ್ರೋಪಿಕ್
ANTHROPIC_API_KEY="..."
ANTHROPIC_MODEL="claude-..."
```

ಚಿತ್ರ ಅನುವಾದಕ್ಕೆ ಹೆಚ್ಚುವರಿ Azure AI Vision ಅಗತ್ಯವಿದೆ:

```bash
AZURE_AI_SERVICE_API_KEY="..."
AZURE_AI_SERVICE_ENDPOINT="https://<resource>.cognitiveservices.azure.com/"
```

## ಔಟ್‌ಪುಟ್ ವಿನ್ಯಾಸ

ಪಠ್ಯ ಅನುವಾದಗಳು ಕೆಳಗಿನ ಸ್ಥಳಕ್ಕೆ ಬರೆಯಲಾಗುತ್ತವೆ:

```text
translations/<language-code>/<original-path>
```

ಅನುವಾದಿತ ಚಿತ್ರ ಔಟ್‌ಪುಟ್ ಕೆಳಗೆ ಬರೆಯಲಾಗುತ್ತದೆ:

```text
translated_images/<language-code>/<original-path>
```

ಉದಾಹರಣೆಗೆ, `README.md` ಮತ್ತು `docs/setup.md` ಅನ್ನು ಕೊರಿಯನ್‌ಗೆ ಅನುವಾದಿಸಿದಾಗ ಉತ್ಪಾದನೆಯಾಗುತ್ತದೆ:

```text
translations/ko/README.md
translations/ko/docs/setup.md
```

## ಕಾಪಿ-ಪೇಸ್ಟ್ CLI ಉದಾಹರಣೆಗಳು

Markdown ಅನ್ನು ಮೂರು ಭಾಷೆಗಳಿಗೆ ಭಾಷಾಂತರಿಸಿ:

```bash
translate -l "ko ja fr" -md
```

ಕೇವಲ ನೋಟ್‌ಬುಕ್‌ಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ:

```bash
translate -l "zh-CN" -nb
```

ಕೇವಲ ಚಿತ್ರಗಳನ್ನು ಭಾಷಾಂತರಿಸಿ:

```bash
translate -l "pt-BR" -img
```

ಫೈಲ್‌ಗಳನ್ನು ಬರೆಯದೆ Markdown ಅನುವಾದವನ್ನು ಪೂರ್ವವೀಕ್ಷಿಸಿ:

```bash
translate -l "de es" -md --dry-run
```

ಕಡಿಮೆ ಆತ್ಮವಿಶ್ವಾಸದ Markdown ಅನುವಾದಗಳನ್ನು ಸರಿಪಡಿಸಿ:

```bash
evaluate -l "ko" -c 0.8
translate -l "ko" --fix -c 0.8 -md
```

CI-ಸ್ನೇಹಿ Markdown ಅನುವಾದವನ್ನು ಓಡಿಸಿ:

```bash
translate -l "ko ja" -md -y -s
```

ಅನುವಾದಿತ ಔಟ್‌ಪುಟ್ ಅನ್ನು ವಿಮರ್ಶಿಸಿ:

```bash
co-op-review -l "ko ja"
```

ಲಿಂಕ್ ವಲಸಣೆಯನ್ನು ಪೂರ್ವವೀಕ್ಷಿಸಿ:

```bash
migrate-links -l "ko" --dry-run
```
