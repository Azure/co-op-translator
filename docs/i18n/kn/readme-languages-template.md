# README ಭಾಷೆಗಳ ಟೆಂಪ್ಲೇಟು

Co-op Translator ಅನುವಾದಿಸಲಾದ ವಿಷಯ ಪ್ರಕಟಿಸುವ ರೆಪೊಸಿಟರಿಗಳ README ಭಾಷಾ ಪಟ್ಟಿಯನ್ನು ನಿರ್ವಹಿಸಬಹುದು.

ಪ್ರತಿ ಅನುವಾದ ಚಲನೆಯಲ್ಲಿ ಸಂಪೂರ್ಣ ವಿಭಾಗವನ್ನು ಬದಲಾಯಿಸಲು Co-op Translatorನನ್ನು ಬಳಸಲು ಕೆಳಗಿನ ಮಾರ್ಕರ್‌ಗಳನ್ನು ಬಳಸಿ. ಕಸ್ಟಮ್ ಉಪಸಮೂಹವನ್ನು ಕೈಯಿಂದ ನಿರ್ವಹಿಸಲು ಇಚ್ಛಿಸುವರೆಂದರೆ ಮಾರ್ಕರ್‌ಗಳನ್ನು ತೆಗೆಯಿರಿ.

ಮಾರ್ಕರ್‌ಗಳ ಮೇಲಿನ ಸಹಭಾಗಿತ್ವ ಮತ್ತು ಪ್ರಾರಂಭಿಕ-ಗೈಡ್ ಲಿಂಕ್ ಐಚ್ಛಿಕವಾಗಿದೆ. ಇವು ಓದುಗರಿಗೆ ಅನುವಾದಗಳು ಹೇಗೆ ನಿರ್ವಹಿಸಲಾಗುತ್ತವೆ ಮತ್ತು ತಮ್ಮದೇ ರೆಪೊಸಿಟರಿಗಳನ್ನು ಹೇಗೆ ಅನುವಾದಿಸಬಹುದು ಎಂದು ಕಂಡುಹಿಡಿಯಲು ಸಹಾಯ ಮಾಡುತ್ತವೆ. ಭಾಷಾ-ಪಟ್ಟಿಯ ನವೀಕರಣಗಳು ಅವುಗಳನ್ನು ಉಳಿಸಿಕೊಂಡಿಡುವಂತೆ ಮಾರ್ಕೆರ್‌ಗಳ ಹೊರಗೆ ಇಡಿ. ಮತ್ತೊಂದು ರೆಪೊಸಿಟರಿಯನ್ನು ನವೀಕರಿಸುವಾಗ ಅದರ ಕೊಡುಗೆ ಮಾರ್ಗದರ್ಶಿಗಳನ್ನು ಅನುಸರಿಸಿ ಮತ್ತು ಈ ಪಠ್ಯವನ್ನು ಸೇರಿಸುವುದನ್ನು ಅದರ ನಿರ್ವಾಹಕರು ತೀರ್ಮಾನಿಸಲು ಬಿಡಿ.

> This repository includes many language translations, which can significantly increase download size. To clone without translations, use sparse checkout:
>
> ```bash
> git clone --filter=blob:none --sparse https://github.com/org/repo.git
> cd repo
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```

ಅನುವಾದದ ವೇಳೆ sparse-checkout ರೆಪೊಸಿಟರಿ URL ಅನ್ನು ವೈಯಕ್ತಿಕಗೊಳಿಸಿ:


ಮಾರ್ಕರ್‌ಗಳು ಇದ್ದರೆ, ಭಾಷೆಗಳು ಸೇರ್ಪಡೆಗೊಂಡಾಗ ಅಥವಾ ಬದಲಾಗಿದಾಗ Co-op Translator ಉತ್ಪತ್ತಿ ಪಟ್ಟಿಯನ್ನು ನವೀಕರಿಸಬಹುದು.

ಇದುವರೆಗಿನ README ಗೆ, ಅದರ ಭಾಷಾ-ಪಟ್ಟಿ ಮಾರ್ಕರ್‌ಗಳ ಮೇಲ್ಭಾಗದಲ್ಲಿ ಐಚ್ಛಿಕ ಸಹಭಾಗಿತ್ವ ಮತ್ತು ಪ್ರಾರಂಭಿಕ ಲಿಂಕ್ ಅನ್ನು ಅದರ ಭಾಷಾ ಲಿಂಕ್‌ಗಳು ಅಥವಾ ಇತರ ವಿಷಯಗಳನ್ನು ಬದಲಾಯಿಸದೆ ಸೇರಿಸಬಹುದು. ಬೆಂಬಲಿತ ಭಾಷೆಗಳ ಲಿಂಕ್‌ಗಳನ್ನು [ಪ್ರಸ್ತುತ ಭಾಷಾ ಮಾರ್ಗದರ್ಶಿ](https://github.com/Azure/co-op-translator/blob/main/docs/supported-languages.md)ಗೆ ಸೂಚಿಸಿ.
