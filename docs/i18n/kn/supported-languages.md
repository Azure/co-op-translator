## ಭಾಷೆ ಸೇರಿಸಿ

ಹೊಸ ಭಾಷೆಗೆ ಬೆಂಬಲ ಸೇರಿಸಲು:

1. ಭಾಷಾ ಉಪಕರಣಗಳಿಗೆ ಭಾಷಾ ಕೋಡ್ ಮತ್ತು ಪ್ರದರ್ಶನ ಹೆಸರನ್ನು ಸೇರಿಸಿ.
2. `src/co_op_translator/fonts/font_language_mappings.yml` ನಲ್ಲಿ ಫಾಂಟ್ ಅನ್ನು ಸೇರಿಸಿ ಅಥವಾ ಮ್ಯಾಪ್ ಮಾಡಿ.
3. ಮಾರ್ಕ್‌ಡೌನ್ ಮತ್ತು ಚಿತ್ರ ಅನುವಾದ ಔಟ್ಪುಟ್ ಅನ್ನು ಪರೀಕ್ಷಿಸಿ.
4. ಮ್ಯಾಪಿಂಗ್ ಮತ್ತು ಮಾನ್ಯತೆ ಟಿಪ್ಪಣಿಗಳೊಂದಿಗೆ ಪುಲ್ ರಿಕ್ವೆಸ್ಟ್ ತೆರೆಯಿರಿ.
