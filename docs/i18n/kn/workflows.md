# ನಿಮ್ಮ ಕಾರ್ಯಪ್ರವಾಹ ಆಯ್ಕೆಮಾಡಿ

Co-op Translator ಅನ್ನು ಮೂರು ರೀತಿಗಳಲ್ಲಿ ಬಳಸಬಹುದು: CLI, Python API, ಮತ್ತು MCP ಸರ್ವರ್. ಅವು ಒಂದೇ ಅನುವಾದ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತವೆ, ಆದರೂ ಪ್ರತಿ ಒಂದೂ ವಿಭಿನ್ನ ಕಾರ್ಯಪ್ರವಾಹಕ್ಕೆ ಹೊಂದಿಕೆಯಾಗುತ್ತದೆ.

ನೀವು ಯಾವುದಿಂದ ಶುರುಮಾಡಬೇಕು ಎಂದು ನಿರ್ಧರಿಸುತ್ತಿದ್ದರೆ ಈ ಪುಟವನ್ನು ಬಳಸಿ.

**ನೀವು ಅನುವಾದಗಳನ್ನು ಕೈಯಿಂದ ಸಂಪಾದಿಸಿದರೆ:** ಡಿಫಾಲ್ಟ್ CLI ಮತ್ತು Actions ಕಾರ್ಯಪ್ರವಾಹಗಳು ಬದಲಾಗಿರುವ ಮೂಲ ಫೈಲ್‌ಗಳನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಮರುಅನುವಾದಿಸುತ್ತವೆ, ಆದ್ದರಿಂದ ಆ ಫೈಲ್‌ಗಳಲ್ಲಿ ನೀವು ಬಳಸಿದ ಪದಗಳು ಮರುಬರೆಸಲ್ಪಡಬಹುದು. ನವೀಕರಣವನ್ನು ಅಂಗೀಕರಿಸುವ ಮೊದಲು diff ಅನ್ನು ಪರಿಶೀಲಿಸಿ. ಸ್ವೀಕರಿಸಿದ ತಿದ್ದುಪಡಿ‌ಗಳ Markdown ಬ್ಲಾಕ್-ಹಂತದ ಸಂರಕ್ಷಣೆಗೆ, ಐಚ್ಛಿಕ [Python API ಅನುವಾದ ಸ್ಥಿತಿ ಪೂರೈಕೆದಾರ](api.md#preserve-accepted-human-edits-with-a-translation-state-provider) ಅನ್ನು ಬಳಸಿ.

## CLI ಬಳಸುವ ಸಂದರ್ಭದಲ್ಲಿ

ಒಬ್ಬ ವ್ಯಕ್ತಿ ಅಥವಾ CI ಕಾರ್ಯವು ಶೆಲ್‌ನಿಂದ ರಿಪೊಜಿಟರಿ ಅನುವಾದವನ್ನು ನಡೆಸುತ್ತಿದ್ದಾಗ CLI ಆಯ್ಕೆಮಾಡಿ.

ಪ್ರಾಜೆಕ್ಟ್ ಫೈಲ್‌ಗಳನ್ನು ಕಂಡುಹಿಡಿಯಲು, ಅನುವಾದಿತ ಔಟ್‌ಪುಟ್‌ಗಳನ್ನು ರಚಿಸಲು, ಪ್ರಾಜೆಕ್ಟ್ ರಚನೆಯನ್ನು ಉಳಿಸಲು, ಮೆಟಾಡೇಟಾ ನವೀಕರಿಸಲು ಮತ್ತು ವಿಮರ್ಶಾ ಕಮಾಂಡ್‌ಗಳನ್ನು ಚಾಲನೆಮಾಡಲು ನೀವು Co-op Translator ಅನ್ನು ಬಳಸಲು ಬಯಸಿದರೆ CLI ಅತ್ಯಂತ ನೇರ ಮಾರ್ಗವಾಗಿದ್ದುದು.

```bash
translate -l "ko" -md --dry-run
translate -l "ko" -md -nb
co-op-review -l "ko"
migrate-links -l "ko" --dry-run
```

ಈ ಉದಾಹರಣೆ Markdown ಮತ್ತು ನೋಟ್ಬುಕ್‌ಗಳು ಅನುವಾದಿಸುತ್ತದೆ. `-img` ಅನ್ನು ಕೇವಲ [Azure AI Vision](configuration.md#azure-ai-vision) ಅನ್ನು ಸಂರಚಿಸಿದ ನಂತರ ಮಾತ್ರ ಸೇರಿಸಿ. Markdown-ಮಾತ್ರ ಮೊದಲ ರನ್‌ಗಾಗಿ, [ನಿಮ್ಮ ಮೊದಲ ಅನುವಾದ](first-translation.md) ಅನ್ನು ಅನುಸರಿಸಿ.

ಉತ್ತಮ ಬಳಕೆಗಳು:

- ನೀವು ಟರ್ಮಿನಲ್‌ನಿಂದ ರಿಪೊಜಿಟರಿಯನ್ನು ಅನುವಾದಿಸುತ್ತಿದ್ದೀರಿ.
- ನೀವು CI ಅಥವಾ ರಿಲೀಸ್ ಕಾರ್ಯಪ್ರವಾಹಗಳಿಗೆ ಪುನರಾವರ್ತಿಸಬಹುದಾದ ಕಮಾಂಡ್ ಬೇಕು.
- ನೀವು ಒಳಗೊಂಡಿರುವ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ವೇಷಣೆ, ಔಟ್‌ಪುಟ್ ಮಾರ್ಗಗಳು, ಮೆಟಾಡೇಟಾ, ಕ್ಲೀನ್‌ಅಪ್ ಮತ್ತು ವಿಮರ್ಶೆ ಬಯಸುತ್ತೀರಿ.
- Python ಕೋಡ್ ಬರೆಯುವುದಕ್ಕೆ ಬದಲು ಕಮಾಂಡ್ ಇಂಟರ್ಫೇಸ್ ಅನ್ನು ನೀವು ಮೇಲುಗೈ ಮಾಡುತ್ತೀರಿ.

## Python API ಬಳಸುವ ಸಂದರ್ಭದಲ್ಲಿ

ನಿಮ್ಮ ಸ್ವಂತ ಕೋಡಿನಿಂದ ಕಾರ್ಯಪ್ರವಾಹವನ್ನು ನಿಯಂತ್ರಿಸಬೇಕಾದಾಗ Python API ಆಯ್ಕೆಮಾಡಿ.

API ಅಪ್ಲಿಕೇಶನ್‌ಗಳು, ಸ್ವಯಂಚಾಲಿತ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು, ನೋಟ್ಬುಕ್‌ಗಳು, ಸೇವೆಗಳು ಮತ್ತು ಕಸ್ಟಮ್ পাইಪ್‌ಲೈನ್‌ಗಳಿಗೆ ಉಪಯುಕ್ತವಾಗಿದೆ. ಇದು ವೈಯಕ್ತಿಕ ಫೈಲ್‌ಗಳಿಗಾಗಿ ಕೆಳಮಟ್ಟದ ವಿಷಯ ಅನುವಾದ APIಗಳನ್ನು ಕರೆಗೊಂಡು ಅಥವಾ CLI ಬಳಸುವಂತೆ ಅದೇ ರಿಪೊಜಿಟರಿ-ಮಟ್ಟದ ಸಂಯೋಜನೆಯನ್ನು ರನ್ ಮಾಡಲು ಅವಕಾಶ ಮಾಡಿಕೊಡುತ್ತದೆ.

ಒಂದು Markdown ಡಾಕ್ಯುಮೆಂಟ್ ಅನ್ನು ಅನುವಾದಿಸಿ ಮತ್ತು ಅದನ್ನು ಎಲ್ಲಿ ಸಂರಕ್ಷಿಸುವುದೆಂದು ನಿರ್ಧರಿಸಿ:

```python
import asyncio
from pathlib import Path

from co_op_translator.api import rewrite_markdown_paths, translate_markdown_content


async def main() -> None:
    source_path = Path("docs/guide.md")
    target_path = Path("translations/ko/docs/guide.md")

    translated = await translate_markdown_content(
        source_path.read_text(encoding="utf-8"),
        "ko",
        {"source_path": source_path},
    )

    rewritten = rewrite_markdown_paths(
        translated,
        source_path=source_path,
        target_path=target_path,
    )

    target_path.parent.mkdir(parents=True, exist_ok=True)
    target_path.write_text(rewritten, encoding="utf-8")


asyncio.run(main())
```

Python ನಿಂದ ರಿಪೊಜಿಟರಿ ಅನುವಾದವನ್ನು ಚಾಲನೆಮಾಡಿ:

```python
from co_op_translator.api import run_translation

run_translation(
    language_codes="ko",
    markdown=True,
    notebook=True,
    images=False,
    dry_run=True,
)
```

ಉತ್ತಮ ಹೊಂದಿಕೆಗಳು:

- ನಿಮ್ಮ ಅಪ್ಲಿಕೇಶನ್ ಈಗಾಗಲೇ ಫೈಲ್‌ಗಳು, ಬಫರ್‌ಗಳು, ನೋಟ್ಬುಕ್‌ಗಳು ಅಥವಾ ಇಮೇಜ್ ಬೈಟ್‌ಗಳನ್ನು ಓದುತ್ತಿದೆ.
- ನಿಮಗೆ ಕಸ್ಟಮ್ ಮಾನ್ಯತೆ, ಸಂಗ್ರಹಣೆ, ಲಾಗಿಂಗ್, ಮರುಪ್ರಯತ್ನಗಳು ಅಥವಾ ಅಂಗೀಕಾರದ ಪ್ರಕ್ರಿಯೆಗಳು ಬೇಕಾದರೆ.
- ನೀವು ಸಂಪೂರ್ಣ ರಿಪೊಜಿಟರಿ ಪ್ರಕ್ರಿಯೆಗೊಳಿಸದೆ ಒಂದೇ ದಸ್ತಾವೇಜು, ನೋಟ್ಬುಕ್ ಅಥವಾ ಚಿತ್ರವನ್ನು ಅನುವಾದಿಸಬಯಸುವುದಾದರೆ.
- ನೀವು ರಿಪೊಜಿಟರಿ ಅನುವಾದವನ್ನು ಬಯಸುತ್ತೀರಿ, ಆದರೆ ಶೆಲ್ ಕಮಾಂಡ್ ಬದಲಿಗೆ Python automation ಮೂಲಕ.

## MCP Server ಬಳಸುವ ಸಂದರ್ಭದಲ್ಲಿ

ಏಜೆಂಟ್, ಸಂಪಾದಕ, ಅಥವಾ MCP-ಅನುಕೂಲ ಕ್ಲೈಂಟ್ Co-op Translator ಉಪಕರಣಗಳನ್ನು ಕರೆ ಮಾಡಬೇಕು ಎಂದಾದರೆ MCP ಸರ್ವರ್ ಆಯ್ಕೆಮಾಡಿ.

ಸಾಮಾನ್ಯ ಸ್ಥಳೀಯ ಸೆಟ್‌ಅಪ್‌ನಲ್ಲಿ, ಬಳಕೆದಾರನು ಸರ್ವರ್ ಅನ್ನು ಕೈಯಿಂದ ಚಾಲನೆ ಮಾಡಿಕೊಂಡುಕೊಳ್ಳುವುದಿಲ್ಲ. MCP ಕ್ಲೈಂಟ್ ಅವಶ್ಯಕತೆ ಬಂದಾಗ `stdio` ಮೂಲಕ `co-op-translator-mcp` ಅನ್ನು ಪ್ರಾರಂಭಿಸುತ್ತದೆ.

ಏಜೆಂಟ್ ನಿರ್ವಹಿಸಬಹುದಾದ ಬಳಕೆದಾರ ವಿನಂತಿಗಳ ಉದಾಹರಣೆಗಳು:

- "ಈ Markdown ಫೈಲ್ನ್ನು ಕೊರಿಯನ್‌ಗೆ ಅನುವಾದಿಸಿ ಮತ್ತು ಲಿಂಕ್‍ಗಳನ್ನು ಸರಿಯಾಗಿ ಉಳಿಸಿ."
- "ಏಜೆಂಟ್-ಸಹಾಯಿತ MCP ಕಾರ್ಯಪ್ರವಾಹದೊಂದಿಗೆ ಈ Markdown ಫೈಲನ್ನು ಕೊರಿಯನ್‌ಗೆ ಅನುವಾದಿಸಿ, ಅನುವಾದಿತ ತುಂಡುಗಳಿಗಾಗಿ ನಿಮ್ಮ ಸ್ವಂತ ಮಾದರಿಯನ್ನು ಬಳಸಿ."
- "ಈ ನೋಟ್ಬುಕ್ ಅನ್ನು ಕೊರಿಯನ್‌ಗೆ ಅನುವಾದಿಸಿ, ಕೋಡ್ ಸೆಲ್‌ಗಳನ್ನು ಉಳಿಸಿ, ಮತ್ತು ನೋಟ್ಬುಕ್ ಅನ್ನು ಮರುರಚಿಸಲು Co-op Translator MCP ಅನ್ನು ಬಳosu."
- "ಈ ಚಿತ್ರದಲ್ಲಿನ ಪಠ್ಯವನ್ನು ಜಾಪಾನೀಸ್‌ಗೆ ಅನುವಾದಿಸಿ ಮತ್ತು ಫಲಿತಾಂಶವನ್ನು ಸಂರಕ್ಷಿಸಿ."
- "ರಿಪೊಜಿಟರಿ ಅನುವಾದವನ್ನು ಸ್ಪ್ಯಾನಿಷ್‌ಗೆ ಡ್ರೈ-ರನ್ ಮಾಡಿ ಮತ್ತು ಏನು ಬದಲಾಗುತ್ತದೆ ಎಂದು ನನಗೆ ತಿಳಿಸಿ."
- "ಕೊರಿಯನ್ ಅನುವಾದ ಔಟ್‌ಪುಟ್ ನವೀಕರಣಗೊಂಡಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ."

Markdown ಮತ್ತು ನೋಟ್ಬುಕ್‌ಗಳಿಗಾಗಿ, MCP ಎರಡು ಮೋಡ್‌ಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸಬಹುದು:

| ಮೋಡ್ | ಬಳಸುವಾಗ | ಪ್ರಮುಖ ಉಪಕರಣಗಳು |
| --- | --- | --- |
| Agent-assisted | MCP ಹೋಸ್ಟ್ ಏಜೆಂಟ್ ತನ್ನ ಸ್ವತಃ ಮಾದರಿಯೊಂದಿಗೆ ಚುಂಕ್‌ಗಳನ್ನು ಅನುವಾದಿಸಬೇಕು, Co-op Translator LLM ಪ್ರೊವೈಡರ್ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಬಳಸದೆ. | `start_markdown_agent_translation`, `finish_markdown_agent_translation`, `start_notebook_agent_translation`, `finish_notebook_agent_translation` |
| Provider-backed | Co-op Translator ನೇರವಾಗಿ Azure OpenAI, OpenAI, ಅಥವಾ Anthropicನ್ನು ಕರೆ ಮಾಡಬೇಕು. | `translate_markdown_content`, `translate_notebook_content` |

MCP provider-backed Markdown ಉಪಕರಣ ಕರೆಗೊಳ್ಳುವ ರೂಪ:

```json
{
  "tool": "translate_markdown_content",
  "arguments": {
    "document": "# Setup\n\nInstall Co-op Translator first.",
    "language_code": "ko",
    "options": {
      "source_path": "docs/setup.md"
    }
  }
}
```

MCP ಇಮೇಜ್ ಉಪಕರಣ ಕರೆಗೊಳ್ಳುವ ರೂಪ:

```json
{
  "tool": "translate_image_content",
  "arguments": {
    "image_path": "assets/architecture.png",
    "language_code": "ko",
    "output_path": "translated_images/ko/assets/architecture.png"
  }
}
```

MCP ಮೂಲಕ ರಿಪೊಜಿಟರಿ ಅನುವಾದವು ಡೀಫಾಲ್ಟ್‌ಗಾಗಿಯೇ ಡ್ರೈ-ರನ್ ಆಗಿ ನಡೆಯುತ್ತದೆ:

```json
{
  "tool": "run_translation",
  "arguments": {
    "language_codes": ["ko"],
    "translate_markdown": true,
    "translate_notebooks": true,
    "translate_images": false,
    "dry_run": true
  }
}
```

ಉತ್ತಮ ಬಳಕೆಗಳು:

- ನೀವು ಏಜೆಂಟ್ ಅಥವಾ ಸಂಪಾದಕರ ಒಳಗೆ ನೈಸರ್ಗಿಕ ಭಾಷೆಯ ಅನುವಾದ ಕಾರ್ಯಪ್ರವಾಹಗಳನ್ನು ಬಯಸುತ್ತೀರಿ.
- ನಿಮಗೆ Markdown ಅಥವಾ ನೋಟ್ಬುಕ್ ಅನುವಾದ ಬೇಕು, ಅಲ್ಲಿ ಹೋಸ್ಟ್ ಏಜೆಂಟ್ ಮಾದರಿ ತಯಾರಿಸಿದ ಚುಂಕ್‌ಗಳನ್ನು ಅನುವಾದಿಸುತ್ತದೆ.
- ನೀವು ಆಯ್ದ ವಿಷಯವನ್ನು ಸಂಪೂರ್ಣ ರಿಪೊಜಿಟರಿ ಬದಲಾಗಿ ಏಜೆಂಟ್ ಅನುವಾದಿಸಲಿ ಎಂದು ಬಯಸುತ್ತೀರಿ.
- ರಿಪೊಜಿಟರಿ-ವ್ಯಾಪ್ತಿ ಬರವಣಿಗೆಗಳ ಮೊದಲು ಅಂಗೀಕಾರದ ಹಂತವನ್ನು ನೀವು ಬಯಸುತ್ತೀರಿ.
- Markdown, ನೋಟ್ಬುಕ್, ಚಿತ್ರ, ವಿಮರ್ಶೆ ಮತ್ತು ಪಥ ಮರುಬರೆಹಿಸುವ ಉಪಕರಣಗಳನ್ನು ಒಟ್ಟಿಗೆ ಪ್ರದರ್ಶಿಸುವ ಒಂದೇ ಇಂಟರ್ಫೇಸ್ ಬೇಕು.

## ಅವುಗಳು ಪರಸ್ಪರ ಹೇಗೆ ಹೊಂದಿಕೊಳ್ಳುತ್ತವೆ

ರಿಪೊಜಿಟರಿಗಳನ್ನು ಜನರು ಅನುವಾದಿಸುವಾಗ CLI ಅತ್ಯುತ್ತಮ ಡೀಫಾಲ್ಟ್ ಆಗಿದೆ. ನಿಮ್ಮ ಕೋಡ್ ಕಾರ್ಯಪ್ರವಾಹವನ್ನು ನಿಯಂತ್ರಿಸುವಾಗ Python API ಅತ್ಯುತ್ತಮ. ಏಜೆಂಟ್ ಅಥವಾ ಸಂಪಾದಕ ಕಾರ್ಯಪ್ರವಾಹವನ್ನು ನಿಯಂತ್ರಿಸಿದಾಗ MCP ಸರ್ವರ್ ಅತ್ಯುತ್ತಮ.

երեք ಮಾರ್ಗಗಳೂ ಒಂದೇ ಸಾರ್ವಜನಿಕ Co-op Translator API ಅನ್ನು ಬಳಸುತ್ತವೆ, ಆದ್ದರಿಂದ ನೀವು CLI ನಿಂದ ಪ್ರಾರಂಭಿಸಿ, ನಂತರ Python ಮೂಲಕ ಸ್ವಯಂಚಾಲಿತಗೊಳಿಸಬಹುದು ಮತ್ತು ಏಜೆಂಟ್-ಚಾಲಿತ ಕಾರ್ಯಪ್ರವಾಹಗಳ ಅಗತ್ಯವಿದ್ದಾಗ ಆವೇ ಸಾಮರ್ಥ್ಯಗಳನ್ನು MCP ಕ್ಲೈಂಟ್‌ಗಳಿಗೆ ಅನಾವರಣ ಮಾಡಬಹುದು.
