## ദ്രുതാരംഭം

ഒരു പ്രൊവൈഡറെ കോൺഫിഗർ ചെയ്ത്, ശേഷം നിങ്ങളുടെ ജോലിക്ക് അനുയോജ്യമായ ഇന്റർഫേസ് തിരഞ്ഞെടുക്കുക. CLI, Python API, MCP എന്നിവ વિકല്പങ്ങളാണ്; നിങ്ങൾക്ക് മൂന്നു എല്ലാം നിർബന്ധമായും പൂർത്തിയാക്കേണ്ടതില്ല.
