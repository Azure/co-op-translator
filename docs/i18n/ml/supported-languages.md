# പിന്തുണയുള്ള ഭാഷകൾ

Co-op Translator വാചകങ്ങൾ, നോട്ട്‌ബുക്ക്, ചിത്രം എന്നിവയുടെ വിവർത്തന ഔട്ട്പുട്ടുകൾക്കായി താഴെപ്പറയുന്ന ഭാഷാ കോഡുകൾ പിന്തുണയ്ക്കുന്നു.

## ഭാഷ ചേർക്കുക

ഒരു പുതിയ ഭാഷയ്ക്ക് പിന്തുണ ചേർക്കാൻ:

1. ഭാഷാ കോഡ് மற்றும் പ്രദർശന നാമം language utilities-ൽ ചേർക്കുക.
2. `src/co_op_translator/fonts/font_language_mappings.yml`-ൽ ഒരു ഫോണ്ട് ചേർക്കുക അല്ലെങ്കിൽ മാപ്പ് ചെയ്യുക.
3. Markdownയും ചിത്രം വിവർത്തന ഔട്ട്പുട്ടും പരീക്ഷിക്കുക.
4. മാപ്പിംഗും സാധുത പരിശോധന കുറിപ്പുകളും ചേർത്തുകൊണ്ട് ഒരു പുൾ റിക്വസ്റ്റ് തുറക്കുക.
