# တစ်စိတ်တစ်ပိုင်း ပရောဂျက်ငယ်တစ်ခုကို ဘာသာပြန်၊ တည်းဖြတ်နှင့် ပြန်လည်သုံးသပ်ခြင်း

တိုတောင်းသော Markdown ဖိုင်နှစ်ခုနှင့် တစ်ခုသော ပစ်မှတ်ဘာသာစကားဖြင့် စတင်ပါ။ ဘာသာပြန်များကို ဘယ်မှာရေးမည်၊ မူရင်း ပြောင်းလဲသည့်အခါ ဖြစ်ပေါ်မည့် အကျိုးသက်ရောက်မှုများနှင့် ရလဒ်ကို မည်သို့ စစ်ဆေးရမည်ကို တွေ့မြင်ရမည်။

## မှတ်တမ်းတင်ထားသော ရလဒ်များ

ဥပမာကို 2026-09-19 တွင် Co-op Translator 0.21.0 နှင့် Azure OpenAI (`gpt-5-mini`) ဖြင့် ဆောင်ရွက်ခဲ့သည်။ မပြင်ဆင်ထားသော CLI အမိန့်များကို Click ၏ `CliRunner` မှတဆင့် တည်ဆောက်ထားသော wheel နှင့် ရှိပြီးသား Python အားလိုအပ်ချက်များဖြင့် ခေါ်ဆောင်ခဲ့သည်။

| အဆင့် | ရလဒ် |
| --- | --- |
| ကြိုတင်ကြည့်ရှုခြင်း | Exit 0; မော်ဒယ် ဘာသာပြန်မှု မတောင်းဆိုခဲ့ပါ |
| ပထမဆုံး ဘာသာပြန်ခြင်း | Exit 0; 27.36 စက္ကန့် |
| အစပိုင်း သုံးသပ်ခြင်း | Exit 0 |
| README ကို တည်းဖြတ်ပြီး သုံးသပ်ခြင်း | Exit 1; ဟောင်းနေသော ဘာသာပြန်ချက် တွေ့ရှိခဲ့သည် |
| ဘာသာပြန်ကို အပ်ဒိတ်လုပ်ခြင်း | Exit 0; 22.17 စက္ကန့် |
| အပ်ဒိတ်ပြီးနောက် သုံးသပ်ခြင်း | Exit 0; အမှား သို့မဟုတ် သတိပေးချက် မရှိပါ |
| မပြောင်းလဲသေးသော guide | README အပ်ဒိတ် မပြုမီနှင့် ပြုလုပ်ပြီးနောက် bytes အတိအကျ တူညီနေပါသည် |
| ထပ်မံပြေးဆောင်ခြင်း | Exit 0; ဘာသာပြန်ဖိုင်အားလုံးအတွက် hash များ အတူတူ ဖြစ်နေပါသည် |

ဤအချက်အလက်များမှာ တစ်ခုချင်းစီ၏ တိုင်းတာချက်များဖြစ်ပြီး လုပ်ဆောင်နိုင်မှု အာမခံချက် မဟုတ်ပါ။ စတင်ပြင်ဆင်ချိန်ကို မတွက်ချက်ထားပါ; ပရိုဗိုင်းဒါ ဘေလ်ချင်းကို မတိုင်းတာခဲ့ပါ။ မပြောင်းလဲသော run တစ်ခုလည်း ပရိုဗိုင်းဒါ၏ ကျန်းမာရေး စစ်ဆေးမှုကို ဆောင်ရွက်နိုင်ပါသည်။

စတင်ထားသော [initial translation](../../assets/demo/before.txt)、[အပ်ဒိတ်လုပ်ပြီးသော အဆိုပါ ဘာသာပြန်ချက်](../../assets/demo/after.txt)、[ပြည့်စုံသော ဘာသာပြန် ကွာခြားချက်](../../assets/demo/update.diff)、[ဟောင်းနေသော သုံးသပ်ချက်](../../assets/demo/review-stale.txt)、[နောက်ဆုံး သုံးသပ်ချက်](../../assets/demo/review-after.txt) နှင့် [run details](../../assets/demo/results.json) ကို စစ်ဆေးပါ။ ဖိုင်လုံးဝ ဘာသာပြန်ခြင်းကြောင့် အခြားစကားလုံးများ ပြောင်းလဲနိုင်ပြီး ၎င်းကို ဖမ်းယူထားသော diff တွင် ပြသထားသည်။ စာသားနှစ်ခုစလုံးတွင် ထုတ်လုပ်ထားသော အပြစ်မခံမှုအကြောင်း အသိပေးချက်ကို ထိန်းသိမ်းထားပါသည်။

လူ့ပြန်လည်စစ်ဆေးခြင်း သေးငယ်စွာ အရေးကြီးပါသည်: ဖမ်းယူထားသော အပ်ဒိတ်တွင် `[사용 가이드](guide.md)을` ကို အသုံးပြုထားပြီး၊ ကိုးရီးယား particle သည် `[사용 가이드](guide.md)를` ဖြစ်သင့်သည်။ စာသား artifacts များသည် ဤအထွက်ကို မော်ဒယ်ထုတ်ပေးသည့်အတိုင်း တည်းဖြတ်ထားသည့် ဘာသာပြန်အဖြစ် မပြသဘဲ မူလအတိုင်း ထိန်းသိမ်းထားသည်။ ဤစကားလုံး ပြဿနာရှိသော်လည်း ဖွဲ့စည်းပုံဆိုင်ရာ သုံးသပ်ချက်မှာ အောင်မြင်သည်။

## 1. သေးငယ်သော ဖိုလ်ဒါတစ်ခု ပြင်ဆင်ပါ

Python 3.11–3.14 ကို အသုံးပြုပါ။ [virtual environment setup](configuration.md#local-runtime-setup) ကို လိုက်နာပါ။ ဤဥပမာအတွက် အသုံးပြုသည့် ဗားရှင်းကို ထည့်သွင်းပါ:

```bash
python -m pip install co-op-translator==0.21.0
mkdir translation-demo
cd translation-demo
git init
```

ဤဖိုလ်ဒါထဲသို့ [README.txt](../../assets/demo/README.txt) နှင့် [guide.txt](../../assets/demo/guide.txt) ကို ဒေါင်းလုတ်ဆွဲ၍ `README.md` နှင့် `guide.md` အဖြစ် သိမ်းဆည်းပါ။ ၎င်းတို့သည် အသေးစား စိတ်ကူးပရောဂျက် စာရွက်များဖြစ်ပြီး မည်သည့် အက်ပလီကေးရှင်း တပ်ဆင်မှုလိုအပ်ချက် မရှိပါ။

README တွင် ကုဒ် ဘလော့ခ်တစ်ခုနှင့် `guide.md` သို့ ချိတ်ဆက်ထားသော လင့်ခ်တစ်ခု ပါရှိသည်။ ၎င်း၏ နောက်ဆုံး စာကြောင်းမှာ -

```text
Notes are saved locally.
```

ဤဖိုလ်ဒါတွင် အဆိုပါ အရင်းခံ စာရွက်နှစ်စောင်သာ ထားပါ။ အောက်ပါ အမိန့်များအားလုံးကို `translation-demo` အတွင်းတွင် ပြေးဆောင်ရမည်ဖြစ်ပြီး Bash နှင့် PowerShell တွင် လည်ပတ်နိုင်ပါသည်။

## 2. မှတ်ပုံတင်အချက်အလက် မပါဘဲ ကြိုတင်ကြည့်ရှုခြင်း

```bash
translate -l "ko" -md --dry-run
```

ကြိုတင်ကြည့်ရှုခြင်းသည် မော်ဒယ် ခေါ်စရာ မလိုဘဲ သို့မဟုတ် ဘာသာပြန်စာများ မရေးသားဘဲ ဘာသာပြန်အလုပ်အပမာဏကို ခန့်မှန်းပေးသည်။ token ခန့်မှန်းချက်များသည် ဘေလ်ချင်း အတိုင်အဖြစ် မဖြစ်ပါ။ ပထမဆုံး ပြေးဆောင်မှုတွင် Markdown ဖိုင်နှစ်ခုလုံးကို အလုပ်အသစ်အဖြစ် သတ်မှတ်မည်ဖြစ်သည်။

## 3. ပရိုဗိုင်းဒါကို ရွေးချယ်ပြီး ဘာသာပြန်ပါ

[configuration guide](configuration.md) အတိုင်း Azure OpenAI, OpenAI သို့မဟုတ် Anthropic တစ်ခုကို ဖွဲ့စည်းသတ်မှတ်ပါ။ OpenAI နှင့် Anthropic ၏ စာသား ဘာသာပြန်မှုများအတွက် Azure အကောင့် မလိုအပ်ပါ။ ဤဥပမာအတွက် ဓာတ်ပုံ ဝန်ဆောင်မှုများ မလိုအပ်ပါ။

ဒေသတွင်း `.env` ဖိုင်ကို သုံးလျှင် `.env` ကို ဤဖိုလ်ဒါ၏ `.gitignore` ထဲသို့ ထည့်ပါ။ ဘာသာပြန်ခေါ်ဆိုမှုများသည် သင်၏ ပရိုဗိုင်းဒါ အကောင့်ကို အသုံးပြုကာ သက်သာမည့် တောင်းခံမှုများ ဖြစ်ပေါ်စေနိုင်သည်။

```bash
translate -l "ko" -md
co-op-review -l "ko"
```

ဖွင့်ပါ `translations/ko/README.md` နှင့် `translations/ko/guide.md`။ ကိုးရီးယား စကားအသုံးအနှုန်း၊ ကုဒ် ဘလော့ခ်နှင့် ဘာသာပြန်ထားသော README မှ ဘာသာပြန်ထားသော guide သို့ ချိတ်ဆက်ထားသော လင့်ခ်ကို စစ်ဆေးပါ။ ထွက်ရှိလာသော စကားလုံးများသည် မော်ဒယ်အလိုက် ကွဲပြားနိုင်ပါသည်။

`co-op-review` သည် တสดထိန်းသိမ်းမှု၊ ဖွဲ့စည်းပုံနှင့် ဒေသတွင်း လင့်ခ်များကို စစ်ဆေးသည်။ ဖြတ်လျှင် ရလဒ်သည် ဘာသာစကား တိကျမှုကို အာမခံမထားပါ။ ဆက်လက်လုပ်ဆောင်ရန်မတိုင်မီ သတိပေးထားသော အမှားများကို ဖြေရှင်းပါ။

Git ဖြင့် အောင်မြင်သည့် အခြေခံ ရလဒ်ကို မှတ်တမ်းတင်ပါ (လိုအပ်ပါက သင်၏ Git identity ကို ပထမဦးစွာ ပြင်ဆင်ပါ):

```bash
git add README.md guide.md translations
git commit -m "Record initial Korean translation"
```

## 4. မူရင်းကို ပြောင်းလဲပါ

README.md အတွင်းရှိ `Notes are saved locally.` ကို အောက်ပါအတိုင်း အစားထိုးပါ။

```text
Notes are saved locally as Markdown files.
```

`guide.md` ကို မပြင်ဆင်ပဲ ထားပါ။ ထို့နောက် ပြေးဆောင်ပါ:

```bash
co-op-review -l "ko"
translate -l "ko" -md --dry-run
```

သုံးသပ်မှုသည် README ဘာသာပြန်ကို ဟောင်းနေသည်ဟု တင်ပြသင့်ပြီး အောင်မြင်စွာ မပျောက်ဆုံးပါ။ ၎င်းသည် မျှော်လင့်ထားသည့် အလယ်အလတ် အခြေအနေဖြစ်သည်။ ကြိုတင်ကြည့်ရှုမှုသည် ပြောင်းလဲထားသော README အတွက် အလုပ် ရှိကြောင်း ဖော်ထုတ်သင့်ပါသည်။

## 5. အပ်ဒိတ်လုပ်ပြီး ကွာဟမှုကို စစ်ဆေးပါ

```bash
translate -l "ko" -md
git diff -- README.md translations/ko/README.md
git diff -- translations/ko/guide.md
co-op-review -l "ko"
```

တကယ့် diff ကို စစ်ဆေးပါ: သတ်မှတ်ထားသော CLI သည် ပြန်လည်ဘာသာပြန်ပေးသောကြောင့် မော်ဒယ်သည် ထိုဖိုင်ထဲရှိ အခြားစကားလုံးများကိုလည်း ပြန်လည်ပြင်ဆင်နိုင်သည်။ မပြောင်းလဲသေးသော guide တွင် diff မshould မရှိသင့်ပါ။ သုံးသပ်ချက်သည် README ကို ဟောင်းနေသည်ဟု ထပ်မံ မဖော်ပြသင့်တော့ပါ; အခြား တွေ့ရှိချက်များကို မချန်ထားဘဲ စုံစမ်းစစ်ဆေးပါ။

လူ့လက်ဖြင့် ပြင်ဆင်ထားသော Markdown အပိုင်းများကို block-level ဖြင့် ထိန်းသိမ်းရန်အတွက် [Python API](api.md) တွင် ရွေးချယ်နိုင်သည့် translation state provider တစ်ခု လိုအပ်ပါသည်။ ဤ CLI အမိန့်များဖြင့် ထည့်သွင်းထားသော်လည်း မဖွင့်ထားပါ။

## 6. မပြောင်းလဲဘဲ ထပ်မံပြေးဆောင်ခြင်း

အပ်ဒိတ် လုပ်ထားသော မူရင်းနှင့် ဘာသာပြန်စာများကို commit ပြုလုပ်ပါ:

```bash
git add README.md translations
git commit -m "Update Korean translation after source edit"
translate -l "ko" -md
git diff --exit-code -- translations
```

လက်ရှိ ဘာသာပြန်စာများနှင့် ဖော်ပြချက်များ မပြောင်းလဲသေးပါက translator သည် ဖိုင်များကို ကျော်လွှင့်မည်။ နောက်ဆုံး Git အမိန့်သည် diff မပါဘဲ အောင်မြင်စွာ ပြီးဆုံးရမည်။
