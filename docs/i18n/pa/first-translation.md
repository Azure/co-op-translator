# ਇੱਕ ਛੋਟੇ ਪ੍ਰੋਜੈਕਟ ਦਾ ਅਨੁਵਾਦ, ਸੋਧ ਅਤੇ ਸਮੀਖਿਆ

ਦੋ ਛੋਟੀਆਂ Markdown ਫਾਈਲਾਂ ਅਤੇ ਇੱਕ ਨਿਸ਼ਾਨੀ ਭਾਸ਼ਾ ਨਾਲ ਸ਼ੁਰੂ ਕਰੋ। ਤੁਸੀਂ ਵੇਖੋਗੇ ਕਿ ਅਨੁਵਾਦ ਕਿੱਥੇ ਲਿਖੇ ਜਾਂਦੇ ਹਨ, ਜਦੋਂ ਸਰੋਤ ਬਦਲਦਾ ਹੈ ਤਾਂ ਕੀ ਹੁੰਦਾ ਹੈ, ਅਤੇ ਨਤੀਜੇ ਨੂੰ ਕਿਵੇਂ ਜਾਂਚਿਆ ਜਾ ਸਕਦਾ ਹੈ।

## ਰਿਕਾਰਡ ਕੀਤੇ ਨਤੀਜੇ

ਉਦਾਹਰਨ 19 ਸਤੰਬਰ 2026 ਨੂੰ Co-op Translator 0.21.0 ਅਤੇ Azure OpenAI (`gpt-5-mini`) ਨਾਲ ਚਲਾਈ ਗਈ ਸੀ। ਬਿਨਾਂ ਸੋਧੀਆਂ CLI ਕਮਾਂਡਾਂ ਨੂੰ ਬਣਾਈ ਗਈ wheel ਅਤੇ ਮੌਜੂਦਾ Python ਨਿਰਭਰਤਾਵਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ Click ਦੇ `CliRunner` ਰਾਹੀਂ ਚਲਾਇਆ ਗਿਆ ਸੀ।

| ਕਦਮ | ਨਤੀਜਾ |
| --- | --- |
| ਪ੍ਰੀਵਿਊ | Exit 0; ਕੋਈ ਮਾਡਲ ਅਨੁਵਾਦ ਦੀ ਬੇਨਤੀ ਨਹੀਂ ਕੀਤੀ ਗਈ |
| ਸ਼ੁਰੂਆਤੀ ਅਨੁਵਾਦ | Exit 0; 27.36 ਸਕਿੰਟ |
| ਸ਼ੁਰੂਆਤੀ ਸਮੀਖਿਆ | Exit 0 |

| ਅਨੁਵਾਦ ਅਪਡੇਟ ਕਰੋ | Exit 0; 22.17 ਸਕਿੰਟ |

| ਫਿਰ ਚਲਾਓ | Exit 0; ਸਾਰੀਆਂ ਅਨੁਵਾਦ ਫਾਈਲਾਂ ਲਈ ਹੈਸ਼ ਇਕੋ ਜਿਹੇ ਹਨ |

ਇਹ ਵਿਅਕਤੀਗਤ ਚਲਾਉਣ ਨਾਪ-ਤੋਲ ਹਨ, ਪ੍ਰਦਰਸ਼ਨ ਦੀਆਂ ਗਾਰੰਟੀਆਂ ਨਹੀਂ। ਸੈਟਅਪ ਸਮਾਂ ਸ਼ਾਮਿਲ ਨਹੀਂ ਕੀਤਾ ਗਿਆ; ਪ੍ਰੋਵਾਈਡਰ ਬਿਲਿੰਗ ਮਾਪੀ ਨਹੀਂ ਗਈ। ਬਿਨਾਂ ਬਦਲਾਅ ਵਾਲੀ ਰਨ ਫਿਰ ਵੀ ਪ੍ਰੋਵਾਈਡਰ ਦੀ ਸਿਹਤ ਜਾਂਚ ਸਕਦੀ ਹੈ।

ਜਾਂਚੋ [ਸ਼ੁਰੂਆਤੀ ਅਨੁਵਾਦ](../../assets/demo/before.txt), [ਅਪਡੇਟ ਕੀਤਾ ਅਨੁਵਾਦ](../../assets/demo/after.txt), [ਪੂਰਾ ਅਨੁਵਾਦ ਫਰਕ](../../assets/demo/update.diff), [ਸਟੇਲ ਸਮੀਖਿਆ](../../assets/demo/review-stale.txt), [ਅੰਤਿਮ ਸਮੀਖਿਆ](../../assets/demo/review-after.txt), ਅਤੇ [ਚਲਾਉਣ ਵੇਰਵੇ](../../assets/demo/results.json)। ਪੂਰੀ ਫਾਈਲ ਦੇ ਅਨੁਵਾਦ ਨਾਲ ਹੋਰ ਸ਼ਬਦਾਵਲੀ ਬਦਲ ਸਕਦੀ ਹੈ, ਜਿਵੇਂ ਕਿ ਕੈਪਚਰ ਕੀਤਾ ਡਿਫ ਦਿਖਾਉਂਦਾ ਹੈ। ਦੋਹਾਂ ਟੈਕਸਟ ਆਰਟੀਫੈਕਟਾਂ ਨੇ ਬਣਾਈ ਗਈ ਡਿਸਕਲੇਮਰ ਨੂੰ ਰੱਖਿਆ ਹੈ।

ਮਨੁੱਖੀ ਸਮੀਖਿਆ ਅਜੇ ਵੀ ਮਹੱਤਵਪੂਰਨ ਹੈ: ਕੈਪਚਰ ਕੀਤਾ ਅਪਡੇਟ `[사용 가이드](guide.md)을` ਵਰਤਦਾ ਹੈ; ਕੋਰੀਆਈ particle ਨੂੰ `[사용 가이드](guide.md)를` ਹੋਣਾ ਚਾਹੀਦਾ ਸੀ। ਟੈਕਸਟ ਆਰਟੀਫੈਕਟ ਇਸ ਆਉਟਪੁੱਟ ਨੂੰ ਅਖੰਡ ਰੱਖਦੇ ਹਨ ਨਾ ਕਿ ਐਡਿਟ ਕੀਤਾ ਅਨੁਵਾਦ ਮਾਡਲ ਆਉਟਪੁੱਟ ਵਜੋਂ ਪੇਸ਼ ਕਰਨ। ਸੰਰਚਨਾਤਮਕ ਸਮੀਖਿਆ ਇਸ ਸ਼ਬਦੀ ਸਮੱਸਿਆ ਦੇ ਬਾਵਜੂਦ ਪਾਸ ਹੁੰਦੀ ਹੈ।

## 1. ਇੱਕ ਛੋਟਾ ਫੋਲਡਰ ਤਿਆਰ ਕਰੋ

Python 3.11–3.14 ਵਰਤੋਂ ਅਤੇ [ਵਰਚੁਅਲ ਵਾਤਾਵਰਣ ਸੈਟਅਪ](configuration.md#local-runtime-setup) ਦੀ ਵਰਤੋਂ ਕਰੋ। ਇਸ ਉਦਾਹਰਨ ਲਈ ਵਰਤੀ ਗਈ ਵਰਜਨ ਇੰਸਟਾਲ ਕਰੋ:

```bash
python -m pip install co-op-translator==0.21.0
mkdir translation-demo
cd translation-demo
git init
```

ਇਸ ਫੋਲਡਰ ਵਿੱਚ [README.txt](../../assets/demo/README.txt) ਅਤੇ [guide.txt](../../assets/demo/guide.txt) ਡਾਊਨਲੋਡ ਕਰੋ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ `README.md` ਅਤੇ `guide.md` ਦੇ ਨਾਂ ਨਾਲ ਸੇਵ ਕਰੋ। ਇਹ ਛੋਟੇ ਕਲਪਨੀ ਪ੍ਰੋਜੈਕਟ ਦਸਤਾਵੇਜ਼ ਹਨ; ਕਿਸੇ ਐਪਲੀਕੇਸ਼ਨ ਦੀ ਇੰਸਟਾਲੇਸ਼ਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ।

README ਵਿੱਚ ਇੱਕ ਕੋਡ ਬਲਾਕ ਅਤੇ `guide.md` ਲਈ ਇੱਕ ਲਿੰਕ ਸ਼ਾਮਿਲ ਹੈ। ਇਸ ਦੀ ਆਖਰੀ ਵਾਕ ਹੈ:

```text
Notes are saved locally.
```

ਸਿਰਫ਼ ਇਹ ਦੋ ਸਰੋਤ ਦਸਤਾਵੇਜ਼ ਇਸ ਫੋਲਡਰ ਵਿੱਚ ਰੱਖੋ। ਹੇਠਾਂ ਦਿੱਤੀਆਂ ਸਾਰੀਆਂ ਕਮਾਂਡਾਂ `translation-demo` ਦੇ ਅੰਦਰ ਚਲਾਈਆਂ ਜਾਣਗੀਆਂ ਅਤੇ Bash ਅਤੇ PowerShell ਵਿੱਚ ਕੰਮ ਕਰਦੀਆਂ ਹਨ।

## 2. ਪ੍ਰਮਾਣ ਪੱਤਰਾਂ ਦੇ ਬਿਨਾਂ ਪ੍ਰੀਵਿਊ

```bash
translate -l "ko" -md --dry-run
```

ਪ੍ਰੀਵਿਊ ਮਾਡਲ ਨੂੰ ਕਾਲ ਕੀਤੇ ਬਿਨਾਂ ਜਾਂ ਅਨੁਵਾਦ ਲਿਖੇ ਬਿਨਾਂ ਅਨੁਵਾਦ ਕੰਮ ਦਾ ਅੰਦਾਜ਼ਾ ਲਗਾਉਂਦਾ ਹੈ। ਟੋਕਨ ਅਨੁਮਾਨ ਬਿਲਿੰਗ ਕੋਟ ਨਹੀਂ ਹਨ। ਪਹਿਲੀ ਰਨ ਦੋਹਾਂ Markdown ਫਾਈਲਾਂ ਨੂੰ ਨਵੇਂ ਕੰਮ ਵਜੋਂ ਪਹਿਚਾਣ ਕਰਨੀ ਚਾਹੀਦੀ ਹੈ।

## 3. ਇੱਕ ਪ੍ਰਦਾਤਾ ਚੁਣੋ ਅਤੇ ਅਨੁਵਾਦ ਕਰੋ

ਇੱਕ ਪ੍ਰਦਾਤਾ [ਕੰਫਿਗਰੇਸ਼ਨ ਗਾਈਡ](configuration.md) ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਸੰਰਚਿਤ ਕਰੋ: Azure OpenAI, OpenAI, ਜਾਂ Anthropic। OpenAI ਅਤੇ Anthropic ਟੈਕ스트 ਅਨੁਵਾਦ ਲਈ Azure ਖਾਤਾ ਲਾਜ਼ਮੀ ਨਹੀਂ ਹੈ। ਇਸ ਉਦਾਹਰਨ ਲਈ ਇਮੇਜ ਸੇਵਾਵਾਂ ਦੀ ਲੋੜ ਨਹੀਂ।

ਜੇ ਤੁਸੀਂ ਲੋਕਲ `.env` ਫਾਈਲ ਵਰਤਦੇ ਹੋ, ਤਾਂ `.env` ਨੂੰ ਇਸ ਫੋਲਡਰ ਦੀ `.gitignore` ਵਿੱਚ ਸ਼ਾਮਿਲ ਕਰੋ। ਅਨੁਵਾਦ ਕਾਲ ਤੁਹਾਡੇ ਪ੍ਰੋਵਾਈਡਰ ਖਾਤੇ ਨੂੰ ਵਰਤਦੇ ਹਨ ਅਤੇ ਚਾਰਜ ਲਾਗੂ ਹੋ ਸਕਦੇ ਹਨ।

```bash
translate -l "ko" -md
co-op-review -l "ko"
```

`translations/ko/README.md` ਅਤੇ `translations/ko/guide.md` ਖੋਲ੍ਹੋ। ਕੋਰੀਆਈ ਸ਼ਬਦ-ਚੋਣ, ਕੋਡ ਬਲਾਕ, ਅਤੇ ਅਨੁਵਾਦ ਕੀਤਾ README ਤੋਂ ਅਨੁਵਾਦ ਕੀਤੀ ਗਾਈਡ ਲਈ ਲਿੰਕ ਦੀ ਜਾਂਚ ਕਰੋ। ਆਉਟਪੁੱਟ ਦੀ ਸ਼ਬਦਾਵਲੀ ਮਾਡਲ ਅਨੁਸਾਰ ਵੱਖ-ਵੱਖ ਹੋ ਸਕਦੀ ਹੈ।

`co-op-review` ਤਾਜ਼ਗੀ, ਸੰਰਚਨਾ, ਅਤੇ ਲੋਕਲ ਲਿੰਕਾਂ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ। ਪਾਸ ਨਤੀਜਾ ਭਾਸ਼ਾਈ ਸਹੀਤਾ ਦੀ ਪੁਸ਼ਟੀ ਨਹੀਂ ਕਰਦਾ। جاري ਰੱਖਣ ਤੋਂ ਪਹਿਲਾਂ ਰਿਪੋਰਟ ਕੀਤੀਆਂ ਕਿਸੇ ਵੀ ਗਲਤੀਆਂ ਨੂੰ ਹੱਲ ਕਰੋ।

ਸਫਲ ਬੇਸਲਾਈਨ ਨੂੰ Git ਨਾਲ ਰਿਕਾਰਡ ਕਰੋ (ਜਰੂਰਤ ਹੋਵੇ ਤਾਂ ਪਹਿਲਾਂ ਆਪਣੀ Git ਪਛਾਣ ਸੰਰਚਿਤ ਕਰੋ):

```bash
git add README.md guide.md translations
git commit -m "Record initial Korean translation"
```

## 4. ਸਰੋਤ ਬਦਲੋ

`README.md` ਵਿੱਚ `Notes are saved locally.` ਨੂੰ ਇਹ ਨਾਲ ਬਦਲੋ:

```text
Notes are saved locally as Markdown files.
```

`guide.md` ਨੂੰ ਬਦਲੇ ਬਿਨਾਂ ਛੱਡੋ। ਫਿਰ ਚਲਾਓ:

```bash
co-op-review -l "ko"
translate -l "ko" -md --dry-run
```

ਸਮੀਖਿਆ README ਅਨੁਵਾਦ ਨੂੰ ਪੁਰਾਣਾ ਦਰਸਾਉਂਦੀ ਹੋਈ ਅਤੇ ਅਸਫਲਤਾਪੂਰਵਕ ਬਾਹਰ ਨਿਕਲਣੀ ਚਾਹੀਦੀ ਹੈ। ਇਹ ਉਮੀਦ ਕੀਤੀ ਗਿਆ ਮੱਧਵਰਤੀ ਸਥਿਤੀ ਹੈ। ਪ੍ਰੀਵਿਊ ਬਦਲੇ README ਲਈ ਕੰਮ ਦੀ ਪਛਾਣ ਕਰਨੀ ਚਾਹੀਦੀ ਹੈ।

## 5. ਅਪਡੇਟ ਕਰੋ ਅਤੇ ਡਿਫ ਦੀ ਜਾਂਚ ਕਰੋ

```bash
translate -l "ko" -md
git diff -- README.md translations/ko/README.md
git diff -- translations/ko/guide.md
co-op-review -l "ko"
```

ਅਸਲ ਡਿਫ ਦੀ ਜਾਂਚ ਕਰੋ: ਡਿਫਾਲਟ CLI ਬਦਲੀ ਫਾਈਲ ਨੂੰ ਮੁੜ ਅਨੁਵਾਦ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਮਾਡਲ ਉਸ ਫਾਈਲ ਵਿੱਚ ਹੋਰ ਸ਼ਬਦਾਂ ਨੂੰ ਵੀ ਸੋਧ ਸਕਦਾ ਹੈ। ਬਦਲੇ ਨਹੀਂ ਗਈ ਗਾਈਡ ਵਿੱਚ ਕੋਈ ਡਿਫ ਨਹੀਂ ਹੋਣਾ ਚਾਹੀਦਾ। ਸਮੀਖਿਆ ਹੁਣ README ਨੂੰ ਪੁਰਾਣਾ ਨਹੀਂ ਦੱਸਣੀ ਚਾਹੀਦੀ; ਹੋਰ ਲੱਭੀਆਂ ਚੀਜ਼ਾਂ ਦੀ ਜਾਂਚ ਕਰੋ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ ਨਜ਼ਰਅੰਦਾਜ਼ ਨਾ ਕਰੋ।

ਬਲੌਕ-ਸਤਰੀ ਰੂਪ ਵਿੱਚ ਮਨੁੱਖੀ Markdown ਸੋਧਾਂ ਨੂੰ ਸੰਭਾਲਣ ਲਈ [Python API](api.md) ਵਿੱਚ ਇੱਕ ਵਿਕਲਪਿਕ ਅਨੁਵਾਦ ਸਥਿਤੀ ਪ੍ਰਦਾਤਾ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ। ਇਹ CLI ਕਮਾਂਡਾਂ ਰਾਹੀਂ ਯੋਗ ਨਹੀਂ ਕੀਤਾ ਗਿਆ।

## 6. ਬਿਨਾਂ ਬਦਲਾਅ ਦੇ ਫਿਰ ਤੋਂ ਚਲਾਓ

ਅਪਡੇਟ ਕੀਤਾ ਸਰੋਤ ਅਤੇ ਅਨੁਵਾਦ commit ਕਰੋ:

```bash
git add README.md translations
git commit -m "Update Korean translation after source edit"
translate -l "ko" -md
git diff --exit-code -- translations
```

ਮੌਜੂਦਾ ਅਨੁਵਾਦਾਂ ਅਤੇ ਬਿਨਾਂ ਬਦਲੇ ਸੰਰਚਨਾ ਨਾਲ, ਟ੍ਰਾਂਸਲੇਟਰ ਫਾਈਲਾਂ ਨੂੰ ਛੱਡ ਦੇਵੇਗਾ। ਆਖਰੀ Git ਕਮਾਂਡ ਕੋਈ ਡਿਫ ਨਹੀਂ ਪੈਦਾ ਕਰਨੀ ਚਾਹੀਦੀ ਅਤੇ ਸਫਲਤਾਪੂਰਵਕ ਬਾਹਰ ਨਿਕਲਣਾ ਚਾਹੀਦਾ ਹੈ।
