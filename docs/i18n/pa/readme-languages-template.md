# README ਭਾਸ਼ਾਵਾਂ ਟੈਮਪਲੇਟ

Co-op Translator ਉਹ ਰਿਪੋਜ਼ਟਰੀਆਂ ਲਈ README ਭਾਸ਼ਾ ਟੇਬਲ ਸੰਭਾਲ ਸਕਦਾ ਹੈ ਜੋ ਅਨੁਵਾਦ ਕੀਤੀ ਸਮੱਗਰੀ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਦੀਆਂ ਹਨ।

ਜੇ ਤੁਸੀਂ ਚਾਹੁੰਦੇ ਹੋ ਕਿ Co-op Translator ਹਰ ਅਨੁਵਾਦ ਦੌਰ 'ਤੇ ਪੂਰੇ ਭਾਗ ਨੂੰ ਬਦਲ ਦੇਵੇ ਤਾਂ ਹੇਠਾਂ ਦਿੱਤੇ ਮਾਰਕਰ ਵਰਤੋ। ਜੇ ਤੁਸੀਂ ਮੈਨੁਅਲ ਤੌਰ 'ਤੇ ਆਪਣਾ ਕਸਟਮ ਉਪਸੈੱਟ ਰੱਖਣਾ ਪਸੰਦ ਕਰਦੇ ਹੋ ਤਾਂ ਮਾਰਕਰ ਹਟਾ ਦਿਓ।

ਮਾਰਕਰਾਂ ਤੋਂ ਉੱਪਰ ਦਿੱਤਾ ਗਿਆ attribution ਅਤੇ getting-started ਲਿੰਕ ਵਿਕਲਪੀ ਹਨ। ਇਹ ਪਾਠਕਾਂ ਨੂੰ ਇਹ ਪਤਾ ਲਗਾਉਣ ਵਿੱਚ ਮਦਦ ਕਰਦੇ ਹਨ ਕਿ ਅਨੁਵਾਦ ਕਿਵੇਂ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ ਅਤੇ ਉਹ ਆਪਣੇ ਰਿਪੋਜ਼ਟਰੀਆਂ ਦਾ ਅਨੁਵਾਦ ਕਿਵੇਂ ਕਰ ਸਕਦੇ ਹਨ। ਉਨ੍ਹਾਂ ਨੂੰ ਮਾਰਕਰਾਂ ਤੋਂ ਬਾਹਰ ਰੱਖੋ ਤਾਂ ਜੋ ਭਾਸ਼ਾ-ਟੇਬਲ ਅੱਪਡੇਟ ਉਹਨਾਂ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖ ਸਕੇ। ਜਦੋਂ ਤੁਸੀਂ ਕਿਸੇ ਹੋਰ ਰਿਪੋਜ਼ਟਰੀ ਨੂੰ ਅੱਪਡੇਟ ਕਰ ਰਹੇ ਹੋ, ਉਸ ਦੀਆਂ ਯੋਗਦਾਨ ਦਿਸ਼ਾ-ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ ਅਤੇ ਉਸਦੇ ਮੇਨਟੇਨਰਾਂ ਨੂੰ ਇਹ ਫੈਸਲਾ ਕਰਨ ਦਿਓ ਕਿ ਕੀ ਇਹ ਲਿਖਤ ਸ਼ਾਮਿਲ ਕਰਨੀ ਹੈ।

> **Prefer to Clone Locally?**
>
> This repository includes many language translations, which can significantly increase download size. To clone without translations, use sparse checkout:
>
> ```bash
> git clone --filter=blob:none --sparse https://github.com/org/repo.git
> cd repo
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
