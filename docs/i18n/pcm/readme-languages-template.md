# Template wey dem dey use for README Languages

Co-op Translator fit maintain a README language table for repositories wey dey publish translated content.

Use the markers wey dey below when you want Co-op Translator to replace the whole section every translation run. Remove the markers if you wan maintain custom subset by hand.

The attribution and getting-started link wey dey above the markers na optional. Dem dey help readers find how translations dey maintained and how dem fit translate their own repositories. Keep dem outside the markers so language-table updates no go remove dem. When you dey update another repository, follow im contribution guidelines and make the maintainers decide whether dem go include this text.

> **Prefer to Clone Locally?**
>
> This repository includes many language translations, which can significantly increase download size. To clone without translations, use sparse checkout:
>
> ```bash
> git clone --filter=blob:none --sparse https://github.com/org/repo.git
> cd repo
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```

```bash
translate -l "ko" --repo-url "https://github.com/org/repo.git"
```

If the markers dey, Co-op Translator fit update the generated table when languages dey added or change.

For an existing README, you fit add the optional attribution and getting-started link above im language-table markers without replacing im language links or other content. Point supported-language links to the [guide for the current language](https://github.com/Azure/co-op-translator/blob/main/docs/supported-languages.md).
