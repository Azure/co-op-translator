# Șablon README pentru limbi

Co-op Translator poate menține un tabel de limbi în README pentru depozitele care publică conținut tradus.

Folosiți marcatorii de mai jos când doriți ca Co-op Translator să înlocuiască întreaga secțiune la fiecare rulare a traducerii. Eliminați marcatorii dacă preferați să mențineți manual un subset personalizat.

Atribuirea și linkul de pornire (getting-started) de deasupra marcatorilor sunt opționale. Ele îi ajută pe cititori să descopere cum sunt întreținute traducerile și cum să-și traducă propriile depozite. Păstrați-le în afara marcatorilor astfel încât actualizările tabelului de limbi să le păstreze. Când actualizați un alt depozit, urmați ghidul de contribuție și lăsați întreținătorii să decidă dacă includ acest text.

````markdown
### Multi-Language Support

#### Supported by [Co-op Translator](https://github.com/Azure/co-op-translator)

Maintain your own documentation? [Start with one README and one language](https://github.com/Azure/co-op-translator/blob/main/docs/github-actions.md#your-first-readme-translation-pr).

> **Prefer to Clone Locally?**
>
> This repository includes many language translations, which can significantly increase download size. To clone without translations, use sparse checkout:
>
> ```bash
> git clone --filter=blob:none --sparse https://github.com/org/repo.git
> cd repo
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```

````

Personalizați URL-ul repository-ului sparse-checkout în timpul traducerii:

```bash
translate -l "ko" --repo-url "https://github.com/org/repo.git"
```

Dacă marcatorii sunt prezenți, Co-op Translator poate actualiza tabelul generat atunci când limbile sunt adăugate sau modificate.

Pentru un README existent, puteți adăuga atribuirea opțională și linkul getting-started de deasupra marcatorilor tabelului de limbi fără a înlocui linkurile limbilor sau alt conținut. Indicați linkurile limbilor acceptate către [ghidul limbii curente](https://github.com/Azure/co-op-translator/blob/main/docs/supported-languages.md).
