# Преведи, уреди и прегледај мали пројекат

Почните са два кратка Markdown фајла и једним циљним језиком. Видећете где се преводи записују, шта се дешава када се извор промени и како проверити резултат.

## Забележени резултати

Пример је покренут 19. септембра 2026. са Co-op Translator 0.21.0 и Azure OpenAI (`gpt-5-mini`). Немодификоване CLI команде су позване преко Click-овог `CliRunner` користећи изграђен wheel и постојеће Python зависности.

| Корак | Резултат |
| --- | --- |
| Преглед | Излаз 0; није захтеван превод моделом |
| Почетни превод | Излаз 0; 27.36 секунди |
| Почетни преглед | Излаз 0 |
| Уреди README и прегледај | Излаз 1; откривен застарео превод |
| Ажурирај превод | Излаз 0; 22.17 секунди |
| Преглед након ажурирања | Излаз 0; нема грешака или упозорења |
| Непромењен водич | Идентични бајтови пре и после ажурирања README-а |
| Покрени поново | Излаз 0; идентични хешеви за све фајлове превода |

Ово су мерења појединачних покретања, а не гаранције перформанси. Време подешавања је искључено; наплата провајдера није мерена. Покретање без промена и даље може извршити проверу здравља провајдера.

Прегледајте [почетни превод](../../assets/demo/before.txt), [ажурирани превод](../../assets/demo/after.txt), [комплетан diff превода](../../assets/demo/update.diff), [застарели преглед](../../assets/demo/review-stale.txt), [финални преглед](../../assets/demo/review-after.txt), и [подаци о покретању](../../assets/demo/results.json). Превод целог фајла може променити друге формулације, као што показује заробљени diff. Оба текстуална артефакта задржавају генерисано одрицање.

Ручни преглед и даље је важан: захваћено ажурирање користи `[사용 가이드](guide.md)을`; корејски део би требао бити `[사용 가이드](guide.md)를`. Текстуални артефакти задржавају овај излаз нетакнут уместо да приказују уређени превод као излаз модела. Структурни преглед пролази упркос овом проблему у формулацији.

## 1. Припремите мали фолдер

Користите Python 3.11–3.14 и [подешавање виртуелног окружења](configuration.md#local-runtime-setup). Инсталирајте верзију коришћену за овај пример:

```bash
python -m pip install co-op-translator==0.21.0
mkdir translation-demo
cd translation-demo
git init
```

Преузмите [README.txt](../../assets/demo/README.txt) и [guide.txt](../../assets/demo/guide.txt) у овај фолдер, сачувајте их као `README.md` и `guide.md`. То су мали фиктивни пројектни документи; није потребна инсталација апликације.

README садржи блок кода и линк ка `guide.md`. Његова последња реченица је:

```text
Notes are saved locally.
```

Задржите само ова два извора у овом фолдеру. Све следеће команде покрећу се унутар `translation-demo` и раде у Bash-у и PowerShell-у.

## 2. Преглед без акредитива

```bash
translate -l "ko" -md --dry-run
```

Преглед процењује посао превођења без позивања модела или писања превода. Процене броја токена нису трошковни извештај. Прво покретање треба да идентификује оба Markdown фајла као нови посао.

## 3. Изаберите провајдера и преведите

Конфигуришите једног провајдера користећи [водич за конфигурацију](configuration.md): Azure OpenAI, OpenAI или Anthropic. OpenAI и Anthropic превод текста не захтевају Azure налог. Услуге за слике нису потребне за овај пример.

Ако користите локални `.env` фајл, додајте `.env` у `.gitignore` овог фолдера. Позиви за превод користе налог вашег провајдера и могу настати трошкови.

```bash
translate -l "ko" -md
co-op-review -l "ko"
```

Отворите `translations/ko/README.md` и `translations/ko/guide.md`. Проверите корејску формулацију, блок кода и линк из преведеног README-а ка преведеном водичу. Формулације изласа варирају по моделу.

`co-op-review` проверава свежину, структуру и локалне линкове. Прошли резултат не гарантује лингвистичку тачност. Решите све пријављене грешке пре наставка.

Забележите успешну почетну тачку са Git-ом (прво конфигуришите свој Git идентитет ако је потребно):

```bash
git add README.md guide.md translations
git commit -m "Record initial Korean translation"
```

## 4. Промените извор

У `README.md` замените `Notes are saved locally.` са:

```text
Notes are saved locally as Markdown files.
```

Оставите `guide.md` непромењен. Затим покрените:

```bash
co-op-review -l "ko"
translate -l "ko" -md --dry-run
```

Преглед би требало да прикаже да је превод README-а застарео и да заврши неуспешно. Ово је очекиван посредни статус. Преглед би требао идентификовати посао за промењени README.

## 5. Ажурирајте и прегледајте diff

```bash
translate -l "ko" -md
git diff -- README.md translations/ko/README.md
git diff -- translations/ko/guide.md
co-op-review -l "ko"
```

Прегледајте стварни diff: подразумевани CLI поново преводи промењени фајл, па модел може и да ревидира другу формулацију у том фајлу. Непромењени водич не би требало да има разлику. Преглед више не би требао пријављивати README као застарео; испитајте свака друга открића уместо да их игноришете.

Сачување на нивоу блокова људских Markdown измена захтева опциони провајдер стања превода у [Python API](api.md). То није омогућено овим CLI командама.

## 6. Покрените поново без промена

Комитујте ажуриран извор и превод:

```bash
git add README.md translations
git commit -m "Update Korean translation after source edit"
translate -l "ko" -md
git diff --exit-code -- translations
```

Са тренутним преводима и непромењеном конфигурацијом, преводилац прескаче фајлове. Коначна Git команда не би требало да произведе разлику и треба да заврши успешно.
