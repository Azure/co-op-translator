## Ongeza Lugha

Ili kuongeza msaada kwa lugha mpya:

1. Ongeza kodi ya lugha na jina la kuonyesha kwenye zana za lugha.
2. Ongeza au ramisha fonti katika `src/co_op_translator/fonts/font_language_mappings.yml`.
3. Jaribu matokeo ya tafsiri ya Markdown na picha.
4. Fungua pull request yenye ramani na maelezo ya uthibitisho.
