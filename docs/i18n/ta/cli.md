# CLI குறிப்பு

Co-op Translator பின்வரும் கட்டளை-வரிசை நுழைவு புள்ளிகளை நிறுவுகிறது:

- `translate`
- `evaluate`
- `migrate-links`
- `co-op-review`
- `co-op-translator-mcp`

`translate`, `evaluate`, `migrate-links`, மற்றும் `co-op-review` கட்டளைகள் `co_op_translator.__main__` மூலம் அனுப்பப்படுகின்றன; இது அழைக்கப்படும் ஸ்கிரிப்ட் பெயரின்படி கட்டளை அமலாக்கத்தினை தேர்ந்தெடுக்கிறது. MCP சர்வர் நேரடியாக `co_op_translator.mcp.server` ஐ பயன்படுத்துகிறது.

CLI, Python API, மற்றும் MCP ஆகியவற்றுக்கிடையில் முடிவெடுக்கும் போது, முதலில் [உங்கள் வேலைவழியைத் தேர்ந்தெடுக்கவும்](workflows.md).

## கமாண்ட்-லைன் வெளியீடு

தொடர்புப்பாவனைக்கான டெர்மினல்களில் தலைப்பு, முன்னேற்றம், மற்றும் சுருக்கங்களுக்கு Rich வடிவமைப்பு பயன்படுத்தப்படுகிறது. CI மற்றும் எதிர்மறை தொடர்பின்றி வெளியீடுகள் தானாகவே சாதாரண உரையாக மாறும்.

சாதாரண வெளியீட்டை جبற்படுத்த `CO_OP_TRANSLATOR_OUTPUT_STYLE=plain` ஐ அமைக்கவும், அல்லது Rich வெளியீட்டை جبற்படுத்த `CO_OP_TRANSLATOR_OUTPUT_STYLE=rich` ஐ அமைக்கவும். நேரடி முன்னேற்ற பட்டைகளை ஒதுக்கி சுருக்கங்களை வைத்திருக்க `CO_OP_TRANSLATOR_NO_PROGRESS=1` ஐ அமைக்கவும்.

மற்றொரு அமைப்பு மெஷின்-படிக்கக் கூடிய முன்னேற்றத்தை தேவைப்படும் போது `translate --json-events progress.ndjson` ஐ பயன்படுத்தவும். CLI மனிதனுக்கான வெளியீட்டை தொடர்ச்சியாக காட்டும் போது, NDJSON கோப்பு பதிப்பிடப்பட்ட `co-op.translation.event.v1` நிகழ்வுகளை பெறும்; இதில் `type`, `stage_key`, `completed`, `total`, மற்றும் `current_path` போன்ற நிலையான புலங்கள் இருக்கும்.





## முதன்முறைக் CLI ஓட்டம்

டெர்மினலில் Co-op Translator ஐப் பயன்படுத்தினால் இங்கு தொடங்குங்கள்:

1. [கட்டமைப்பு](configuration.md) இல் விளக்கப்படுமாறு ஒரு LLM வழங்குநரை உள்ளமைக்கவும்.
2. நீங்கள் மொழிபெயர்க்க விரும்பும் உள்ளடக்க வகையை தேர்வு செய்யவும்.
3. முதலில் ஒரு மையமாக்கப்பட்ட கட்டளையை இயக்குங்கள், உதாரணமாக Markdown மட்டும் மொழிபெயர்ப்பு.
4. பெரிய ரெப்போ மாற்றங்களுக்கு முன் `--dry-run` ஐ பயன்படுத்தவும்.
5. மொழிபெயர்ப்புக்குப் பிறகு அமைப்பு மற்றும் تازா நிலையை சரிபார்க்க `co-op-review` ஐ பயன்படுத்தவும்.

| நோக்கம் | தொடக்கக் கட்டளை |
| --- | --- |
| Markdown ஆவணங்களை மொழிபெயர்க்க | `translate -l "ko" -md` |
| நோட்புக்குகளை மொழிபெயர்க்க | `translate -l "ko" -nb` |
| படங்களில் உள்ள உரையை மொழிபெயர்க்க | `translate -l "ko" -img` |
| கோப்புகளை எழுதாமல் பணியை முன்னோட்டம் பார்க்க | `translate -l "ko" -md --dry-run` |
| קיימமுள்ள மொழிபெயர்ப்புகளை முடிவாய்வு செய்ய | `co-op-review -l "ko"` |
| நோட்புக் மற்றும் Markdown இணைப்புகளை புதுப்பிக்க | `migrate-links -l "ko" --dry-run` |
| கருவிகளைக் MCP கிளையன்டுக்கு வெளியிட | CLI கட்டளைகளை நேரடியாக இயக்கு பதிலாக [MCP Server](mcp.md) ஐ கட்டமைக்கவும். |

## translate

Markdown கோப்புகள், நோட்புக்குகள், மற்றும் படங்களில் உள்ள உரைகளை ஒரு அல்லது அதற்கு மேற்பட்ட இலக்கு மொழிகளுக்கு மொழிபெயர்க்கிறது.

```bash
translate -l "ko ja fr"
```

### பொதுவான உதாரணங்கள்

Markdown மட்டும் மொழிபெயர்க்க:

```bash
translate -l "de" -md
```

நோட்புக்குகள் மட்டும் மொழிபெயர்க்க:

```bash
translate -l "zh-CN" -nb
```

Markdown மற்றும் படங்களை மொழிபெயர்க்க:

```bash
translate -l "pt-BR" -md -img
```

இருக்கும் மொழிபெயர்ப்புகளை நீக்கி மீண்டும் உருவாக்கி புதுப்பிக்க:

```bash
translate -l "ko" -u
```

தொடர்பு கேள்விகள் இல்லாமல் இயக்க:

```bash
translate -l "ko ja" -md -y
```

பதிவுகளை சேமிக்க:

```bash
translate -l "ko" -s
```

கட்டமைக்கப்பட்ட முன்னேற்ற நிகழ்வுகளை எழுத:

```bash
translate -l "ko ja" -md --json-events progress.ndjson
```

### விருப்பங்கள்

| விருப்பம் | தேவை | விளக்கம் |
| --- | --- | --- |
| `-l`, `--language-codes` | ஆம் | இடைவெளியால் பிரிக்கப்பட்ட மொழிக் குறியீடுகள், உதாரணமாக `"es fr de"`, அல்லது `"all"`. |
| `-r`, `--root-dir` | இல்லை | திட்டத்தின் ரூட். இயல்பாக தற்போதைய அடைவாகும். |
| `-u`, `--update` | இல்லை | தேர்ந்தெடுக்கப்பட்ட மொழிகளுக்கான இருக்கும் மொழிபெயர்ப்புகளை நீக்கி மீண்டும் உருவாக்கும். |
| `-img`, `--images` | இல்லை | படக் கோப்புகளை மட்டும் மொழிபெயர்க்க. |
| `-md`, `--markdown` | இல்லை | Markdown கோப்புகளை மட்டும் மொழிபெயர்க்க. |
| `-nb`, `--notebook` | இல்லை | Jupyter நோட்புக் கோப்புகளை மட்டும் மொழிபெயர்க்க. |
| `-d`, `--debug` | இல்லை | கான்சோலில் டீபக் பதிவு இயக்கவும். |
| `-s`, `--save-logs` | இல்லை | DEBUG-தரப்புத் பதிவுகளை `<root-dir>/logs/` கீழ் சேமிக்கவும். |
| `--json-events` | இல்லை | மெஷின்-படிக்கக்கூடிய மொழிபெயர்ப்பு முன்னேற்ற நிகழ்வுகளை NDJSON ஆக எழுதுக. |
| `-x`, `--fix` | இல்லை | முந்தைய மதிப்பீட்டு முடிவுகளின் அடிப்படையில் குறைந்த நம்பிக்கை கொண்ட Markdown கோப்புகளை மறுபடியும் மொழிபெயர்க்க. |
| `-c`, `--min-confidence` | இல்லை | `--fix` பயன்பாட்டிற்கான நம்பிக்கை சிக்மை. இயல்பாக `0.7`. |
| `--add-disclaimer`, `--no-disclaimer` | இல்லை | மெஷின் மொழிபெயர்ப்புக்கான பண்பட்ட நிரூபணங்களைச் சேர்க்க அல்லது ஒதுக்க. CLI இல் இயல்பாக செயல்பாட்டில் உள்ளது. |
| `-f`, `--fast` | இல்லை | பழையவாகிய விரைவு பட முறையை ஒதுக்கப்பட்டுள்ளது. |
| `-y`, `--yes` | இல்லை | கேள்விகளை தானாக ஒப்புதல்; CI இல் பயனுள்ளதாகும். |
| `--repo-url` | இல்லை | README மொழி அட்டவணையின் sparse-checkout ஆலோசனையில் பயன்படுத்தப்படும் ரெப்போ URL. |
| `--migrate-language-folders` | இல்லை | `cn` அல்லது `tw` போன்ற பழைய அலையாக வழங்கப்பட்ட அடைவுகளை canonical BCP 47 அடைவுகளாக மறுபெயர்க்க. |
| `--dry-run` | இல்லை | கோப்புகளை எழுதாமல் மொழி அடைவு மாற்றமும் மொழிபெயர்ப்பு மதிப்பீடுகளின் முன்னோட்டத்தையும் காண்பிக்க. |

எந்த வகைப் பிளாக் கொடுக்கப்படாவிட்டால், `translate` Markdown, நோட்புக்குகள் மற்றும் படங்களை செயல்படுத்தும். பட மொழிபெயர்ப்பிற்கு Azure AI Vision கட்டமைப்புத் தேவைப்படும்.

## evaluate

ஒரு மொழிக்கான மொழிபெயர்க்கப்பட்ட Markdown தரத்தை மதிப்பீடு செய்க.

!!! warning "பரிசோதனை"
    `evaluate` பரிசோதனை நிலை உள்ளது. இது விதி-அடிப்படையிலான மற்றும் LLM-அடிப்படையிலான தரச் சரிபார்ப்புகளைப் பயன்படுத்தக்கூடும், மதிப்பீட்டு முடிவுகளை மொழிபெயர்ப்பு மெட்டாடேட்டாவிலே எழுதுகிறது, மேலும் அதன் மதிப்பீட்டு மாதிரியும் மெட்டாடேட்டா நடத்தையும் மாறக்கூடும்.

```bash
evaluate -l "ko"
```

### பொதுவான உதாரணங்கள்

கடுமையான குறைந்த நம்பிக்கை சிக்மையைப் பயன்படுத்த:

```bash
evaluate -l "es" -c 0.8
```

விதி-அடிப்படையிலான சரிபார்ப்புகள் மட்டும் இயக்க:

```bash
evaluate -l "fr" -f
```

LLM-அடிப்படையிலான சரிபார்ப்புகள் மட்டும் இயக்க:

```bash
evaluate -l "ja" -D
```

### விருப்பங்கள்

| விருப்பம் | தேவை | விளக்கம் |
| --- | --- | --- |
| `-l`, `--language-code` | ஆம் | மதிப்பீடு செய்ய ஒரே மொழிக் குறியீடு. இணை குறியீடுகள் சாதாரணமாக்கப்படுகின்றன. |
| `-r`, `--root-dir` | இல்லை | திட்டத்தின் ரூட். இயல்பாக தற்போதைய அடைவு. |
| `-c`, `--min-confidence` | இல்லை | குறைந்த நம்பிக்கை மொழிபெயர்ப்புகளை பட்டியலிட பயன்படும் சிக்மை. இயல்பாக `0.7`. |
| `-d`, `--debug` | இல்லை | டீபக் பதிவு இயக்கவும். |
| `-s`, `--save-logs` | இல்லை | DEBUG-தரப் பதிவுகளை `<root-dir>/logs/` கீழ் சேமிக்கவும். |
| `-f`, `--fast` | இல்லை | விதி-அடிப்படையிலான மதிப்பீடு மட்டுமே. |
| `-D`, `--deep` | இல்லை | LLM-அடிப்படையிலான மதிப்பீடு மட்டுமே. |

இயல்பாக, `evaluate` இரண்டு விதி-அடிப்படையையும் LLM-அடிப்படையையும் பயன்படுத்தும். முடிவுகள் மொழிபெயர்ப்பு மெட்டாடேட்டாவிற்குள் எழுதப்பட்டு கான்ஸோலில் சுருக்கமாக காண்பிக்கப்படுகின்றன.

## co-op-review

API πισுரீடென்ஷயல்களை இல்லாமல் தீர்மானமான (deterministic) மொழிபெயர்ப்பு பராமரிப்பு சரிபார்ப்புகளை இயக்கவும்.

!!! note "பீட்டா"
    `co-op-review` ஒரு பீட்டா தீர்மானமான பரோசனை கட்டளை. இது மாதிரி வழங்குநர்களை அழைக்கும் அல்லது கோப்புகளை எழுதாது, ஆனால் அதன் சரிபார்ப்புகள் மற்றும் குறைபாடு வெளியீட்டு சிக்கலான அமைப்பு (schema) மாற்றப்படக்கூடும்.

```bash
co-op-review -l "ko"
```

### பொதுவான உதாரணங்கள்

தற்போதைய அடைவிலிருந்து கொரிய மற்றும் ஜப்பானிய மொழிபெயர்ப்புகளை ஆய்வு செய்ய:

```bash
co-op-review -l "ko ja"
```

ஒரு குறிப்பிட்ட திட்ட ரூட் ஐ ஆய்வு செய்ய:

```bash
co-op-review -l "fr" -r ./my-course
```

README மட்டுமே மொழிபெயர்ப்புக்குப் பின்னர் README ஐ மட்டும் ஆய்வு செய்ய:

```bash
translate -l "ko" --readme-only -y
co-op-review -l "ko" --readme-only --format github
```

`--readme-only` மற்ற ஆவணங்களையும் உள்ளடக்க README-களையும் பொருட்படாமல் புறக்கணிக்கும். மூல
`README.md` காணவில்லை எனில் அது தோல்வி அடையும். `--changed-from` உடன் சேர்த்தால், இது மூல கோப்பு மாற்றப்பட்டிருந்தால் மட்டுமே README-வை ஆய்வு செய்யும். README மட்டுமே மொழிபெயர்ப்பு மூல README-வை மாற்றாது, பொதுவாக பகிர்ந்துச் உள்ள பகுதியில் உள்ள குறிச்சொற்களும் அடங்கும்.



ஒரு அடித்தள ref உடன் மாற்றப்பட்ட மூல கோப்புகளை மட்டும் ஆய்வு செய்ய:

```bash
co-op-review -l "ko" --changed-from origin/main
```

CI சுருக்கங்களுக்கு GitHub-ஐ பாணி வகையின் Markdown வெளியீட்டை அச்சிட:

```bash
co-op-review -l "ko ja" --changed-from origin/main --format github
```

### விருப்பங்கள்

| விருப்பம் | தேவை | விளக்கம் |
| --- | --- | --- |
| `-l`, `--language-code` | இல்லை | ஆய்வு செய்ய மொழிக் குறியீடு. பல முறை கொடுக்கலாம் அல்லது இடைவெளியால் பிரிக்கப்பட்ட மதிப்பாக கொடுக்கலாம். கண்டுபிடிக்கப்பட்ட அனைத்து மொழிகளுக்கும் இயல்பாகயும். |
| `-r`, `--root-dir` | இல்லை | திட்டத்தின் ரூட். இயல்பாக தற்போதைய அடைவு. |
| `--changed-from` | இல்லை | மாற்றப்பட்ட மூல கோப்புகளுக்காக ஆய்வை வரையறுக்கும் Git ref. |
| `--readme-only` | இல்லை | ரூட் `README.md` மொழிபெயர்ப்பையே மட்டும் ஆய்வு செய்யவும். |
| `--format` | இல்லை | வெளியீடு வடிவம்: `text` அல்லது `github`. இயல்பாக `text`. |

`co-op-review` தற்போது காணாமல் போன மொழிபெயர்ப்புகள், காணாமல் போன அல்லது பழைய மொழிபெயர்ப்பு மெட்டாடேட்டா, Markdown முன்குறிப்புகள் மற்றும் குறியீட்டு கம்பிகள் நுணுக்கம், தவறான மொழிபெயர்க்கப்பட்ட நோட்புக் JSON, மற்றும் உள்ளூர் Markdown அல்லது பட இணைப்பு இலக்குகள் காணாமை ஆகியவற்றைப் சரிபார்க்கிறது. காணாமல் போன இணைப்புகள் வழக்கமாக எச்சரிக்கையாக காணப்படுகின்றன; கட்டமைப்பு மற்றும் تازா நிலை பிரச்சினைகள் கட்டளையை தோல்வி செய்யும்.

## co-op-translator-mcp

முகவரிகள், எடிட்டர்கள் மற்றும் MCP-உடன் இணக்கமான கிளையன்டுகளுக்காக Co-op Translator MCP சர்வரை இயக்கவும்.

```bash
co-op-translator-mcp
```

இயல்புநிலை போக்குவரத்து `stdio` ஆகும். கிளையன்ட் கட்டமைப்பு, கருவிகள், வளங்கள் மற்றும் பாதுகாப்பு குறிப்புகளுக்காக [MCP Server](mcp.md) வழிகாட்டியைப் பார்க்கவும்.

### விருப்பங்கள்

| விருப்பம் | தேவை | விளக்கம் |
| --- | --- | --- |
| `--transport` | இல்லை | MCP போக்குவரத்து: `stdio`, `streamable-http`, அல்லது `sse`. இயல்பாக `stdio`. |

## migrate-links

மொழிபெயர்க்கப்பட்ட Markdown கோப்புகளை மீண்டும் செயலாக்கி, மொழிபெயரிக்கப்பட்ட நோட்புக்குகள் கிடைக்கும் பட்சத்தில் நோட்புக் இணைப்புகளை அவற்றுக்குச் சுட்டி புதுப்பிக்கவும்.

```bash
migrate-links -l "ko ja"
```

### பொதுவான உதாரணங்கள்

இணைப்பு புதுப்பிப்புகளை முன்னோட்டமாக பார்க்க:

```bash
migrate-links -l "ko" --dry-run
```

அனைத்து ஆதரிக்கப்படும் மொழிகளையும் படிப்படியாக உறுதிப்படுத்தாது செயலாக்க:

```bash
migrate-links -l "all" -y
```

மாற்ற மொழிபெயர்க்கப்பட்ட நோட்புக்குகள் இருக்கும் போது மட்டும் இணைப்புகளை மீலெழுது:

```bash
migrate-links -l "ko" --no-fallback-to-original
```

### விருப்பங்கள்

| விருப்பம் | தேவை | விளக்கம் |
| --- | --- | --- |
| `-l`, `--language-codes` | ஆம் | இடைவெளியால் பிரிக்கப்பட்ட மொழிக் குறியீடுகள், அல்லது `"all"`. |
| `-r`, `--root-dir` | இல்லை | திட்டத்தின் ரூட். இயல்பாக தற்போதைய அடைவு. |
| `--image-dir` | இல்லை | ரூட் அடைவிற்கு wzglுத்தப்பட்ட மொழிபெயர்க்கப்பட்ட பட அடைவு. இயல்பாக `translated_images`. |
| `--dry-run` | இல்லை | மாற்றங்களை எழுதாமல் எந்த கோப்புகள் மாறுமோ காட்டவும். |
| `--fallback-to-original`, `--no-fallback-to-original` | இல்லை | மொழிபெயர்க்கப்பட்ட நோட்புக்குகள் இல்லாதபட்சத்தில் மூல நோட்புக் இணைப்புகளை பயன்படுத்துக. இயல்பாக இயல்பாக सक्षम. |
| `-d`, `--debug` | இல்லை | டீபக் பதிவு இயக்கவும். |
| `-s`, `--save-logs` | இல்லை | DEBUG-தரப் பதிவுகளை `<root-dir>/logs/` கீழ் சேமிக்கவும். |
| `-y`, `--yes` | இல்லை | அனைத்து மொழிகளையும் செயலாக்கும்போது கேள்விகளை தானாக ஒப்புதல். |

## சூழல்

ஒரு கட்டளை வழங்குநர் நற்சான்றிதழ்களை தேவை்படுத்தும் போது, இந்த வழங்குநர் தொகுதிகளில் ஒன்றை உள்ளமைக்கவும். `translate --dry-run` மற்றும் `co-op-review` வழங்குநர் நற்சான்றிதழ்களைத் தேவைப்படுத்தாது:

```bash
# Azure OpenAI
AZURE_OPENAI_API_KEY="..."
AZURE_OPENAI_ENDPOINT="https://<resource>.openai.azure.com/"
AZURE_OPENAI_MODEL_NAME="gpt-4o"
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME="<deployment>"
AZURE_OPENAI_API_VERSION="2024-12-01-preview"

# அல்லது OpenAI
OPENAI_API_KEY="..."
OPENAI_CHAT_MODEL_ID="gpt-4o"

# அல்லது Anthropic
ANTHROPIC_API_KEY="..."
ANTHROPIC_MODEL="claude-..."
```

பட மொழிபெயர்ப்பிற்கு கூடுதலாக Azure AI Vision தேவையாகும்:

```bash
AZURE_AI_SERVICE_API_KEY="..."
AZURE_AI_SERVICE_ENDPOINT="https://<resource>.cognitiveservices.azure.com/"
```

## வெளியீடு அமைப்பு

உரை மொழிபெயர்ப்புகள் கீழ்க்கண்ட இடத்தில் எழுதப்படுகின்றன:

```text
translations/<language-code>/<original-path>
```

மொழிபெயர்க்கப்பட்ட பட வெளியீடுகள் கீழ்க்கண்ட இடத்தில் எழுதப்படுகின்றன:

```text
translated_images/<language-code>/<original-path>
```

உதாரணமாக, `README.md` மற்றும் `docs/setup.md` ஐ கொரிய மொழிக்கு மொழிபெயர்க்கும் போது உருவாகும்:

```text
translations/ko/README.md
translations/ko/docs/setup.md
```

## நகல்-ஒட்டுதல் CLI உதாரணங்கள்

Markdown ஐ மூன்று மொழிகளுக்கு மொழிபெயர்க்க:

```bash
translate -l "ko ja fr" -md
```

நோட்புக்குகளை மட்டும் மொழிபெயர்க்க:

```bash
translate -l "zh-CN" -nb
```

படங்களை மட்டும் மொழிபெயர்க்க:

```bash
translate -l "pt-BR" -img
```

கோப்புகளை எழுதாமல் Markdown மொழிபெயர்ப்பை முன்னோட்டம் காண:

```bash
translate -l "de es" -md --dry-run
```

குறைந்த நம்பிக்கை கொண்ட Markdown மொழிபெயர்ப்புகளை சரி செய்:

```bash
evaluate -l "ko" -c 0.8
translate -l "ko" --fix -c 0.8 -md
```

CI-உகந்த Markdown மொழிபெயர்ப்பு இயக்கு:

```bash
translate -l "ko ja" -md -y -s
```

மொழிபெயர்த்த வெளியீடுகளை ஆய்வு செய்ய:

```bash
co-op-review -l "ko ja"
```

இணைப்பு மாற்றத்தை முன்னோட்டமாக பார்க்க:

```bash
migrate-links -l "ko" --dry-run
```
