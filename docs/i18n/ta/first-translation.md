# ஒரு சிறிய திட்டத்தை மொழிபெயர்ப்பு, திருத்தம் மற்றும் மதிப்பாய்வு

இரண்டு சிறிய மார்க்டவுன் கோப்புகள் மற்றும் ஒரு இலக்கு மொழியுடன் துவங்குங்கள். மொழிபெயர்ப்புகள் எங்கு எழுதப்படுகின்றன, மூல உள்ளடக்கம் மாற்றப்பட்டால் என்ன நடக்கும், மற்றும் முடிவை எப்படி சரிபார்க்குவது என்பதைக் காண்பீர்கள்.

## பதிவுசெய்யப்பட்ட முடிவுகள்

இந்த எடுத்துக்காட்டு 2026 செப்டம்பர் 19 அன்று Co-op Translator 0.21.0 மற்றும் Azure OpenAI (`gpt-5-mini`) உடன் இயக்கப்பட்டது. மாற்றமில்லாத CLI கட்டளைகள் கட்டப்பட்ட வீல் மற்றும் உள்ள Python சார்ந்த இழைமைகளைக் பயன்படுத்தி Click இன் `CliRunner` வழியாக அழைக்கப்பட்டன.

| படி | முடிவு |
| --- | --- |
| முன்னோக்கம் | Exit 0; மாதிரி மொழிபெயர்ப்பு கோரப்படவில்லை |
| ஆரம்ப மொழிபெயர்ப்பு | Exit 0; 27.36 விநாடிகள் |
| ஆரம்ப மதிப்பாய்வு | Exit 0 |
| README ஐ திருத்தி மதிப்பாய்வு | Exit 1; பழைய மொழிபெயர்ப்பு கண்டறியப்பட்டது |
| மொழிபெயரிப்பு புதுப்பிப்பு | Exit 0; 22.17 விநாடிகள் |
| புதுப்பிப்பின் பின் மதிப்பாய்வு | Exit 0; பிழைகள் அல்லது எச்சரிப்புகள் இல்லை |
| மாற்றமில்லாத வழிகாட்டி | README புதுப்பிப்புக்கு முந்தையதும் பின்னதும் அதே பைடுகள் |
| மீண்டும் இயக்கவும் | Exit 0; அனைத்து மொழிபெயர்ப்பு கோப்புகளுக்கும் ஒரே ஹாஷ் மதிப்புகள் |

இவை தனித்தனி இயக்க அளவீடுகள்; செயல்திறன் உறுதிப்பாடுகள் அல்ல. அமைப்பு நேரம் சேர்க்கப்படவில்லை; வழங்குநர் பில்லிங் அளவீடு செய்யப்படவில்லை. மாற்றமின்றி ஒரு ரன் கூட வழங்குநர் ஆரோக்கியச் சோதனையைச் செய்யலாம்.

பரிசீலிக்கவும் [ஆரம்ப மொழிபெயர்ப்பு](../../assets/demo/before.txt), [புதுப்பிக்கப்பட்ட மொழிபெயர்ப்பு](../../assets/demo/after.txt), [முழு மொழிபெயர்ப்பு வித்தியாசம்](../../assets/demo/update.diff), [பழைய மதிப்பாய்வு](../../assets/demo/review-stale.txt), [இறுதி மதிப்பாய்வு](../../assets/demo/review-after.txt), மற்றும் [இயக்கு விவரங்கள்](../../assets/demo/results.json). முழு-கோப்பு மொழிபெயர்ப்பு பிடிக்கப்பட்ட வித்தியாசம் மற்ற சொற்பயன்பாடுகளை அதேபோல் மாற்றலாம். இரு உரை நகல்களும் உருவாக்கப்பட்ட மறுப்பு அறிக்கையை வைத்திருக்கின்றன.

மனித மதிப்பாய்வு இன்னும் முக்கியம்: பிடிக்கப்பட்ட புதுப்பிப்பில் `[사용 가이드](guide.md)을` பயன்படுத்தப்பட்டுள்ளது; கொரிய பிணைப்பு பகுதி சரியாக `[사용 가이드](guide.md)를` ஆக இருக்க வேண்டும். உரை ஆவணங்கள் இந்த வெளியீட்டை மாற்றமின்றி வைத்துள்ளன, மாதிரி வெளியீடாக ஒரு திருத்தப்பட்ட மொழிபெயர்ப்பை வழங்குவதற்குப் பதிலாக. இந்த சொற்பயன்பாட்டு சிக்கலின்போதும் கட்டமைப்பு சார்ந்த மதிப்பாய்வு அங்கீகரிக்கப்பட்டுள்ளது.

## 1. ஒரு சிறிய கோப்புறை தயாரிக்கவும்

Python 3.11–3.14 ஐப் பயன்படுத்தவும் மற்றும் [மெய்நிகர் சூழல் அமைப்பு](configuration.md#local-runtime-setup). இந்த எடுத்துக்காட்டில் பயன்படுத்தப்பட்ட பதிப்பை நிறுவவும்:

```bash
python -m pip install co-op-translator==0.21.0
mkdir translation-demo
cd translation-demo
git init
```

இந்த கோப்புறையில் [README.txt](../../assets/demo/README.txt) மற்றும் [guide.txt](../../assets/demo/guide.txt) ஐ பதிவிறக்கி அவற்றை `README.md` மற்றும் `guide.md` ஆக சேமிக்கவும். இவை சிறிய கற்பனை திட்ட ஆவணங்கள்; எந்த பயன்பாடு நிறுவலுமே தேவையில்லை.

README ஒரு குறியீட்டு தொகுதியும் `guide.md` க்கு ஒரு இணையும் கொண்டுள்ளது. அதன் கடைசி பகுதி:

```text
Notes are saved locally.
```

இந்த கோப்புறைவில் இவைகள் மட்டுமே காட் மூல ஆவணங்களாக வைத்திருங்கள். பின்வரும் அனைத்து கட்டளைகளும் `translation-demo` இல் உள்ளபடி இயங்கும் மற்றும் Bash மற்றும் PowerShell இல் வேலை செய்வன.

## 2. அங்கீகாரங்கள் இல்லாமல் முன்னோட்டம்

```bash
translate -l "ko" -md --dry-run
```

முன்னோட்டு ஒரு மாதிரியை அழைக்காமலும் மொழிபெயர்ப்புகளை எழுதாமலும் மொழிபெயர்ப்பு பணியை மதிப்பிடுகிறது. டோக்கன் மதிப்பீடுகள் பில்லிங் மேற்கோள் அல்ல. முதற்கட்ட இயக்கம் இரு மார்க்டவுன் கோப்புகளையும் புதிய பணியாக அடையாளம் காண வேண்டும்.

## 3. ஒரு வழங்குநரை தேர்வு செய்து மொழிபெயர்க்கவும்

[உருவமைப்பு வழிகாட்டி](configuration.md) ஐப் பயன்படுத்தி ஒரு வழங்குநரை அமைக்கவும்: Azure OpenAI, OpenAI, அல்லது Anthropic. OpenAI மற்றும் Anthropic உரை மொழிபெயர்ப்பு Azure கணக்கைத் தேவைப்படுத்தாது. இந்த எடுத்துக்காட்டிற்கு படச்சேவைகள் அவசியமில்லை.

நீங்கள் உள்ளூரில் `.env` கோப்பை பயன்படுத்தினால், `.env` ஐ இந்த கோப்புறையின் `.gitignore` இல் சேர்க்கவும். மொழிபெயர்ப்பு அழைப்புகள் உங்கள் வழங்குநர் கணக்கைப் பயன்படுத்தும் என்பதால் கட்டணங்களுக்கு உட்பட்டதாக இருக்கலாம்.

```bash
translate -l "ko" -md
co-op-review -l "ko"
```

Open `translations/ko/README.md` and `translations/ko/guide.md`. கொரிய சொற்பயன்பாடு, குறியீட்டு தொகுதி மற்றும் மொழிபெயர்க்கப்பட்ட READMEஓடு மொழிபெயர்க்கப்பட்ட guide க்கு உள்ள இணைவைச் சரிபார்க்கவும். வெளியீட்டு சொற்தொடர் மாதிரிக்கேற்ப மாறும்.

`co-op-review` تازگی, கட்டமைப்பு மற்றும் உள்ளூர் இணைப்புகளைச் சரிபார்க்கிறது. பரவலாக ஏற்றுக் கொள்ளப்பட்ட முடிவு மொழி துல்லியத்தினை உறுதிசெய்யாது. தொடர்வதற்கு முன் எந்த பதிவான பிழைகளையும் தீர்க்கவும்.

Git உடன் வெற்றிகரமான அடிப்படையை பதிவு செய்யவும் (தேவைப்பட்டால் முதலில் உங்கள் Git அடையாளத்தை அமைக்கவும்):

```bash
git add README.md guide.md translations
git commit -m "Record initial Korean translation"
```

## 4. மூலத்தை மாற்றவும்

`README.md` இல், `Notes are saved locally.` என்றதை இதன் மூலம் மாற்றவும்:

```text
Notes are saved locally as Markdown files.
```

`guide.md`-ஐ மாற்றமின்றி வைக்கவும். பின்னர் இயக்கவும்:

```bash
co-op-review -l "ko"
translate -l "ko" -md --dry-run
```

மதிப்பாய்வு README மொழிபெயர்ப்பை பழையதாக அறிவிக்கmalı மற்றும் தவறான வெளியீட்டுடன் நிற்க வேண்டும். இது எதிர்பார்க்கப்படும் இடைநிலை நிலை. முன்னோட்டு மாற்றப்பட்ட README க்கான பணியை அடையாளம் காண வேண்டும்.

## 5. புதுப்பித்து வித்தியாசத்தை ஆராய்க

```bash
translate -l "ko" -md
git diff -- README.md translations/ko/README.md
git diff -- translations/ko/guide.md
co-op-review -l "ko"
```

உண்மையான வித்தியாசத்தை பரிசோதிக்கவும்: இயல்புநிலை CLI மாற்றப்பட்ட கோப்பைப் மறுபெயர்க்கிறது, ஆகவே மாதிரி அந்த கோப்பில் மற்ற சொற்பயன்பாடுகளையும் திருத்தக்கூடும். மாற்றமில்லாத guide-க்கு எந்த வித்தியாசமும் இருக்கக் கூடாது. README இனைもう பழையதாக மதிப்பிடுவதில்லை; மீதமுள்ள கண்டுபிடிப்புகளை புறக்கணிக்காமல் விசாரிக்கவும்.

மனிதன் செய்த மார்க்டவுன் திருத்தங்களின் தொகுதி-நிலையான பாதுகாப்பு ஒரு விருப்பமான மொழிபெயர்ப்பு நிலை வழங்குநரை [Python API](api.md) இல் தேவைப்படும். இது இந்த CLI கட்டளைகள் மூலம் இயக்கு செய்யப்படவில்லை.

## 6. மாற்றமின்றி மீண்டும் இயக்கவும்

புதுப்பிக்கப்பட்ட மூலமும் மொழிபெயர்ப்பும் commit செய்க:

```bash
git add README.md translations
git commit -m "Update Korean translation after source edit"
translate -l "ko" -md
git diff --exit-code -- translations
```

தற்போதைய மொழிபெயர்ப்புகள் மற்றும் மாற்றமில்லாத அமைப்புடன், மொழிபெயர்ப்பாளர் கோப்புகளைத் தவிர்க்கும். இறுதி Git கட்டளை எந்த வித்தியாசமும் உண்டாக்காமல் வெற்றிகரமாக முடிவடைவதை எதிர்பார்க்கலாம்.
