## மொழியைச் சேர்க்க

புதிய மொழிக்கு ஆதரவைச் சேர்க்க:

1. மொழி குறியீடு மற்றும் காட்சி பெயரை மொழி உதவிக்கருவிகளில் சேர்க்கவும்.
2. `src/co_op_translator/fonts/font_language_mappings.yml` இல் ஒரு எழுத்துருவை சேர்க்கவும் அல்லது வரைபடுத்தவும்.
3. Markdown மற்றும் பட மொழிபெயர்ப்பு வெளியீட்டை சோதிக்கவும்.
4. வரைபடுத்தல் மற்றும் சரிபார்ப்பு குறிப்புகளுடன் ஒரு pull request திறக்கவும்.
