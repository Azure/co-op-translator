# பிரச்சினைகளை தீர்க்குதல்

இந்தப் பக்கத்தை மொழிபெயர்ப்பு ஓட்டம் எதிர்பாராதவாறு வெற்றி அடைந்தால், கட்டமைப்பில் தோல்வியடைந்தால், அல்லது மதிப்பாய்வு தேவைப்படும் வெளியீடு உருவானால் பயன்படுத்துங்கள்.

## ஆரம்பிக்கவும்

1. முதலில் கவனம் செலுத்தப்பட்ட கட்டளையை ஓட்டவும், உதாரணமாக `translate -l "ko" -md`.
2. கன்சோல் டீபக் பதிவுகளுக்கு `-d` ஐ சேர்க்கவும்.
3. டீபக் பதிவுகளை `<root-dir>/logs/` என்ற இடத்தில் சேமிக்க `-s` ஐ சேர்க்கவும்.
4. மொழிபெயர்ப்புக்குப் பிறகு புதுப்பிக்கப்பட்ட நிலை, அமைப்பு மற்றும் உள்ளூர் இணைப்புகளைச் சரிபார்க்க `co-op-review` ஐ ஓட்டவும்.

```bash
translate -l "ko" -md -d -s
co-op-review -l "ko"
```

## கட்டமைப்பு பிழைகள்

### மொழி மாதிரி வழங்கியாளர் இல்லை

Error:

```text
No language model configuration found.
```

Fix:

- Azure OpenAI, OpenAI அல்லது Anthropic ஐ கட்டமைக்கவும்.
- கட்டளை ஓடும் சூழலில் மாறிலிகள் உள்ளதா என்பதை உறுதிசெய்க.
- உள்ளூர் பயன்பாட்டிற்கு, அவை திட்டத்தின் ரூட்டில் உள்ள `.env`-இல் வையவும்.

பார்க்: [கட்டமைப்பு](configuration.md).

### Azure AI Vision இல்லாமல் பட மொழிபெயர்ப்பு

Error:

```text
Image translation requested but Azure AI Service is not configured.
```

Fix:

- `AZURE_AI_SERVICE_API_KEY`ஐ சேர்க்கவும்.
- `AZURE_AI_SERVICE_ENDPOINT`ஐ சேர்க்கவும்.
- அல்லது `translate -l "ko" -md` போன்ற உரை மட்டும் கட்டளையை ஓட்டவும்.

### தவறான விசை அல்லது முடிவுநிலை

அறிகுறிகளில் `401`, உரிமை தொடர்புடைய பிழைகள் அல்லது endpoint அணுகல் பிழைகள் இருக்கலாம்.

Fix:

- விசை endpoint உடன் சேர்ந்தே இருக்கும் அதே Azure வளத்திற்கு சொந்தம்தானா என்பதை உறுதிசெய்க.
- `-img` பயன்படுத்தும் போது அந்த வளம் Vision-ஐ ஆதரிக்கிறதா என்பதை உறுதிசெய்க.
- Azure OpenAI deployment பெயர் மற்றும் API பதிப்பு உங்கள் deployment உடன் பொருந்துகிறதா என்பதை உறுதிசெய்க.
- டீபக் பதிவு மூலம் இயக்கவும்: `translate -l "ko" -md -d -s`.

## எந்த கோப்புகளும் மொழிபெயர்க்கப்படவில்லை

பொதுவான காரணங்கள்:

- தேர்ந்தெடுக்கப்பட்ட கொடிகள் உங்கள் கோப்புகளுடன் பொருந்தவில்லை.
- ஏற்கனவே மொழிபெயர்க்கப்பட்ட கோப்புகள் உள்ளன.
- மூலக் கோப்புகள் விலக்கப்பட்ட அடைவு(கள)யில் உள்ளன.
- கட்டளை தவறான திட்ட ரூட் இடத்தில் இருந்து இயங்குகிறது.

Checks:

```bash
translate -l "ko" -md --dry-run
translate -l "ko" -nb --dry-run
translate -l "ko" -img --dry-run
```

கட்டளை திட்ட ரூட்டின் வெளியே ஓடும்போது `--root-dir` ஐப் பயன்படுத்தவும்.

## எதிர்பாராத இணைப்பு நடத்தை

இணைப்புகளை மறுசீரமைத்தல் தேர்ந்தெடுக்கப்பட்ட உள்ளடக்க வகைகளின் அடிப்படையில் இருக்கும்:

- `-nb` சேர்க்கப்பட்டால்: நோட்புக் இணைப்புகள் மொழிபெயர்க்கப்பட்ட நோட்புக் க்களை குறிக்கலாம்.
- `-nb` நீக்கப்பட்டால்: நோட்புக் இணைப்புகள் மூல நோட்புக் களைத் தான் குறிக்கலாம்.
- `-img` சேர்க்கப்பட்டால்: பட இணைப்புகள் மொழிபெயர்க்கப்பட்ட படங்களை குறிக்கலாம்.
- `-img` நீக்கப்பட்டால்: பட இணைப்புகள் மூல படங்களைத் தான் காட்டலாம்.

உள்ளக இணைப்புகள் அனைத்தும் மொழிபெயர்க்கப்பட்ட வெளியீடுகளை முதன்மையாகக் காட்ட வேண்டும் என்றால் முழு உள்ளடக்க மொழிபெயர்ப்பை ஓட்டவும்:

```bash
translate -l "ko" -md -nb -img
```

மொழிபெயர்ப்புக்குப் பிறகு இணைப்பு மதிப்பாய்வை ஓட்டவும்:

```bash
co-op-review -l "ko"
```

## Markdown காட்சி பிரச்சனைகள்

மொழிபெயர்க்கப்பட்ட Markdown தவறாக காட்சியாகினால்:

- frontmatter `---`-இல் துவங்கி `---`-இல் முடிகிறதா என்பதை சரிபார்க்கவும்.
- மூல மற்றும் மொழிபெயர்க்கப்பட்ட கோப்புகளில் code fence எண்ணிக்கை பொருந்துகிறதா என்பதை சரிபார்க்கவும்.
- பொதுவான அமைப்பு பிரச்சனைகளை பிடிக்க `co-op-review`ஐ ஓட்டவும்.
- வெளியீடு கெடப்பட்டிருந்தால் அந்த குறிப்பிட்ட கோப்பைப் மீண்டும் மொழிபெயர்க்கவும்.

```bash
co-op-review -l "ko" --format github
```

## GitHub Action ஓடியது ஆனால் எந்த Pull Request உருவாகவில்லை

`peter-evans/create-pull-request` பிரேஞ்ச் base-ஐவிட முன்னேறவில்லை என்று தெரிவித்தால், workflow commit செய்யல் உள்ள கோப்புகளை கண்டுபிடிக்கவில்லை.

சாத்தியமான காரணங்கள்:

- மொழிபெயர்ப்பு ஓட்டம் எந்த மாற்றத்தையும் உருவாக்கவில்லை.
- `.gitignore` `translations/`, `translated_images/` அல்லது மொழிபெயர்க்கப்பட்ட நோட்பூக்களை விலக்குகிறது.
- `add-paths` உருவாக்கப்பட்ட வெளியீடு அடைவு(கள)க்கு பொருந்தவில்லை.
- மொழிபெயர்ப்பு படி முன்னதாக முடிந்து விட்டது.

Fixes:

1. `translations/` அல்லது `translated_images/`-இல் உருவாக்கப்பட்ட கோப்புகள் இருக்கிறதா என்பதைக் உறுதிசெய்க.
2. `.gitignore` உருவாக்கப்பட்ட வெளியீடுகளை புறக்கணிக்கதில்லை என்பதை உறுதிசெய்க.
3. பொருந்தும் `add-paths` ஐ பயன்படுத்தவும்:

   ```yaml
   with:
     add-paths: |
       translations/
       translated_images/
   ```

4. தற்காலிகமாக translate கட்டளைக்கு டீபக் கொடிகளைச் சேர்க்கவும்:

   ```bash
   translate -l "ko" -md -d -s
   ```

5. workflow அனுமதிகள் இதை உள்ளடக்கியுள்ளதா என்பதை உறுதிசெய்க:

   ```yaml
   permissions:
     contents: write
     pull-requests: write
   ```

## மொழிபெயர்ப்பு தரம்

மெஷின் மொழிபெயர்ப்புகள் மனித மதிப்பாய்வை தேவைப்படலாம். நீங்கள் பரிசோதனைக் குணதன்மை மதிப்பீடு மற்றும் குறைந்த நம்பகத்தன்மை திருத்த வேலைநிரல்களைப் பயன்படுத்த விரும்பினால் மட்டும் `evaluate` ஐப் பயன்படுத்தவும்.

!!! warning "Experimental"
    `evaluate` விதி அடிப்படையிலான மற்றும் LLM அடிப்படையிலான சரிபார்ப்புகளைப் பயன்படுத்தக்கூடும், அதன் மதிப்பீட்டு மாதிரி மற்றும் மெட்டாடேட்டா நடத்தை மாறக்கூடும். உங்கள் workflow மாற்றங்களுக்கு தயாராக இல்லையெனில் இதனை தேவையான CI வாயில்களில் பயன்படுத்த வேண்டாம்.

For deterministic CI checks, use `co-op-review` instead.
