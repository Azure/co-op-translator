# உங்கள் பணிவழிமுறையை தேர்வு செய்யவும்

Co-op Translator ஐ மூன்று வழிகளில் பயன்படுத்தலாம்: CLI, Python API, மற்றும் MCP சேவையகம். அவை ஒரே மொழிபெயர்ப்பு திறன்களை பகிர்ந்துகொள்கின்றன, ஆனால் ஒவ்வொன்றும் வெவ்வேறு பணிவழிமுறைக்கு பொருந்தும்.

எங்கே தொடங்குவது என்று முடிவெடுக்கும்போது இந்தப் பக்கத்தை பயன்படுத்துங்கள்.

**If you edit translations by hand:** இயல்புநிலையான CLI மற்றும் Actions பணிவழிமுறைகள் மாற்றமடைந்த மூல கோப்புகளை முழுமையாக மீண்டும் மொழிபெயர்க்கும், ஆகையால் அந்த கோப்புகளில் நீங்கள் செய்த மொழிப்பயன்பாடுகள் மாற்றப்படலாம். மேம்பாட்டை ஏற்கும் முன் diff ஐ பரிசீலிக்கவும். ஏற்றுக்கொள்ளப்பட்ட திருத்தங்களை Markdown தொகுதி-அம்ச நிலைப்படி பாதுகாக்க, விருப்பமான [Python API மொழிபெயர்ப்பு நிலை வழங்கி](api.md#preserve-accepted-human-edits-with-a-translation-state-provider) ஐப் பயன்படுத்தவும்.

## CLI ஐப் பயன்படுத்த வேண்டிய போது

ஒரு நபர் அல்லது CI வேலை ரெப்போசிட்டரி மொழிபெயர்ப்பை ஷெல்லில் இருந்து இயக்கும் போது CLI ஐ தேர்வு செய்யுங்கள்.

project கோப்புகளை கண்டுபிடித்து, மொழிபெயர்க்கப்பட்ட வெளியீடுகளை உருவாக்கி, திட்ட அமைப்பை பாதுகாத்து, மெட்டாடேட்டாவை புதுப்பித்து, மற்றும் மதிப்பாய்வு கட்டளைகளை இயக்க Co-op Translator ஐ CLI வழியாக நேரடியாகப் பயன்படுத்துவது சிறந்த வழி.

```bash
translate -l "ko" -md --dry-run
translate -l "ko" -md -nb
co-op-review -l "ko"
migrate-links -l "ko" --dry-run
```

இந்த எடுத்துக்காட்டு Markdown மற்றும் நோட்பூக்களை மொழிபெயர்க்கிறது. `-img` ஐ சேர்க்கும் முன் [Azure AI Vision](configuration.md#azure-ai-vision) ஐ அமைத்துக்கொள்ளவும். Markdown மட்டும் முதற்கட்ட ஓட்டத்திற்காக, [உங்கள் முதல் மொழிபெயர்ப்பு](first-translation.md) ஐ பின்பற்றவும்.

உகந்தவை:

- நீங்கள் உங்கள் டெர்மினலிலிருந்து ஒரு repository ஐ மொழிபெயர்க்கிறீர்கள்.
- நீங்கள் CI அல்லது வெளியீட்டு பணிமுறைகளுக்காக மீண்டும் பயன்படுத்தக்கூடிய கட்டளையை விரும்புகிறீர்கள்.
- நீங்கள் உள்ளமைக்கப்பட்ட திட்ட கண்டறிதல், வெளியீட்டு பாதைகள், மெட்டா-தரவு, சுத்தப்படுத்தல் மற்றும் மீளாய்வை விரும்புகிறீர்கள்.
- Python கோடுகளை எழுதுவதற்குப் பதிலாக கட்டளை இடைமுகத்தை நீங்கள் முன்னுரிமை கொள்கிறீர்கள்.

## Python API ஐப் பயன்படுத்த வேண்டிய போது

உங்கள் சொந்தக் கோடு பணிவழிமுறையை கட்டுப்படுத்த வேண்டும் என்றால் Python API ஐ தேர்வு செய்யுங்கள்.

API பயன்பாடுகள், தானியக்க ஸ்கிரிப்டுகள், நோட்பூக்கள், சேவைகள், மற்றும் தனிப்பயன் குழாய் கோயில்களுக்கு பயனுள்ளதாகும். இது தனித்த கோப்புகளுக்கான குறைந்த நிலை உள்ளடக்க மொழிபெயர்ப்பு API களை அழைக்கவோ, அல்லது CLI பயன்பாட்டில் பயன்படுத்தப்படும் அதே ரெப்போசிட்டரி-நிலை ஒருங்கமைப்பை இயக்கவோ உங்களுக்கு அனுமதிக்கிறது.

ஒரு Markdown ஆவணத்தை மொழிபெயர்த்து அதை எங்கே சேமிக்க வேண்டும் என்று தீர்மானிக்கவும்:

```python
import asyncio
from pathlib import Path

from co_op_translator.api import rewrite_markdown_paths, translate_markdown_content


async def main() -> None:
    source_path = Path("docs/guide.md")
    target_path = Path("translations/ko/docs/guide.md")

    translated = await translate_markdown_content(
        source_path.read_text(encoding="utf-8"),
        "ko",
        {"source_path": source_path},
    )

    rewritten = rewrite_markdown_paths(
        translated,
        source_path=source_path,
        target_path=target_path,
    )

    target_path.parent.mkdir(parents=True, exist_ok=True)
    target_path.write_text(rewritten, encoding="utf-8")


asyncio.run(main())
```

Python இல் இருந்து ஒரு ரெப்போசிட்டரி மொழிபெயர்ப்பை இயக்கவும்:

```python
from co_op_translator.api import run_translation

run_translation(
    language_codes="ko",
    markdown=True,
    notebook=True,
    images=False,
    dry_run=True,
)
```

உகந்தவை:

- உங்கள் பயன்பாடு ஏற்பறவே கோப்புகள், பஃபர்கள், நோட்புக்குகள் அல்லது பட பைட்டுகளைப் படிக்கிறது.
- உங்களுக்கு தனிப்பயன் சரிபார்ப்பு, சேமிப்பு, பதிவேடு, மீண்டும் முயற்சிகள் அல்லது அனுமதி ஓட்டங்கள் தேவை.
- முழு ரெப்பொசிடரியை செயலாக்காமல் ஒரு ஆவணம், நோட்புக் அல்லது படத்தை நீங்கள் மொழிபெயர்க்க விரும்புகிறீர்கள்.
- நீங்கள் ரெப்பொசிடரி மொழிபெயர்ப்பை விரும்புகிறீர்கள், ஆனால் ஷெல் கட்டளையின் பதிலாக Python ஆட்டோமேஷன் மூலம்.

## MCP சேவையகத்தைப் பயன்படுத்த வேண்டிய போது

ஒரு ஏஜென்ட், தொகுப்பாளர், அல்லது MCP-உகந்த கிளையெண்ட் Co-op Translator கருவிகளை அழைக்க வேண்டும் என்றால் MCP சேவையகத்தை தேர்வு செய்யவும்.

சாதாரண உள்ளூர் அமைப்பில், பயனர் ஒரு சேவையகத்தை கைமுறையாக இயங்கவைக்கமாட்டார். கருவிகள் தேவையென்றால் MCP கிளையெண்ட் `stdio` மூலம் `co-op-translator-mcp` ஐ துவக்குகிறது.

எஜென்ட் கையாளக்கூடிய பயனர் கோரிக்கைகளின் எடுத்துக்காட்டுகள்:

- "இந்த Markdown கோப்பை கொரிய மொழிக்கு மொழிபெயர்த்து இணைப்புகளை சரியாக வைத்திருங்கள்."
- "ஏஜென்ட்-உதவிய MCP பணிவழிமுறையைப் பயன்படுத்தி இந்த Markdown கோப்பை கொரிய மொழிக்கு மொழிபெயர்க்கவும், மொழிபெயர்க்கப்பட்ட துண்டுகளுக்காக உங்கள் சொந்த மாதிரியைப் பயன்படுத்தவும்."
- "இந்த நோட்புக் ஐ கொரிய மொழிக்கு மொழிபெயர்த்து, குறியீட்டு செல்களை பாதுகாப்பாக வைத்திருங்கள், மற்றும் நோட்புக் மீடமைக்க Co-op Translator MCP ஐ பயன்படுத்தவும்."
- "இந்த படத்தின் உள்ள உரையை ஜப்பானி மொழிக்கு மொழிபெயர்த்து முடிவைக் காப்பாற்றவும்."
- "ஸ்பானிஷ் மொழிக்கு ஒரு ரெப்போசிட்டரி மொழிபெயர்ப்பை ட்ரை-ரன் செய்து என்ன மாற்றம் வரும் என்று சொல்லுங்கள்."
- "கொரிய மொழிபெயர்ப்பு வெளியீடு சமீபத்தியதா என்பதை மதிப்பாய்வு செய்யுங்கள்."

Markdown மற்றும் நோட்பூக்களுக்காக, MCP இரு முறைகளில் செயல்படலாம்:

| முறை | எப்போது பயன்படுத்துவது | முக்கிய கருவிகள் |
| --- | --- | --- |
| Agent-assisted | MCP ஹோஸ்ட் ஏஜென்ட் அதன் சொந்த மாதிரியைப் பயன்படுத்தி துண்டுகளை மொழிபெயரிக்க வேண்டும், Co-op Translator LLM வழங்குநர் அங்கீகாரங்கள் இல்லாமல். | `start_markdown_agent_translation`, `finish_markdown_agent_translation`, `start_notebook_agent_translation`, `finish_notebook_agent_translation` |
| Provider-backed | Co-op Translator நேரடியாக Azure OpenAI, OpenAI, அல்லது Anthropic ஐ அழைக்க வேண்டும். | `translate_markdown_content`, `translate_notebook_content` |

MCP வழங்குநர் ஆதரவு கொண்ட Markdown கருவி அழைப்பு வடிவம்:

```json
{
  "tool": "translate_markdown_content",
  "arguments": {
    "document": "# Setup\n\nInstall Co-op Translator first.",
    "language_code": "ko",
    "options": {
      "source_path": "docs/setup.md"
    }
  }
}
```

MCP image tool call shape:

```json
{
  "tool": "translate_image_content",
  "arguments": {
    "image_path": "assets/architecture.png",
    "language_code": "ko",
    "output_path": "translated_images/ko/assets/architecture.png"
  }
}
```

MCP வழியாக ரெப்பொசிடரி மொழிபெயர்ப்பு இயல்பாக ட்ரை-ரன் ஆக நடைபெறுகிறது:

```json
{
  "tool": "run_translation",
  "arguments": {
    "language_codes": ["ko"],
    "translate_markdown": true,
    "translate_notebooks": true,
    "translate_images": false,
    "dry_run": true
  }
}
```

உகந்தவை:

- நீங்கள் ஒரு ஏஜென்ட் அல்லது எடிட்டரில் இயங்கும் இயற்கை மொழி மொழிபெயர்ப்பு பணிமுறைகளை விரும்புகிறீர்கள்.
- ஹோஸ்ட் ஏஜென்ட் மாடல் தயார் செய்யப்பட்ட துண்டுகளை மொழிபெயர்ப்பதற்கான Markdown அல்லது நோட்புக் மொழிபெயர்ப்பை நீங்கள் விரும்புகிறீர்கள்.
- முழு ரெப்பொசிடரியின் பதிலாக தேர்ந்தெடுக்கப்பட்ட உள்ளடக்கத்தை ஏஜென்ட் மொழிபெயரிக்க வேண்டும் என்று நீங்கள் விரும்புகிறீர்கள்.
- ரெப்பொசிடரி முழுவதும் எழுதுவதற்கு முன் ஒரு அனுமதி படியை நீங்கள் விரும்புகிறீர்கள்.
- Markdown, நோட்புக், படம், மீளாய்வு மற்றும் பாதை மறுபெயர்க்கும் கருவிகளை வெளிப்படுத்தும் ஒரு இடைமுகத்தை நீங்கள் விரும்புகிறீர்கள்.

## அவை ஒன்றாக எப்படி பொருந்துகின்றன

ரெப்போசிட்டரிகளை மொழிபெயர்ப்பதில் CLI மனிதர்களுக்கான இயல்புநிலையான தேர்வு. உங்கள் கோடு பணிவழிமுறையை உரிமையுள்ளதாக்கினால் Python API சிறந்தது. ஏஜென்ட் அல்லது தொகுப்பாளர் பணிவழிமுறையை உரிமையாக்கினால் MCP சேவையகம் சிறந்தது.

இந்த மூன்று வழிகளும் ஒரே பொதுப் Co-op Translator API ஐப் பயன்படுத்துகின்றன, ஆகையால் நீங்கள் CLI மூலம் தொடங்கி பின் Python மூலம் தானியக்கப்படுத்தலாம், மற்றும் ஏஜென்ட்-ஈடுபடும்போது MCP கிளையெண்ட்களுக்கு அதே திறன்களை வெளிப்படுத்தலாம்.
