# CLI సూచిక

Co-op Translator ఈ క్రింది కమాండ్-లైన్ ఎంట్రీ పాయింట్లను ఇన్స్టాల్ చేస్తుంది:

- `translate`
- `evaluate`
- `migrate-links`
- `co-op-review`
- `co-op-translator-mcp`

`translate`, `evaluate`, `migrate-links`, మరియు `co-op-review` కమాండ్లు `co_op_translator.__main__` ద్వారా పంపబడతాయి, ఇది పిలవబడిన స్క్రిప్ట్ పేరును ఆధారంగా కమాండ్ అమలును ఎంచుకుంటుంది. MCP సర్వర్ నేరుగా `co_op_translator.mcp.server`ను ఉపయోగిస్తుంది.

మీరు CLI, Python API, మరియు MCP మధ్య నిర్ణయించుకుంటున్నట్లయితే, [మీ పని ప్రవాహాన్ని ఎంచుకోండి](workflows.md) నుండి ప్రారంభించండి.

## కన్సోల్ అవుట్పుట్

ఇంటరాక్టివ్ టెర్మినళ్లు కమాండ్ హెడ్డర్, ప్రగతి మరియు సారాంశాల కోసం Rich ఫార్మాటింగ్‌ను ఉపయోగిస్తాయి. CI మరియు నాన్-ఇంటరాక్టివ్ అవుట్‌పుట్ స్వయంచాలకంగా సాధారణ టెక్స్ట్‌కు మారుతుంది.

సాదా అవుట్‌പుట్ బలవంతం చేయడానికి `CO_OP_TRANSLATOR_OUTPUT_STYLE=plain` ను సెట్ చేయండి, లేదా రిచ్ అవుట్‌పుట్ బలవంతం చేయడానికి `CO_OP_TRANSLATOR_OUTPUT_STYLE=rich` ను సెట్ చేయండి. ప్రత్యక్ష ప్రోగ్రెస్ బార్లను దాచుతూ సారాంశాలను ఉంచడానికి `CO_OP_TRANSLATOR_NO_PROGRESS=1` ను సెట్ చేయండి.

మరొక సిస్టమ్‌కి యంత్రం చదవగలిగే (machine-readable) ప్రగతి అవసరమైతే `translate --json-events progress.ndjson` ఉపయోగించండి
CLI మానవ-గమనించదగిన అవుట్‌పుట్‌ను కొనసాగిస్తుంది, while
NDJSON ఫైల్ సంస్కరణ చేయబడిన `co-op.translation.event.v1` ఈవెంట్లను పొందుతుంది, వీటిలో
స్థిర ఫీల్డ్స్ جيئن `type`, `stage_key`, `completed`, `total`, and
`current_path`.

## మొదటి సారి CLI ప్రవాహం

టెర్మినల్‌లో Co-op Translator ఉపయోగిస్తుంటే ఇక్కడ నుండే ప్రారంభించండి:

1. [కాన్ఫిగరేషన్](configuration.md)లో వివరించినట్లుగా ఒక LLM ప్రొవైడర్‌ను కాన్ఫిగర్ చేయండి.
2. మీరు అనువదించాలనుకునే కంటెంట్ రకాన్ని ఎంచుకోండి.
3. మొదటే ఒక కేంద్రీకృత కమాండ్ నడిపించండి, ఉదాహరణకి Markdown మాత్రమే అనువదించడం.
4. పెద్ద రిపోజిటరీ మార్పుల ముందు `--dry-run` ఉపయోగించండి.
5. నిర్మాణం మరియు తాజాదనాన్ని తనిఖీ చేయడానికి అనువాదం తర్వాత `co-op-review` ఉపయోగించండి.

| లక్ష్యం | ప్రారంభించడానికి కమాండ్ |
| --- | --- |
| Markdown డాక్యుమెంట్లను అనువదించండి | `translate -l "ko" -md` |
| నోట్‌బుక్స్‌ను అనువదించండి | `translate -l "ko" -nb` |
| చిత్రపు పాఠ్యాన్ని అనువదించండి | `translate -l "ko" -img` |
| ఫైళ్లను రాయకుండా పని ను ప్రివ్యూ చేయండి | `translate -l "ko" -md --dry-run` |
| ఇప్పటికే ఉన్న అనువాదాలను సమీక్షించండి | `co-op-review -l "ko"` |
| నోట్బుక్ మరియు Markdown లింకులను నవీకరించండి | `migrate-links -l "ko" --dry-run` |
| సాధనాలను MCP క్లయింట్‌కి ప్రదర్శించండి | CLI కమాండ్లను నేరుగా నడపడం బదులుగా [MCP Server](mcp.md)ని కాన్ఫిగర్ చేయండి. |

## translate

Markdown ఫైళ్లు, నోట్‌బుక్స్ మరియు చిత్ర పాఠ్యాలను ఒకటి లేదా ఎక్కువ లక్ష్య భాషలకు అనువదించండి.

```bash
translate -l "ko ja fr"
```

### సాధారణ ఉదాహరణలు

Markdown మాత్రమే అనువదించండి:

```bash
translate -l "de" -md
```

నోట్‌బుక్స్ మాత్రమే అనువదించండి:

```bash
translate -l "zh-CN" -nb
```

Markdown మరియు చిత్రాలను అనువదించండి:

```bash
translate -l "pt-BR" -md -img
```

ఇప్పటిక ఉన్న అనువాదాలను తీసేసి మళ్లీ సృష్టించడం ద్వారా నవీకరించండి:

```bash
translate -l "ko" -u
```

ఇంటరాక్టివ్ ప్రాంప్ట్‌లుండకుండా నడపండి:

```bash
translate -l "ko ja" -md -y
```

లాగ్‌లను సేవ్ చేయండి:

```bash
translate -l "ko" -s
```

సంరచనబద్ధమైన ప్రగతి ఈవెంట్లను రాయండి:

```bash
translate -l "ko ja" -md --json-events progress.ndjson
```

### ఎంపికలు

| ఎంపిక | అవసరం | వివరణ |
| --- | --- | --- |
| `-l`, `--language-codes` | అవశ్యం | స్పేస్-విడగొట్టబడిన భాషా కోడ్లు, ఉదాహరణకి "es fr de", లేదా "all". |
| `-r`, `--root-dir` | కాదు | ప్రాజెక్ట్ రూట్. డిఫాల్ట్‌గా ప్రస్తుత డైరెక్టర్‌ి. |
| `-u`, `--update` | కాదు | ఎంపిక చేసిన భాషల కోసం ఉన్న అనువాదాలను తొలగించి మళ్లీ సృష్టిస్తుంది. |
| `-img`, `--images` | కాదు | ఇమేజ్ ఫైళ్లను మాత్రమే అనువదించండి. |
| `-md`, `--markdown` | కాదు | Markdown ఫైళ్లను మాత్రమే అనువదించండి. |
| `-nb`, `--notebook` | కాదు | Jupyter నోట్‌బుక్ ఫైళ్లను మాత్రమే అనువదించండి. |
| `-d`, `--debug` | కాదు | కన్సోల్‌లో డీబగ్ లాగింగ్‌ను ప్రారంభించండి. |
| `-s`, `--save-logs` | కాదు | Save DEBUG-level logs under `<root-dir>/logs/`. |
| `--json-events` | కాదు | యంత్రం చదవగలిగే అనువాద ప్రగతి ఈవెంట్లను NDJSONగా రాయండి. |
| `-x`, `--fix` | కాదు | గత మూల్యాంకన ఫలితాల ఆధారంగా తక్కువ-నమ్మకత గల Markdown ఫైల్స్‌ను మళ్లీ అనువదించండి. |
| `-c`, `--min-confidence` | కాదు | `--fix`కి నమ్మక పరిమితి. డిఫాల్ట్ `0.7`. |
| `--add-disclaimer`, `--no-disclaimer` | కాదు | మెషీన్ అనువాద డిస్క్లెయిమర్‌లను జోడించండి లేదా ఆపండి. CLIలో డిఫాల్ట్‌గా సక్రియం. |
| `-f`, `--fast` | కాదు | డిప్రికేటెడ్ ఫాస్ట్ ఇమేజ్ మోడ్. |
| `-y`, `--yes` | కాదు | ప్రాంప్ట్‌లను ఆటో-కన్ఫర్మ్ చేయండి, CIలో ఉపయోగకరంగా ఉంటుంది. |
| `--repo-url` | కాదు | README భాషల పట్టికలో sparse-checkout సూచన కోసం ఉపయోగించే రిపోజిటరీ URL. |
| `--migrate-language-folders` | కాదు | పాత అలియాస్ ఫొల్డర్లను, ఉదాహరణకు `cn` లేదా `tw`, canonical BCP 47 ఫొల్డర్లకు పునర్నామకరణ చేయండి. |
| `--dry-run` | కాదు | ఫైళ్లను రాయకుండా భాషా ఫొల్డర్ మైగ్రేషన్ మరియు అనువాద అంచనాలను ప్రివ్యూకు చూపిస్తుంది. |

ఏదైనా టైప్ ఫ్లాగ్ ఇవ్వబడకపోతే, `translate` Markdown, నోట్‌బుక్స్, మరియు ఇమేజ్‌లను ప్రాసెస్ చేస్తుంది. ఇమేజ్ అనువాదానికి Azure AI Vision కాన్ఫిగరేషన్ అవసరం.

## evaluate

ఒక భాషకు అనువదించిన Markdown నాణ్యతను మూల్యాంకనం చేయండి.

!!! warning "Experimental"
    `evaluate` ప్రయోగాత్మకంగా ఉంది. ఇది నియమాధారిత మరియు LLM-ఆధారిత నాణ్యత తనిఖీలను ఉపయోగించవచ్చు, మూల్యాంకన ఫలితాలను అనువాద మెటాడేటాలో రాస్తుంది, మరియు దాని స్కోరింగ్ మోడల్ మరియు మెటాడేటా ప్రవర్తన మారవచ్చు.

```bash
evaluate -l "ko"
```

### సాధారణ ఉదాహరణలు

మరింత కఠినమైన తక్కువ-నమ్మకత పరిమితిని ఉపయోగించండి:

```bash
evaluate -l "es" -c 0.8
```

కేవలం నియమాధారిత తనిఖీలను నడపండి:

```bash
evaluate -l "fr" -f
```

కేవలం LLM-ఆధారిత తనిఖీలు నడపండి:

```bash
evaluate -l "ja" -D
```

### ఎంపికలు

| ఎంపిక | అవసరం | వివరణ |
| --- | --- | --- |
| `-l`, `--language-code` | అవశ్యం | మూల్యాంకనం చేయడానికి ఒకే భాషా కోడ్. అలియాస్ కోడ్లు సాధారణీకరించబడతాయి. |
| `-r`, `--root-dir` | కాదు | ప్రాజెక్ట్ రూట్. డిఫాల్ట్‌గా ప్రస్తుత డైరెక్టరీ. |
| `-c`, `--min-confidence` | కాదు | తక్కువ-నమ్మకత అనువాదాలను జాబితా చేయునప్పుడు ఉపయోగించే పరిమితి. డిఫాల్ట్ `0.7`. |
| `-d`, `--debug` | కాదు | డీబగ్ లాగింగ్‌ను ప్రారంభించండి. |
| `-s`, `--save-logs` | కాదు | Save DEBUG-level logs under `<root-dir>/logs/`. |
| `-f`, `--fast` | కాదు | కేవలం నియమాధారిత మూల్యాంకనం. |
| `-D`, `--deep` | కాదు | కేవలం LLM-ఆధారిత మూల్యాంకనం. |

డిఫాల్ట్‌గా, `evaluate` నియమాధారిత మరియు LLM-ఆధారిత రెండింటినీ ఉపయోగిస్తుంది. ఫలితాలు అనువాద మెటాడేటాలో రాస్తారు మరియు కన్సోల్‌లో సారాంశాలను చూపిస్తారు.

## co-op-review

API క్రెడెన్షియల్స్ లేకుండా నిర్ణీత అనువాద నిర్వహణ తనిఖీలను నడపండి.

!!! note "Beta"
    `co-op-review` ఒక బీటా నిర్దిష్ట సమీక్ష కమాండ్. ఇది మోడల్ ప్రొవైడర్లను పిలవదు లేదా ఫైళ్లను రాయదు, కానీ దాని తనిఖీలు మరియు ఇష్యూ అవుట్‌పుట్ స్కీమా మారవచ్చు.

```bash
co-op-review -l "ko"
```

### సాధారణ ఉదాహరణలు

ప్రస్తుత డైరెక్టరీలోని కొరియన్ మరియు జపనీస్ అనువాదాలను సమీక్షించండి:

```bash
co-op-review -l "ko ja"
```

ఒక నిర్దిష్ట ప్రాజెక్ట్ రూట్‌ను సమీక్షించండి:

```bash
co-op-review -l "fr" -r ./my-course
```

README-మాత్రమైన అనువాదం చేసిన తర్వాత కేవలం READMEని సమీక్షించండి:

```bash
translate -l "ko" --readme-only -y
co-op-review -l "ko" --readme-only --format github
```

`--readme-only` ఇతర డాక్యుమెంట్లు మరియు nested READMEs ను నిర్లక్ష్యం చేస్తుంది. ఇది రూట్
`README.md` లేని సమయంలో విఫలమవుతుంది. `--changed-from` తో కలిపితే, ఇది READMEని మాత్రమే సమీక్షిస్తుంది
ఆ మూల ఫైల్ మారినప్పుడు. README-మాత్రి అనువాదం మూల READMEని మార్చకుండా ఉంచుతుంది,
ఏ షేర్డ్-సెక్షన్ మార్కర్లను కూడా.

బేస్ refతో పోల్చినప్పుడు మారిన మూల ఫైళ్లను మాత్రమే సమీక్షించండి:

```bash
co-op-review -l "ko" --changed-from origin/main
```

GitHub-ఫ్లేవర్డ్ Markdown అవుట్‌పుట్‌ను CI సారాంశాల కోసం ప్రింట్ చేయండి:

```bash
co-op-review -l "ko ja" --changed-from origin/main --format github
```

### ఎంపికలు

| ఎంపిక | అవసరం | వివరణ |
| --- | --- | --- |
| `-l`, `--language-code` | కాదు | సమీక్షించవలసిన భాషా కోడ్. ఒకటి కంటే ఎక్కువ సార్లు లేదా స్పేస్-విడగొట్టిన విలువగా ఇవ్వవచ్చు. డిఫాల్ట్‌గా అన్ని కనుగొన్న అనువాద భాషలు. |
| `-r`, `--root-dir` | కాదు | ప్రాజెక్ట్ రూట్. డిఫాల్ట్‌గా ప్రస్తుత డైరెక్టరీ. |
| `--changed-from` | కాదు | మారిన మూల ఫైళ్లకు పరిమితం చేయడానికి ఉపయోగించే Git ref. |
| `--readme-only` | కాదు | రూట్ `README.md` అనువాదం మాత్రమే సమీక్షించండి. |
| `--format` | కాదు | అవుట్‌పుట్ ఫార్మాట్: `text` or `github`. డిఫాల్ట్ `text`. |

`co-op-review` ప్రస్తుతం కనిపించని అనువాద ఫైళ్లను, లేమి లేదా పాతవైన అనువాద మెటాడేటాను, Markdown frontmatter మరియు కోడ్ ఫెన్స్ సమగ్రతను, చెత్తగా అనువదించిన నోట్‌బుక్ JSONని, మరియు తప్పిపోయిన స్థానిక Markdown లేదా ఇమేజ్ లింక్ లక్ష్యాలను తనిఖీ చేస్తుంది. లింక్లు లేనివి డిఫాల్ట్‌గా హెచ్చరికలు; నిర్మాణాత్మక మరియు తాజాదన సమస్యలు కమాండ్‌ను విఫలమవుస్తాయి.

## co-op-translator-mcp

ఎజెంట్లు, ఎడిటర్లు మరియు MCP-సమర్థక క్లయింట్ల కోసం Co-op Translator MCP సర్వర్‌ను నడపండి.

```bash
co-op-translator-mcp
```

డిఫాల్ట్ ట్రాన్స్‌పోర్ట్ `stdio` ఉంది. క్లయింట్ కాన్ఫిగరేషన్, సాధనాలు, వనరులు, మరియు భద్రతా గమనికల కోసం [MCP Server](mcp.md) గైడ్‌ను చూడండి.

### ఎంపికలు

| ఎంపిక | అవసరం | వివరణ |
| --- | --- | --- |
| `--transport` | కాదు | MCP ట్రాన్స్‌పోర్ట్: `stdio`, `streamable-http`, లేదా `sse`. డిఫాల్ట్ `stdio`. |

## migrate-links

అనువదించిన Markdown ఫైళ్లను మళ్ళీ ప్రాసెస్ చేసి, అనువదించిన నోట్‌బుక్స్ ఉన్నప్పుడు లింక్లు వాటి వైపు సూచించేలా నవీకరించండి.

```bash
migrate-links -l "ko ja"
```

### సాధారణ ఉదాహరణలు

లింక్ నవీకరణలను ప్రివ్యూ చేయండి:

```bash
migrate-links -l "ko" --dry-run
```

నిర్ధారణ లేకుండా మద్దతు ఉన్న అన్ని భాషలను ప్రాసెస్ చేయండి:

```bash
migrate-links -l "all" -y
```

అనువదించిన నోట్‌బుక్స్ ఉన్నపుడే మాత్రమే లింకులను రీరైట్ చేయండి:

```bash
migrate-links -l "ko" --no-fallback-to-original
```

### ఎంపికలు

| ఎంపిక | అవసరం | వివరణ |
| --- | --- | --- |
| `-l`, `--language-codes` | అవశ్యం | స్పేస్-విడగొట్టబడిన భాషా కోడ్లు, లేదా "all". |
| `-r`, `--root-dir` | కాదు | ప్రాజెక్ట్ రూట్. డిఫాల్ట్‌గా ప్రస్తుత డైరెక్టరీ. |
| `--image-dir` | కాదు | రూట్‌కు సంబంధించి అనువదించిన చిత్రం డైరెక్టరీ. డిఫాల్ట్ `translated_images`. |
| `--dry-run` | కాదు | అప్డేట్స్ రాయకుండా ఏ ఫైళ్లను మార్చవచ్చో చూపిస్తుంది. |
| `--fallback-to-original`, `--no-fallback-to-original` | కాదు | అనువదించిన నోట్‌బుక్స్ లేనప్పుడు ఒరిజినల్ నోట్‌బుక్ లింక్లకు fallback చేయండి లేదా కాకండని సెట్ చేయండి. డిఫాల్ట్‌గా ఎనేబుల్ చేయబడింది. |
| `-d`, `--debug` | కాదు | డీబగ్ లాగింగ్‌ను ప్రారంభించండి. |
| `-s`, `--save-logs` | కాదు | Save DEBUG-level logs under `<root-dir>/logs/`. |
| `-y`, `--yes` | కాదు | అన్ని భాషలను ప్రాసెస్ చేస్తున్నప్పుడు ప్రాంప్ట్‌లను ఆటో-కన్ఫర్మ్ చేయండి. |

## Environment

ఏదైనా కమాండ్ ప్రొవైడర్ క్రెడెన్షియల్స్ అవసరమైతే, ఈ ప్రొవైడర్ సెట్లలో ఒకటిని కాన్ఫిగర్ చేయండి. `translate --dry-run` మరియు `co-op-review`కి ప్రొవైడర్ క్రెడెన్షియల్స్ అవసరం లేదు:

```bash
# ఆజూర్ ఓపెన్‌ఏఐ
AZURE_OPENAI_API_KEY="..."
AZURE_OPENAI_ENDPOINT="https://<resource>.openai.azure.com/"
AZURE_OPENAI_MODEL_NAME="gpt-4o"
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME="<deployment>"
AZURE_OPENAI_API_VERSION="2024-12-01-preview"

# లేదా ఓపెన్‌ఏఐ
OPENAI_API_KEY="..."
OPENAI_CHAT_MODEL_ID="gpt-4o"

# లేదా ఆంథ్రోపిక్
ANTHROPIC_API_KEY="..."
ANTHROPIC_MODEL="claude-..."
```

చిత్ర అనువాదానికి అదనంగా Azure AI Vision అవసరం:

```bash
AZURE_AI_SERVICE_API_KEY="..."
AZURE_AI_SERVICE_ENDPOINT="https://<resource>.cognitiveservices.azure.com/"
```

## అవుట్‌పుట్ ఆకృతి

టెక్స్ట్ అనువాదాలు ఈ క్రిందగా రాయబడతాయి:

```text
translations/<language-code>/<original-path>
```

అనువదించిన ఇమేజ్ అవుట్‌పుట్ క్రింద రాయబడుతుంది:

```text
translated_images/<language-code>/<original-path>
```

ఉదాహరణకు, `README.md` మరియు `docs/setup.md` ను కొరియన్‌కి అనువదించడం produces:

```text
translations/ko/README.md
translations/ko/docs/setup.md
```

## కాపీ-పేస్ట్ CLI ఉదాహరణలు

Markdown ను మూడు భాషల్లోకి అనువదించండి:

```bash
translate -l "ko ja fr" -md
```

నోట్‌బుక్స్ మాత్రమే అనువదించండి:

```bash
translate -l "zh-CN" -nb
```

చిత్రాలు మాత్రమే అనువదించండి:

```bash
translate -l "pt-BR" -img
```

ఫైళ్లను రాయకుండా Markdown అనువాదాన్ని ముందుగా చూడండి:

```bash
translate -l "de es" -md --dry-run
```

తక్కువ-నమ్మకత గల Markdown అనువాదాలను మరమ్మతు చేయండి:

```bash
evaluate -l "ko" -c 0.8
translate -l "ko" --fix -c 0.8 -md
```

CI-స్నేహపూర్వక Markdown అనువాదాన్ని నడపండి:

```bash
translate -l "ko ja" -md -y -s
```

అనువదించిన అవుట్‌పుట్‌ను సమీక్షించండి:

```bash
co-op-review -l "ko ja"
```

లింక్ మైగ్రేషన్‌ను ప్రివ్యూ చేయండి:

```bash
migrate-links -l "ko" --dry-run
```
