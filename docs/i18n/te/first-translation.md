# ఒక చిన్న ప్రాజెక్టును అనువదించండి, సవరించండి, మరియు సమీక్షించండి

రెండు చిన్న Markdown ఫైళ్లు మరియు ఒక గమ్య భాషతో ప్రారంభించండి. అనువాదాలు ఎక్కడ రాయబడ్డాయో, మూలం మారినప్పుడు ఏమవుతుందో, మరియు ఫలితాన్ని ఎలా పరిశీలించాలో మీరు చూడగలుగుతారు.

## రికార్డు చేయబడిన ఫలితాలు

ఈ ఉదాహరణను Co-op Translator 0.21.0 మరియు Azure OpenAI (`gpt-5-mini`)తో 2026 సెప్టెంబర్ 19 న అమలు చేయబడింది. మార్పులేతర CLI కమాండ్లు Click యొక్క `CliRunner` ద్వారా నిర్మిత వీల్ మరియు ఉన్న Python ఆధారాలను ఉపయోగించి పిలవబడ్డాయి.

| దశ | ఫలితం |
| --- | --- |
| Preview | Exit 0; మోడల్ అనువాదం అభ్యర్థించబడలేదు |
| Initial translation | Exit 0; 27.36 seconds |
| Initial review | Exit 0 |
| Edit README and review | Exit 1; పాత అనువాదం గుర్తించబడింది |
| Update translation | Exit 0; 22.17 seconds |
| Review after update | Exit 0; ఎటువంటి తప్పులు లేదా హెచ్చరికలు లేవు |
| Unchanged guide | README నవీకరణ ముందు మరియు తరువాత బైట్లు ఒకే మాదిరిగానే ఉన్నాయి |
| Run again | Exit 0; అన్ని అనువాద ఫైళ్ల కోసం హ్యాష్‌లు ఒకేలా ఉన్నాయి |

ఇవి వ్యక్తిగత రన్ కొలతలు, పనితీరు హామీలు కావు. సెటప్ సమయంలో తీసిన సమయం బహిష్కరించబడింది; ప్రొవైడర్ బిల్లింగ్ కొలవబడలేదు. మార్పు లేని రన్ కూడా ప్రొవైడర్ ఆరోగ్య తనిఖీ చేయవచ్చు.

క్రింది లింక్‌లను పరిశీలించండి: [ప్రాథమిక అనువాదం](../../assets/demo/before.txt), [నవీకరించిన అనువాదం](../../assets/demo/after.txt), [సంపూర్ణ అనువాద తేడా](../../assets/demo/update.diff), [పాత సమీక్ష](../../assets/demo/review-stale.txt), [చివరి సమీక్ష](../../assets/demo/review-after.txt), మరియు [రన్ వివరాలు](../../assets/demo/results.json). క్యాప్చర్ చేయబడిన తేడా చూపినట్లే, పూర్తి ఫైల్ అనువాదం ఇతర పదప్రయోగాలను కూడా మార్చవచ్చు. రెండు సాధారణ పాఠ్య దస్త్రాలు ఉత్పత్తి చేసిన నిరాకరణను నిల్వ చేసుకుంటాయి.

మానవ సమీక్ష ఇప్పటికీ ముఖ్యం: the captured update uses `[사용 가이드](guide.md)을`; the Korean particle should be `[사용 가이드](guide.md)를`. పాఠ్య కళారూపాలు ఈ అవుట్పుట్‌ను ఎడిట్ చేసిన అనువాదంగా మోడల్ అవుట్పుట్‌గా చూపించడానికి బదులుగా దాన్ని యథావిధిగా ఉంచుతాయి. పదజాల సమస్య ఉన్నప్పటికీ నిర్మాణాత్మక సమీక్ష విజయవంతంగా పూర్తయింది.

## 1. ఒక చిన్న ఫోల్డర్ తయారుచేసుకోండి

Python 3.11–3.14 మరియు [వర్చువల్ ఎన్విరాన్‌మెంట్ సెటప్](configuration.md#local-runtime-setup) ను ఉపయోగించండి. ఈ ఉదాహరణలో ఉపయోగించిన వెర్షన్‌ను ఇన్స్టాల్ చేయండి:

```bash
python -m pip install co-op-translator==0.21.0
mkdir translation-demo
cd translation-demo
git init
```

Download [README.txt](../../assets/demo/README.txt) and [guide.txt](../../assets/demo/guide.txt) into this folder, saving them as `README.md` and `guide.md`. అవి చిన్న కల్పిత ప్రాజెక్టు పత్రాలు; ఏ అప్లికేషన్ ఇన్స్టాలేషన్ అవసరం లేదు.

READMEలో కోడ్ బ్లాక్ మరియు `guide.md` కు ఒక లింక్ ఉంది. దాని చివరి వాక్యం:

```text
Notes are saved locally.
```

ఈ ఫోల్డర్‌లో ఇవే రెండు మూల పత్రాలను మాత్రమే ఉంచండి. తరువాత ఉండే అన్ని కమాండ్లు `translation-demo` లో నడుస్తాయి మరియు Bash మరియు PowerShell లో పనిచేస్తాయి.

## 2. క్రెడెన్షియల్స్ లేకుండా ప్రివ్యూ

```bash
translate -l "ko" -md --dry-run
```

ప్రివ్యూ మోడల్‌ను పిలవకుండా లేదా అనువాదాలను రాయకుండా అనువాద పనిని అంచనా వేస్తుంది. టోకెన్ అంచనాలు బిల్లింగ్ కోట్ కాదు. మొదటి రన్ రెండు Markdown ఫైళ్లను కొత్త పనిగా గుర్తించాలి.

## 3. ఒక ప్రొవైడర్ను ఎంచుకొని అనువదించండి

ఒక ప్రొవైడర్ను [కన్ఫిగరేషన్ గైడ్](configuration.md)ను ఉపయోగించి సెట్ చేయండి: Azure OpenAI, OpenAI, లేదా Anthropic. OpenAI మరియు Anthropic టెక్స్ట్ అనువాదానికి Azure ఖాతా అవసరం లేదు. ఈ ఉదాహరణకు ఇమేజ్ సేవలు అవసరం కాదు.

మీరు స్థానిక `.env` ఫైల్‌ను ఉపయోగిస్తే, `.env` ను ఈ ఫోల్డర్ యొక్క `.gitignore` లో జోడించండి. అనువాద కాల్స్ మీ ప్రొవైడర్ ఖాతాను ఉపయోగిస్తాయి మరియు ఛార్జీలకు కారణం కావచ్చు.

```bash
translate -l "ko" -md
co-op-review -l "ko"
```

తెరవండి `translations/ko/README.md` మరియు `translations/ko/guide.md`. కేరియన్ పదజాలం, కోడ్ బ్లాక్, మరియు అనువదించిన README నుండి అనువదించిన guide కు ఉన్న లింక్ను తనిఖీ చేయండి. అవుట్పుట్ పదజాలం మోడల్‌పై ఆధారపడి మారుతుంది.

`co-op-review` తాజాదన, నిర్మాణం, మరియు స్థానిక లింకులను పరీక్షిస్తుంది. పాస్ అయిన ఫలితం భాషా ఖచ్చితత్వాన్ని ధృవీకరించదు. కొనసాగే ముందు తెలియజేయబడిన ఏ తప్పులైనా పరిష్కరించండి.

విజయవంతమైన బేస్లైన్‌ను Gitతో నమోదు చేయండి (ఆవశ్యకమైతే ముందుగా మీ Git ఐడెంటిటీని కాన్ఫిగర్ చేయండి):

```bash
git add README.md guide.md translations
git commit -m "Record initial Korean translation"
```

## 4. మూలాన్ని మార్చండి

`README.md` లో, `Notes are saved locally.`ని ఈ వాక్యంతో మార్చండి:

```text
Notes are saved locally as Markdown files.
```

`guide.md` ను మార్చకుండా ఉంచండి. తరువాత రన్ చేయండి:

```bash
co-op-review -l "ko"
translate -l "ko" -md --dry-run
```

సమీక్ష README అనువాదాన్ని పాతదిగా (stale) సూచించి విఫలంగా ఎగ్జిట్ చేయాలి. ఇది ఆశించిన మధ్యస్థితి. ప్రివ్యూ మార్చబడిన README కోసం పని గుర్తించాలి.

## 5. నవీకరించండి మరియు డిఫ్‌ను పరిశీలించండి

```bash
translate -l "ko" -md
git diff -- README.md translations/ko/README.md
git diff -- translations/ko/guide.md
co-op-review -l "ko"
```

నిజమైన డిఫ్‌ను పరిశీలించండి: డిఫాస్టు CLI మార్చబడిన ఫైల్‌ను మళ్లీ అనువదిస్తుంది, కాబట్టి మోడల్ ఆ ఫైల్‌లోని ఇతర పదజాలాన్ని కూడా సవరించవచ్చు. మార్పు లేని guideకు డిఫ్ ఉండకూడదు. సమీక్ష READMEని ఇకపై staleగా నివేదించకూడదు; ఇతర కనుగొనిన అంశాలను నిర్లక్ష్యపరచకుండా పరిశీలించండి.

మానవ Markdown ఎడిట్ల బ్లాక్-స్థాయి పరిరక్షణకు [Python API](api.md)లో ఒక ఐచ్ఛిక అనువాద స్థితి ప్రొవైడర్ అవసరం. ఇది ఈ CLI కమాండ్ల ద్వారా ఎనేబుల్ చేయబడలేదు.

## 6. మార్పుల్లేకుండా మళ్ళీ అమలు చేయండి

నవీకరించిన సోర్స్ మరియు అనువాదాన్ని కమిట్ చేయండి:

```bash
git add README.md translations
git commit -m "Update Korean translation after source edit"
translate -l "ko" -md
git diff --exit-code -- translations
```

ఇప్పుడు ఉన్న అనువాదాలు మరియు మార్పు లేకపోయే కాన్ఫిగరేషన్‌తో, ట్రాన్స్లేటర్ ఫైళ్లను స్కిప్ చేస్తుంది. చివరి Git కమాండ్ డిఫ్ ఉత్పత్తి చేయకూడదు మరియు విజయవంతంగా ఎగ్జిట్ అవుతుంది.
