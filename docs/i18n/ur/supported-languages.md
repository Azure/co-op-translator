## ایک زبان شامل کریں

نئی زبان کے لیے سپورٹ شامل کرنے کے لیے:

1. زبان کے یوٹیلِٹیز میں زبان کا کوڈ اور دکھانے والا نام شامل کریں۔
2. `src/co_op_translator/fonts/font_language_mappings.yml` میں فونٹ شامل کریں یا میپ کریں۔
3. مارک ڈاؤن اور تصویر کے ترجمے کے نتائج کا ٹیسٹ کریں۔
4. میپنگ اور جانچ کے نوٹس کے ساتھ ایک پل ریکویسٹ کھولیں۔
