# 參與語言改進

你的語言知識可以幫助改善 Co-op Translator。請透過 [翻譯回饋表格](https://github.com/Azure/co-op-translator/issues/new?template=translation_feedback.yml) 提供一個範例、建議修正及說明開始。你不需要撰寫程式碼或支付模型運行費用。

## 從報告到共用改進

1. 貢獻者提供原文節錄、其翻譯與上下文。
2. 語言審核者檢查語義、自然度，以及建議是否依賴特定語區或課程。
3. 維護者決定該修正應該放在來源課程、共用語言指示、術語設定，還是翻譯程式碼中。
4. 對於共用規則，維護者會比較在報告範例與不相關範例上變更前後的輸出。貢獻者可以在不用自行執行工具的情況下檢視這些輸出。
5. 產生的 PR 會連結該報告並標註提供範例與審核的人。部署或在使用該套件的倉庫中重生成則為另一個步驟。

一則報告不會自動更改提示詞或重生成課程翻譯。課程專屬的修正應保留與課程倉庫的連結。不要假設手動編輯會在日後重新翻譯時保留；請確認該工作流程的實際行為。

## 現有範例：日語的 Markdown 連結

該 [日語指示檔案](https://github.com/Azure/co-op-translator/blob/main/src/co_op_translator/templates/language/ja.md) 告訴模型要翻譯連結文字，同時保留 Markdown 語法與連結目的地。例如，寫成 `[text](URL)` 的連結不得變成 `「text」（URL）`。

這是一個聚焦的語言規則範例，並以正確與錯誤輸出示例為佐證。這並不代表僅靠提示詞指示就能保證 Markdown 一定正確。

該 [Markdown 提示建構器](https://github.com/Azure/co-op-translator/blob/main/src/co_op_translator/utils/markdown/prompts.py) 使用經過小寫並修剪的語言代碼載入 `templates/language/<language_code>.md`。如果檔案不存在，則使用共用指示。這描述的是 Markdown 提示的路徑；不要假設每張圖片或其他翻譯路徑都使用相同的指示。

該 [提示詞測試](https://github.com/Azure/co-op-translator/blob/main/tests/co_op_translator/utils/markdown/test_prompts.py) 檢查是否包含日語指示。那是驗證提示詞的組裝，而非翻譯品質。

## 語言規則應包含什麼？

提出一項具體且可重複的修正，附上原文範例、預期行為，以及該規則不得適用的反例。保留語意、佔位符、程式碼、URL 以及文件結構。避免將個人風格偏好或單一課程的術語視為通用規則。

目前的 [詞彙表實作](https://github.com/Azure/co-op-translator/blob/main/src/co_op_translator/glossary.py) 會保護術語不被翻譯。它並非來源到目標的術語辭典。在向貢獻者承諾新術語行為之前請先討論。

## 社群範例：日語產品名稱報告

在 [report #527](https://github.com/Azure/co-op-translator/issues/527) 中，@hyoshioka0128 找出一個將產品名稱 `Co-op Translator` 變更為 `Co-op 翻訳` 的日語翻譯。該報告包含受影響文件的連結與截圖，讓問題容易定位。

該貢獻者也連結了 [相關課程 PR](https://github.com/microsoft/AZD-for-beginners/pull/109)。在議題討論中，維護者回覆了該報告並建議調查名稱為何會變更，包括術語保護、詞彙表行為與翻譯路徑。

這說明小型報告如何支持超出個別措辭修正的調查。這並非已驗證的變更前後結果，或證明上述日語 Markdown 連結指示修復了此產品名稱問題。

你也可以用同樣的方式貢獻：分享原文、目前的翻譯、建議修正以及其重要性。必要時附上文件連結或截圖。你不需要在報告前診斷原因或撰寫提示詞。

## 採納規則前的驗證

在基準與候選執行中使用相同的來源範例、翻譯版本、提供者/模型與生成設定，唯一改動僅限於擬議的指示。記錄實際的提示詞變更與輸出；必要時重複範例以區別穩定的效果與輸出變異。包含所回報的失敗、對比的上下文，以及原本已正確翻譯的範例。

| 範例 | 原文/上下文 | 基準輸出 | 候選輸出 | 審核者評估 |
| --- | --- | --- | --- | --- |
| 回報失敗 | 收集中 | 未執行 | 未執行 | 等待中 |
| 反例 | 收集中 | 未執行 | 未執行 | 等待中 |
| 不受影響的範例 | 收集中 | 未執行 | 未執行 | 等待中 |

請將結構上的不變量與語言判斷分開檢查。提示詞載入測試成功並非品質評估，而一個完全相符的預期句子也不是唯一正確的翻譯。如果缺少上下文、模型執行或語言審核，請把提案保留為等待中，而非聲稱問題已修復。
