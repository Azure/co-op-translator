# README 語言範本

Co-op Translator 可以為發佈翻譯內容的儲存庫維護 README 語言表。

當您希望 Co-op Translator 在每次翻譯執行時取代整個區段時，請使用下面的標記。如果您想手動維護自訂子集，請移除這些標記。

標記上方的歸屬和快速入門連結是選用的。它們可幫助讀者了解翻譯如何維護以及如何翻譯他們自己的儲存庫。請將它們放在標記之外，以便語言表更新時能保留它們。當更新其他儲存庫時，請遵循其貢獻指南，並讓其維護者決定是否包含此文字。

> **Prefer to Clone Locally?**
>
> This repository includes many language translations, which can significantly increase download size. To clone without translations, use sparse checkout:
>
> ```bash
> git clone --filter=blob:none --sparse https://github.com/org/repo.git
> cd repo
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```

在翻譯期間個人化稀疏簽出（sparse-checkout）儲存庫的 URL：

```bash
translate -l "ko" --repo-url "https://github.com/org/repo.git"
```

如果存在標記，Co-op Translator 可以在新增或變更語言時更新產生的表格。

對於現有的 README，您可以在語言表標記上方新增選用的歸屬和快速入門連結，而不必取代其語言連結或其他內容。將支援語言的連結指向 [目前語言指南](https://github.com/Azure/co-op-translator/blob/main/docs/supported-languages.md)。
