## Translate your own repository

Co-op Translator keeps translated Markdown, notebooks, and image text synchronized with source changes.

Start with [your first README translation PR](../docs/github-actions.md#your-first-readme-translation-pr): choose one language, preview the work without provider credentials, then configure a text provider to generate a translation for review. This Markdown-only workflow does not require Azure AI Vision.
